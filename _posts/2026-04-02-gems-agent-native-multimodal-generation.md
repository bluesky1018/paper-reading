> 📄 **论文**：GEMS: Agent-Native Multimodal Generation with Memory and Skills
> 🔗 **arXiv**：[2603.28088](https://arxiv.org/abs/2603.28088)
> 🏢 **机构**：Tong Zhu, Yafu Li, Xiaoye Qu 等

## 一句话总结

GEMS 受 Claude Code 等先进智能体框架启发，通过智能体循环（迭代闭环优化）、智能体记忆（层次化持久化轨迹记忆）和智能体技能（领域特定专业能力按需加载）三大核心组件，将文生图任务重构为智能体驱动的迭代优化问题，使轻量级 6B 模型在 GenEval2 上超越闭源 SOTA。

## 背景与问题

近年来，多模态生成模型在通用生成任务上取得了显著进展，但在处理复杂指令和专业化下游任务时仍然面临挑战：

1. **复杂指令理解**：多组合要素、精确空间关系、精细属性控制等复杂 Prompt 超出基础模型能力范围
2. **专业领域任务**：电商产品图、游戏设计图、医疗可视化等专业下游任务需要领域专业知识
3. **单次生成的局限**：基础模型在单次前向传播中无法通过自我反思和迭代改进来修正错误

现有的推理时扩展方法（如提示重写、随机搜索）缺乏持久化记忆和系统化专业技能。GEMS 受 Claude Code 等先进智能体框架的成功启发，将智能体范式引入多模态生成领域。

## 核心方法

GEMS 基于三大核心组件构建：

![GEMS 系统架构](https://arxiv.org/html/2603.28088v1/x2.png)
*图2：GEMS 系统架构。框架由智能体循环（Agent Loop）、智能体记忆（Agent Memory）和智能体技能（Agent Skill）三大支柱组成。用户 Prompt 由 Agent Skill 提供的领域知识增强，然后在 Agent Loop 中迭代精化，Agent Memory 管理历史上下文以指导生成过程。*

### 组件一：智能体循环（Agent Loop）

Agent Loop 作为 GEMS 的骨干，包含五个协作模块：

- **Planner（规划器）**：分析用户意图，选择适当技能，制定生成策略
- **Decomposer（分解器）**：将复杂指令分解为可执行的子任务
- **Generator（生成器）**：基于当前状态和 Prompt 生成图像
- **Verifier（验证器）**：评估生成结果是否符合用户意图和质量标准
- **Refiner（精化器）**：基于验证反馈对 Prompt 或生成参数进行针对性修正

这一闭环架构支持渐进式的提示-视觉对齐，尤其适用于复杂指令。

### 组件二：智能体记忆（Agent Memory）

Agent Memory 提供**持久化的轨迹级记忆**，层次化存储：
1. **事实状态**：每轮迭代的具体生成状态和评估结果
2. **压缩经验摘要**：对历史轨迹的层次化压缩表示

通过归档层次化压缩表示，系统消除信息噪声，同时为 Refiner 提供整个生成轨迹的鲁棒长上下文视角，避免冗余信息干扰。

### 组件三：智能体技能（Agent Skill）

![Agent Skill 系统架构](https://arxiv.org/html/2603.28088v1/figs/skill.png)
*图3：Agent Skill 系统架构，展示其可扩展和按需加载的特性。*

Agent Skill 提供可扩展的领域特定专业能力集合，支持**按需加载**。技能类别包括：
- **美学绘图（Aesthetic Drawing）**：艺术风格和美学增强
- **创意绘图（Creative Drawing）**：创意表达和概念视觉化
- 以及多种其他专业领域技能

![Agent Skill 效果对比](https://arxiv.org/html/2603.28088v1/figs/skill_demo.png)
*图7：Agent Skill 的定性比较。GEMS 自动触发美学绘图（左）和创意绘图（右）以增强艺术表达。*

## 实验结果

GEMS 在五个主流基准和四个专业下游任务上进行评估，使用多种生成后端验证效果。

![GEMS 整体性能](https://arxiv.org/html/2603.28088v1/x1.png)
*图1：GEMS 与 Z-Image-Turbo 的整体性能。GEMS 使轻量级蒸馏 6B 模型 Z-Image-Turbo 在各种主流基准上超越 Nano Banana 和 GPT-Image 等知名闭源模型。*

**核心性能指标**（Z-Image-Turbo 后端）：
- 五个主流基准平均提升：**+14.22**
- 四个专业下游任务平均提升：**+14.03**
- **在 GenEval2 上超越 SOTA 闭源模型 Nano Banana 2**

技能分布分析显示，引入 Memory 和 Skill 后，迭代分布向更早轮次偏移，降低了平均迭代次数，在效率和效果之间实现了更好的平衡。

## 总结

GEMS 将文生图生成重构为智能体驱动的迭代优化问题，通过统一的智能体循环、持久化记忆和领域专业技能，实现了对基础模型能力的显著扩展。最具说服力的结论是：轻量级 6B 模型在 GEMS 框架下超越了参数量更大的闭源 SOTA 模型，证明了智能体系统可以有效解锁较小基础模型的潜力。

**局限性**：
- 智能体循环引入了额外的推理延迟，在延迟敏感场景下需要权衡
- 技能库的质量和覆盖度直接影响专业任务的表现，需要持续维护
- 记忆压缩策略的设计对长轨迹优化效果影响较大，尚有改进空间
