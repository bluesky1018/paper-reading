## 一句话总结

GFT 通过将 SFT 重新解读为一种奖励极稀疏的策略梯度优化，并引入组优势学习（GAL）和动态系数矫正（DCR），在数学推理任务上全面超越 SFT 和 GRPO，同时大幅缓解灾难性遗忘问题。

## 背景与问题

监督微调（SFT）是当前 LLM 训练的基石，在指令跟随和知识蒸馏方面表现出色。然而，作者从策略梯度角度对 SFT 进行深入分析，发现其存在四个本质性缺陷：

1. **奖励极度稀疏**：SFT 只使用单条专家示范，隐式奖励为 "正确则 +1，否则 0"，奖励信号极其稀疏，模型难以获得有效的对比学习信号。

2. **逆概率加权不稳定**：SFT 的梯度权重正比于 1/π_t（当前 token 概率的倒数），当生成概率极小时，梯度权重可趋近无穷，导致训练极不稳定。

3. **熵崩溃**：SFT 强迫模型模仿单一路径，导致输出多样性快速下降，模型陷入"只能走一条路"的局面，后续 RL 训练难以探索新解法。

4. **梯度爆炸**：上述问题的综合作用下，训练过程中容易出现梯度爆炸，影响收敛稳定性。

这解释了一个令人困惑的现象：先 SFT 再 GRPO 的效果，往往**不如直接 GRPO**——因为 SFT 已经让模型的输出分布过度收缩，后续强化学习难以有效探索。

## 核心方法

### 理论基础：SFT 作为策略梯度的特例

作者严格推导了 SFT 梯度与策略梯度的等价关系，证明：

$$\nabla \mathcal{L}_{SFT} \equiv \nabla \mathcal{L}_{PG} \big|_{R \text{ extremely sparse, } w = 1/\pi_t}$$

这一发现为后续改进提供了清晰的理论依据。

### 组优势学习（GAL）

为每个查询构建**混合响应组**（K=8）：

| 来源 | 数量 | 说明 |
|------|------|------|
| 专家示范 | 1条 | 来自训练数据 |
| 教师蒸馏 | 3条 | Qwen2.5-Math-72B 生成 |
| 自我采样 | 4条 | 当前策略 rollout |

优势归一化：

$$A(y_k) = \frac{R(y_k) - \mu}{\sigma + \epsilon}$$

通过多响应对比，将奖励从"单点稀疏"变为"分布式对比"，大幅缓解奖励稀疏问题，同时保持了多样性（Pass@k 指标显著提升）。

### 动态系数矫正（DCR）

引入阈值 τ（最优约为0.7）对逆概率权重进行自适应裁剪：

- 若 π_t < τ：施加停止梯度（stop-gradient），边界化更新
- 若 π_t ≥ τ：保留标准梯度

这一机制在保留高效知识迁移的同时，避免了极小概率 token 引发的梯度爆炸。

## 实验结果

### 主要结果（数学推理）

| 模型 | 方法 | AMC23 | MATH | Minerva |
|------|------|-------|------|---------|
| Qwen2.5-Math-1.5B | Base | 30.16 | 46.54 | 10.51 |
| | SFT | 31.25 | 60.66 | 23.99 |
| | GRPO | 44.84 | 65.97 | 21.17 |
| | **GFT** | **46.09** | **70.50** | **28.93** |
| Qwen2.5-Math-7B | SFT | 41.88 | 67.16 | 31.82 |
| | **GFT** | **56.09** | **77.31** | **39.86** |
| LLaMA-3.2-3B | SFT | 19.53 | 43.66 | 12.14 |
| | **GFT** | **27.50** | **49.60** | **18.84** |

**GFT 在所有模型规模和所有数学基准上均超越 SFT 和 GRPO，最大提升幅度达 14+%。**

### 灾难性遗忘（通用能力保留）

| 方法 | Mawps↑ | Svamp↑ | MMLU-STEM↑ |
|------|-------|-------|----------|
| Base | 96.06 | 86.36 | 41.03 |
| SFT | 91.97 (-4.09) | 78.73 (-7.63) | 35.05 (-5.98) |
| GRPO | 94.60 (-1.46) | 88.11 (+1.75) | 39.48 (-1.55) |
| **GFT** | **95.79 (-0.27)** | **84.65 (-1.71)** | **43.89 (+2.86)** |

**GFT 几乎完全消除了 SFT 的灾难性遗忘问题，在 MMLU-STEM 上甚至超过基础模型。**

### 输出多样性（Pass@k）

| 方法 | SAT Math | Minerva | TabMWP | 平均 |
|------|---------|---------|--------|------|
| 蒸馏 | 66.67 | 22.98 | 79.32 | 56.32 |
| GRPO | 52.95 | 19.89 | 76.77 | 49.87 |
| **GFT** | **72.58** | **28.59** | **85.31** | **62.16** |

Pass@128 指标下，GFT 显著高于 GRPO（+12.3%），说明混合响应组有效保留了模型的探索多样性。

### 最优响应混合比例

| 专家示范:自采样 | 平均分 |
|-------------|------|
| 8:0（纯蒸馏） | 24.84 |
| 6:2 | 43.60 |
| **2:6（最优）** | **45.59** |
| 0:8（纯RL） | 30.84 |

2:6 的混合比例最优，说明少量高质量专家示范配合大量自采样能实现最佳效果。

## 总结

GFT 的理论贡献在于揭示了 SFT 的策略梯度本质，这一统一视角为理解各种微调方法的优劣提供了新的分析工具。实践贡献在于 GAL 和 DCR 的精妙设计——前者解决奖励稀疏，后者解决训练不稳定——两者相互配合，实现了超越 SFT 和 GRPO 的综合性能。

特别值得关注的是 GFT 在灾难性遗忘方面的出色表现。SFT 在提升数学能力的同时，会显著损害 MMLU-STEM 等通用能力；而 GFT 不仅保留了这些能力，甚至在 MMLU-STEM 上超越了原始基础模型（+2.86%）。这对于需要平衡专业能力和通用能力的实际应用场景极具价值。

局限性方面，GFT 需要维护混合响应组，计算开销高于标准 SFT；τ 阈值的选择（0.7最优）可能对不同任务域需要重新调优。未来工作可探索自适应阈值选择方法。
