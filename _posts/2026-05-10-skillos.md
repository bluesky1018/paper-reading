> 📄 **论文**：SkillOS: Learning Skill Curation for Self-Evolving Agents
> 🔗 **arXiv**：[2605.06614](https://arxiv.org/abs/2605.06614)
> 🏢 **机构**：多机构合作

## 一句话总结

SkillOS 提出了一种基于经验驱动的强化学习训练方案，通过将技能策划（提取和管理可复用技能）建模为长期流式任务下的学习问题，训练出能跨执行器和任务泛化的技能策划者，相比最强基线提升 9.8% 并减少 6.0% 交互步骤。

## 背景与问题

基于 LLM 的智能体越来越多地部署在现实世界场景中，需要从一次性问题解决转向长期熟练度提升。在流式任务场景中（任务按时间顺序展开），自进化能力至关重要：有能力的智能体不应反复从零开始，而应持续积累、精炼和复用经验。

**技能策划**（从过去交互中提取高质量经验并整合到技能集合中）是自进化智能体的核心能力。然而现有方法存在局限：
- **人工策划技能**（如 Anthropic 的技能库）：需要大量人工专业知识，无法扩展到智能体遇到的多样化任务
- **基于提示/启发式的方法**：依赖固定规则，缺乏下游性能反馈，无法适应执行器的实际需求
- **现有 RL 方法**：要么专注于教智能体使用技能，要么只在短任务流中优化技能操作，学习信号密度有限

特别缺少对**技能更新**和**技能删除**等复杂管理操作的学习，这对长期健壮自进化至关重要。

## 核心方法

### SkillOS 框架

![SkillOS 框架](https://arxiv.org/html/2605.06614v1/x1.png)
*图1：(a) SkillOS 的模块化多智能体框架。冻结的执行器用技能集合解决任务，可训练的技能策划者通过函数调用更新和管理集合；(b) 技能以 Markdown 文件表示，包含指令、示例和支持资源。*

**模块化多智能体设计**：
- **冻结执行器（Frozen Executor）**：使用技能仓库（SkillRepo）解决任务，不参与训练
- **可训练技能策划者（Trainable Skill Curator）**：通过函数调用更新和管理技能集合

**技能表示**：将技能表示为 Markdown 文件，通过类似操作系统的文件 I/O 操作进行管理（读、写、更新、删除）。

### 两个核心设计

**1. 群组训练实例构建（Group Task Construction）**：
每个训练实例构建为一组**相关任务**。通过模拟测试时的流式场景，将技能策划建立在长期效用上：从早期经验中归纳的技能通过其改善后续相关任务的能力来评估。

这使得学习信号来自真实的长期效用，而不仅仅是即时反馈。

**2. 多维度奖励设计**：
将环境反馈归因于策划决策的奖励，包含：
- **任务性能**：下游任务成功率
- **有效函数调用**：技能操作的合法性
- **技能质量**：所策划技能的内容质量
- **SkillRepo 紧凑性**：技能集合的精简程度（避免冗余）

*图2：SkillOS 训练流程。将群组相关任务中的延迟和间接监督转化为技能策划的学习信号。*

## 实验结果

在多轮智能体任务和单轮推理任务上评估：

### 主要结果

| 方法 | 性能提升 | 交互步骤 |
|------|---------|--------|
| 无记忆基线 | - | 基准 |
| 提示/启发式记忆 | +部分 | 增加 |
| 现有 RL 技能方法 | +有限 | 减少少量 |
| **SkillOS（本文）** | **+9.8%** | **-6.0%** |

相比最强基线，SkillOS 实现：
- **+9.8% 相对性能提升**
- **-6.0% 更少的交互步骤**

### 泛化实验

- 训练好的技能策划者**跨执行器泛化**：即使使用 Gemini-2.5-Pro 作为执行器也能提升性能
- **8B 策划者超越 Gemini-2.5-Pro**：当直接用作策划者时，小模型也能优于大模型基线

### 定性分析

- 学习到的技能策划者产生更有针对性和更有效的技能利用
- SkillRepo 中的技能随时间演化为更丰富结构化的 Markdown 文件，编码更高层次的元技能
- 学习到了复杂的管理操作（技能更新、删除），而不只是简单的插入操作

## 总结

SkillOS 将技能策划重新定义为一个长时间域、执行器基础的学习问题，通过群组任务构建和多维奖励设计将延迟间接的监督信号转化为有效的学习信号。这使得智能体能够学习真正有用的长期技能管理策略，而不只是短期适应。

关键贡献：将自进化智能体的技能记忆管理从规则驱动提升为 RL 学习驱动，并证明了跨执行器和任务的强泛化性。这为构建能够在真实世界流式场景中持续自我提升的智能体系统提供了实用基础。
