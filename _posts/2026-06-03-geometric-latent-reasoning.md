> 📄 **论文**：Geometric Latent Reasoning Induces Shorter Generations in LLMs
> 🔗 **arXiv**：[2606.02248](https://arxiv.org/abs/2606.02248)
> 🏢 **机构**：Idiap 研究院（瑞士）、EPFL

## 一句话总结
GLR（几何潜在推理）将推理过程建模为预训练 token 嵌入空间中的几何路径逼近问题，通过轻量过渡头在连续空间中进行迭代方向更新，在严格约束生成预算下显著提升准确率，同时大幅缩短生成长度。

## 背景与问题

LLM 解决复杂问题时依赖显式推理链（Chain-of-Thought），但这带来三个问题：

1. **计算开销大**：冗长的推理轨迹消耗大量计算资源
2. **长度敏感**：在严格 token 预算下性能急剧下降
3. **离散约束**：必须在每一步提交到具体 token，无法在连续空间中"思考"

现有潜在推理方法（如将隐状态直接循环馈入模型、通过辅助模型蒸馏软轨迹等）存在嵌入空间不匹配问题，或引入复杂的蒸馏依赖。

GLR 的核心洞察：将推理建模为预训练 **token 嵌入空间**中的几何路径问题——使用文本 CoT 轨迹作为锚点，学习逼近离散推理轨迹，同时允许连续偏差以跳过不必要的中间步骤。

## 核心方法

*图：GLR 模型架构，轻量过渡头（g_φ）在嵌入空间中进行迭代方向更新*

### 几何潜在推理（GLR）

**问题形式化**：将标准文本 CoT 视为离散 token 嵌入空间中的一条路径。给定起始嵌入 h₀（问题的隐状态），目标是预测一系列方向更新 {Δ₁, Δ₂, ..., Δ_K}，使得经过 K 步后的嵌入 h_K 接近 CoT 路径的某个中间点，从而让后续 token 解码从更"靠近答案"的位置开始。

**轻量过渡头 g_φ**：
- 对于 0.6B 模型，g_φ 仅添加约 **1M** 额外参数
- 对于 1.7B 模型，g_φ 仅添加约 **4M** 额外参数
- 从零初始化，在预训练模型的 token 嵌入空间中工作，避免嵌入不匹配

**训练目标**：以文本 CoT 轨迹作为监督，训练 g_φ 预测连续空间中的推理方向更新，同时通过损失掩码确保最终 token 生成的准确性。

**推理过程**：给定推理步数 K（latent budget），模型先进行 K 步连续潜在过渡，然后切换到标准 token 生成。

## 实验结果

### 严格预算下的性能（Qwen3-1.7B，MATH500）

| 方法 | 512步预算准确率 | 1024步预算准确率 | 平均生成长度（正确答案）|
|------|--------------|--------------|---------------------|
| CoT-SFT | ~0% | ~15% | 1847 tokens |
| **GLR-10（ours）** | **>40%** | **~52%** | **~1200 tokens** |
| **GLR-20（ours）** | **~45%** | **~55%** | **~1050 tokens** |

**关键发现：**

1. **严格预算下大幅领先**：在 512 步预算的 MATH500 上，CoT-SFT 几乎解决 0% 的问题，GLR-10 解决超过 **40%**
2. **更短的生成长度**：对于相同的正确答案，GLR 生成的 token 数比 CoT-SFT 少约 **35-45%**
3. **推理不来自训练技巧**：在推理时禁用潜在步骤（K=0）后，相同的 GLR 模型回退到冗长显式生成，证明性能提升来自连续潜在过渡本身

## 总结

GLR 提供了一种轻量、无需额外推理成本、与预训练语言模型天然兼容的潜在推理方案。通过将推理建模为 token 嵌入空间中的几何路径问题，GLR 实现了"连续思考"——在离散 token 生成开始前，先在嵌入空间中进行若干步方向更新，从而跳过大量显式中间步骤。

这项工作揭示了一个重要现象：LLM 的推理轨迹中存在**可压缩的几何结构**，连续空间可以更高效地表达这些结构。这为未来的高效推理研究提供了新视角：不必要求模型"写出每一步"，而是可以在嵌入空间中"滑动"到更接近答案的位置，再开始生成。
