> 📄 **论文**：VoiceMem: Streaming Dual-Brain Memory for Real-Time Interaction
> 🔗 **arXiv**：[2608.26005](https://arxiv.org/abs/2608.26005)
> 🏢 **机构**：南洋理工大学、新加坡国立大学、清华大学、香港中文大学、Open Interaction Lab

## 一句话总结

VoiceMem 提出了一种流式双脑记忆架构，通过左脑（信息检索）与右脑（情感人设）的并行协作，在保证实时性（检索延迟 134ms）的前提下，为语音语言模型提供准确、个性化且情感感知的长期记忆能力。

## 背景与问题

随着语音语言模型（SLM）和双工对话系统的快速发展，如何赋予这些系统长期记忆能力成为重要挑战。现有记忆系统在三个关键维度上存在缺陷：

1. **统一架构缺失**：现有系统要么专注于信息检索，要么专注于情感理解，难以同时建模用户的知识与情感/人设状态。
2. **延迟与密度矛盾**：传统记忆系统需要 2-3 秒完成检索，而实时对话仅允许 100-200ms 的额外延迟；同时 top-100 输出对语音模型的上下文窗口来说过于庞大。
3. **语音模态缺失**：现有记忆基准和系统主要针对文本，无法处理语音中的副语言信息（语调、情感、环境声）。

## 核心方法

VoiceMem 由三个核心组件构成：**左脑（信息记忆）**、**右脑（人设记忆）** 和 **流式 I/O 机制**。

### 左脑：高效信息检索

左脑通过 **Cluster-Entity-MemItem 三层索引**解决密集记忆访问问题：
- **Schema（模式层）**：粗粒度语义路由，识别对话涉及的主题领域
- **Entity（实体层）**：精确定位具体人物、事件或概念
- **MemItem（记忆项层）**：存储具体记忆内容，与实体关联

检索时，流式匹配器在用户说话过程中实时识别相关 Schema 和 Entity，通过强/弱一跳连接扩展候选集，最终在压缩后的候选池中执行 top-K 检索，将检索延迟从 2-3 秒降至 **134ms**。

**Cluster 涌现机制**：通过查询一致性评分 $\rho(H)$ 自动识别经常被一同检索的实体子图，促成新的 Cluster 涌现，保持语义密度。

### 右脑：用户人设建模

右脑维护**人设图（Persona Graph）**，包含两类节点：
- **独立节点 $v^I$**：编码用户内在属性，如持久性情绪倾向、行为规律
- **跨实体节点 $v^C_e$**：捕获用户对特定人/事/物的情感态度，与左脑实体关联

右脑通过**短时情感归因**（当轮情感）和**长时情感归因**（跨会话情感演化）双机制，构建完整的用户情感画像。

### 流式记忆 I/O

- **流式写入**：对话结束后异步更新，不阻塞实时响应
- **流式检索**：用户说话过程中并行执行，在 VAD 截止前完成

## 实验结果

### 信息记忆基准（文本对话）

| 方法 | LoCoMo | LongMemEval | Memora | **平均** |
|------|--------|-------------|--------|---------|
| Full-Context | - | - | - | 60.49 |
| Mem0 (top-200) | - | - | - | 52.27 |
| **VoiceMem (top-5)** | - | - | - | **76.39** |

VoiceMem 在 top-5 检索下超过 Mem0 top-200 检索 **+24.12** 分，超过全上下文处理 **+15.90** 分。

### 人设记忆基准

| 方法 | ES-MemEval | PersonaMem | PersonaLens | **平均** |
|------|-----------|------------|-------------|---------|
| MemOS (最强基线) | - | - | - | 72.27 |
| **VoiceMem** | - | - | - | **74.16** |
| **VoiceMem + 微调** | - | - | - | **76.56** |

### ChatMem-Bench（语音记忆专项基准）

新构建的语音记忆评测基准，包含 **316 个问题**，覆盖 **53 小时**音频，分为信息记忆、人设记忆、情感归因、副语言四大类。

## 总结

VoiceMem 通过双脑并行架构和流式 I/O 机制，成功解决了实时语音对话中记忆系统面临的三大挑战：准确性（超越 Mem0 top-200 达 +24 分）、情感感知（达到 SOTA 人设理解）和实时性（134ms 检索，零额外对话延迟）。

该工作的局限性在于：当前系统依赖 GPT-4o-mini 作为骨干 LLM，在资源受限场景下的轻量化部署仍需探索；此外，多语言、多方言语音的记忆处理尚未得到充分验证。

未来，VoiceMem 有望成为新一代语音助手的标准记忆基础设施，推动从"智能工具"到"人性化伙伴"的转变。
