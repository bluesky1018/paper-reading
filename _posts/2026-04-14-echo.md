> 📄 **论文**：ECHO: Efficient Chest X-ray Report Generation with One-step Block Diffusion
> 🔗 **arXiv**：[2604.09450](https://arxiv.org/abs/2604.09450)
> 🏢 **机构**：美的集团 / 北京交通大学 / 大连理工大学

## 一句话总结

ECHO 通过直接条件蒸馏（DCD）框架将多步扩散压缩为每块单步推理，在胸部X光报告生成中实现 **8倍推理加速**，同时临床指标 RaTE 和 SemScore 分别超越自回归基线 **64.33%** 和 **60.58%**。

## 背景与问题

胸部X光（CXR）报告自动生成是临床辅助诊断的重要应用。目前主流方法基于自回归视觉语言模型（VLMs），通过逐 token 解码生成报告，存在明显的推理速度瓶颈：

- 单次报告生成需要数百步顺序解码
- 在高吞吐量的影像科场景下，延迟难以接受
- 扩散模型支持并行生成，但直接应用面临**均场偏差**（mean-field bias）问题

均场偏差源于扩散模型对 token 的独立因子化假设：

$$p_\theta(\mathbf{x}_0|\mathbf{x}_t,t) = \prod_{i=1}^{L} p_\theta(x_{0,i}|\mathbf{x}_t,t)$$

在单步从全掩码状态预测时，各 token 之间缺乏依赖建模，导致生成文本语义不连贯、临床准确性差。

## 核心方法

### 三阶段训练流程

![ECHO 训练流程](https://arxiv.org/html/2604.09450v1/x2.png)
*图：ECHO 三阶段训练管线概览*

**阶段一：Lingshu-7B 医疗 VLM 监督微调**
基于约 73 万条双语 CXR 报告（MIMIC-CXR、CheXpert-Plus、ReXGradient、IU-Xray）进行全参数 SFT，得到 ECHO_AR。

**阶段二：响应非对称扩散（RAD）训练**
将自回归模型转换为块扩散模型，关键创新是**只对响应部分进行重复**（而非整个序列），相比先前方案：
- 节省约 **72.3% 的训练计算量**
- 实现 **3.61 倍训练加速**
- 仅需阶段一 2.2% 的数据即可达到同等质量

**阶段三：直接条件蒸馏（DCD）**

![融合块KV缓存](https://arxiv.org/html/2604.09450v1/x4.png)
*图：融合块 KV 缓存，将推理前向传播次数从 2N 减少至 N*

两相蒸馏策略：
- **相1**：收集教师模型的在线轨迹（基于置信度的逐步去掩码），构建非因子化监督信号
- **相2**：最小化正向 KL 散度，对晚期解码的 token 施加更强的监督权重（step-wise reweighting），同时对 `<eos>` token 增加交叉熵损失防止退化重复

仅使用 **3 万条样本**（占 SFT 数据的 2.3%）完成蒸馏。

### 融合块 KV 缓存

将第 n-1 块的 KV 更新合并到第 n 块的去噪前向传播中，减少冗余计算，将每块的前向传播次数从 **2N → N**，总 FLOPs 不变但延迟显著降低。

## 实验结果

### 主要速度-质量权衡（Table 1）

| 方法 | 速度 (TPF) | TPS | 临床质量 |
|------|-----------|-----|---------|
| 自回归基线 (Lingshu-7B) | ×1.0 | ~16–54 | 基准 |
| ECHO_Base (多步扩散) | ×1.89 | 48.86 | 优于基线 |
| **ECHO_blk4** | **×4.00** | **129.19** | 与 ECHO_Base 相差 <1.25% |
| **ECHO_blk8** | **×8.00** | **274.21** | 与 ECHO_Base 相差 2–5% |

与最佳自回归基线 Lingshu-7B 相比（CheXpert-Plus 数据集）：
- ECHO_blk8 RaTE: **56.85** vs **31.34**（+81%）
- ECHO_blk8 SemScore: **51.40** vs **27.54**（+87%）

### DCD 组件消融（ECHO_blk4）

| SW | CE | 结果 (CheXpert ROUGE-L) | PPL |
|----|----|------------------------|-----|
| ✗ | ✗ | 52.57 | 23.72 |
| ✓ | ✗ | 52.44 | 21.07 |
| ✓ | ✓ | **56.14** | **18.83** |

CE 损失对 `<eos>` token 的监督是最关键的单一贡献，单独去掉导致 ROUGE-L 下降约 3.7%，困惑度显著上升。

## 总结

ECHO 证明了在医疗报告生成领域，**高临床准确性与极致推理效率可以同时实现**。三阶段训练流程（RAD 适配 + DCD 蒸馏）为离散扩散 LM 的单步蒸馏提供了首个系统化方案，对其他文本生成任务的加速具有广泛的借鉴价值。

局限性在于模型主要针对胸部X光这一单一影像模态，向 CT、MRI 等其他医疗影像的迁移需要重新收集领域数据；此外，块扩散范式在超长报告中的性能稳定性仍需进一步验证。
