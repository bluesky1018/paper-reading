> 📄 **论文**：What do Language Models Learn and When? The Implicit Curriculum Hypothesis
> 🔗 **arXiv**：[2604.08510](https://arxiv.org/abs/2604.08510)
> 🏢 **机构**：Carnegie Mellon University、Johns Hopkins University、Northeastern University、USC

## 一句话总结

LLM 预训练遵循一个可预测的组合式课程：技能涌现顺序在不同模型家族间高度一致（ρ=0.81），先决技能先于依赖技能涌现，且模型的表示几何能够预测未见任务的训练轨迹（R²=0.84）。

## 背景与问题

规模化定律揭示了模型**提升多少**，但无法回答模型**学了什么**以及**何时学**。聚合的交叉熵损失掩盖了离散技能获取的细节，复杂基准（如 GSM8K）混淆了多个前置技能，使失败诊断困难。

本文提出**隐式课程假说**：语言模型的预训练遵循一个跨模型家族的组合式可预测课程。这一假说有三个可检验的子假说：

| 假说 | 内容 |
|------|------|
| **H1** 组合式排序 | 前置技能涌现时间不晚于依赖技能 |
| **H2** 跨模型稳定性 | 技能涌现顺序在不同模型间高度一致 |
| **H3** 表示对齐 | 相似的函数向量预测相似的学习轨迹 |

## 核心方法

### 实验规模

- **91 个任务**：53 个基础任务（字符串操作、词法变换、翻译、算术、逻辑、阅读理解）+ 38 个组合任务（机械链式操作，如 `gerund_upper`: run → RUNNING）
- **9 个模型**：OLMo-2（1B/7B/13B）、OLMo-3（7B）、LLM360 Crystal（7B 代码密集）和 Amber（7B NL 密集）、Pythia（410M/1.4B/12B）
- **检查点采样**：每个模型约 20 个检查点，覆盖前 1 万亿 tokens（约每 200 亿 tokens 一个）

### 涌现度量

- **绝对阈值**：首次超过固定准确率 θ 的检查点
- **相对阈值**：首次达到模型最佳表现 α 比例的检查点

### 表示相似性

通过函数向量（Function Vectors）量化技能之间的表示距离：
1. **注意力头基**：因果干预分析识别关键注意力头
2. **隐藏状态基**：残差流后的隐藏状态

用 RBF 核的核岭回归在函数向量空间上预测组合任务的训练轨迹（留一法交叉验证）。

![跨模型家族的涌现顺序](https://arxiv.org/html/2604.08510/x1.png)
*图：不同模型家族中技能涌现顺序（高斯平滑，σ=1.0）——顺序的高度一致性清晰可见*

## 实验结果

### 跨模型稳定性（H2）

45 个模型对中，Spearman ρ 在 **0.64–0.93** 之间，均值 **ρ=0.81**（θ=0.8），所有相关性在 p < 10⁻⁷ 显著。

**典型对比**：

| 模型对 | ρ |
|--------|---|
| OLMo2-7B ↔ OLMo2-13B | 0.93 |
| OLMo2-7B ↔ OLMo3-7B | 0.93 |
| Amber ↔ Crystal | 0.87 |
| OLMo2-1B ↔ Pythia-1.4B | 0.92 |
| OLMo2-13B ↔ Pythia-410M | 0.64（最低） |

即使在架构不同、数据组成不同（代码密集 vs 自然语言密集）的模型间，涌现顺序也高度一致。

![涌现顺序热图](https://arxiv.org/html/2604.08510/x2.png)
*图：技能涌现顺序热图（绝对阈值=0.8）——颜色越深表示越早涌现*

### 组合式排序（H1）

76 个组合任务中：
- **54 个**（71%）组合任务涌现时间晚于或等于其所有前置技能
- **19 个**弱违反（在一个前置技能后涌现，另一个稍早）
- **3 个**强违反（同时早于两个前置技能），均涉及 `first_letter`

**观测到的涌现顺序**：
```
复制 → 简单字符串操作（大小写）→ 词法变换（复数、时态）
  → 知识依赖任务（翻译）→ 逻辑操作 → 多步算术和复杂推理
```

### 轨迹预测（H3）

| 模型 | R²（全任务） | MAE | 
|------|------------|-----|
| Pythia-410M | 0.681 | 0.195 |
| OLMo2-1B | 0.723 | 0.070 |
| Pythia-1.4B | 0.778 | 0.086 |
| Amber (7B) | 0.751 | 0.082 |
| Crystal (7B) | 0.676 | 0.133 |
| OLMo2-7B | 0.767 | 0.068 |
| OLMo3-7B | 0.692 | 0.079 |
| Pythia-12B | 0.812 | 0.136 |
| **OLMo2-13B** | **0.838** | 0.099 |

关键发现：**仅使用基础任务表示**预测组合任务轨迹时，MAE 平均增大 0.135——说明存在"组合瓶颈"，组合任务的学习动态有其独特结构，不能被基础任务完全捕捉。

![组合任务轨迹预测示例](https://arxiv.org/html/2604.08510/x3.png)
*图：OLMo2-7B 上部分组合任务的预测轨迹（绿色）vs 实际轨迹（橙色）——预测与实际高度吻合*

### 预测精度示例

| 任务 | R² | MAE |
|------|----|-----|
| `fr_eng_upper`（法译英+大写） | 0.99 | 0.017 |
| `plural_lower`（复数+小写） | 0.89 | 0.028 |
| `eng_fr_upper`（英译法+大写） | 0.51 | 0.068 |

## 总结

本文提供了迄今最系统的 LLM 预训练内部学习动态研究。隐式课程假说的三个子假说均得到了强有力的实证支持：技能涌现跨模型高度一致、遵循依赖图顺序、且可从表示几何预测。这对于理解 LLM 能力的本质、设计更高效的预训练策略，以及构建可解释的评估框架都具有重要意义。

局限性：91 个任务均为人工构造的组合操作，不能直接推广到所有自然语言技能；仅研究了前 1T tokens 的训练，未涵盖更长训练阶段；相对阈值的一致性显著低于绝对阈值（均值 ρ=0.53 vs 0.81），说明"何时达到最佳性能的某比例"比"何时首次涌现"更难预测。
