## 一句话总结

本文系统研究了大语言模型在线策略蒸馏（On-Policy Distillation, OPD）的训练动态，揭示了 OPD 成功的两个必要条件、其内在机制，并提出了两种实用修复策略，同时指出了 OPD 在长轨迹任务中可能难以规模化的根本性挑战。

---

## 背景与问题

### 什么是在线策略蒸馏（OPD）？

大语言模型后训练领域中，知识蒸馏是将大型教师模型的能力迁移到小型学生模型的重要方法。传统的**离线策略蒸馏**（Off-Policy Distillation）直接使用教师模型生成的数据对学生进行监督微调，但会产生"暴露偏差"（exposure bias）——训练时学生看到的是教师的输出分布，推理时却需要对自己的分布做决策，两者不匹配。

**在线策略蒸馏（OPD）** 的核心思想是：让学生模型自己生成 rollout，然后利用教师模型的逐 token 对数概率作为密集奖励信号来优化学生。这相当于把教师的 token 级概率分布作为"软标签"，对学生的当前策略进行实时校正。

近期，Qwen3、MiMo、GLM-5 等重量级模型均已将 OPD 纳入其后训练流程，OPD 的重要性不言而喻。

*图1：论文整体框架——从现象学、机制到实践配方的三层次研究路径*

### 问题的核心困惑

尽管 OPD 已被广泛采用，它在实践中却**"理解匮乏、表现脆弱"**。最令人困惑的现象是：

> **更强的教师未必带来更好的学生。**

具体来说，基准测试得分更高的教师模型，有时反而完全无法提升学生的能力，而得分相对较低的教师却能显著改善学生表现。这一反直觉现象促使本文作者展开系统性研究。

## 现象学：OPD 成功的两个必要条件

作者以 Qwen3-1.7B-Base 作为学生模型，分别使用不同的教师进行 OPD，观察训练动态。

![两种教师的OPD实验结果](https://arxiv.org/html/2604.13016/x2.png)

*图2：将两种不同教师蒸馏到 Qwen3-1.7B-Base 的结果对比*

![两种教师的验证集表现](https://arxiv.org/html/2604.13016/x3.png)

*图3：两种教师在验证集上的性能表现*

### 条件一：思维模式兼容性（Thinking-Pattern Consistency）

实验发现，教师模型是否经过 **强化学习后训练（RL post-training）** 对 OPD 结果有决定性影响：

- 使用经过 GRPO 训练的教师（即具备 "thinking" 能力的教师）进行 OPD，学生显著受益；
- 使用未经 RL 训练的普通教师（non-thinking teacher）进行 OPD，学生几乎没有提升；

关键发现在于：**经过 RL 训练的教师，在训练初期就展现出更高的 token 重叠率（overlap ratio）**，尽管其基准分数可能略低。而思维模式不匹配导致的蒸馏损失，**无法在训练后期弥补**。

![有无RL后训练的教师对比](https://arxiv.org/html/2604.13016/x4.png)

*图4：使用有/无 RL 后训练的教师进行 OPD 的性能对比*

![Qwen家族不同模型的对比](https://arxiv.org/html/2604.13016/x5.png)

*图5：Qwen 家族不同模型的思维模式兼容性分析*

### 条件二：教师必须提供真正新颖的知识

仅仅基准分数更高，并不代表教师有真正"新"的知识可传授。实验表明：

- 来自**同一训练流水线**的教师（如 R1-Distill-7B vs R1-Distill-1.5B），即便参数量相差悬殊，OPD 效果提升也十分有限；
- 经过 **RL 后训练** 的教师，往往能产生实质性更高的**差距恢复率**（Gap Recovery Rate）：

$$\text{Gap Recovery Rate} = \frac{Acc_{after} - Acc_{before}}{Acc_{teacher} - Acc_{before}}$$

### 逆向蒸馏验证

为了验证上述结论，作者设计了一个优雅的反向实验：将 JustRL-1.5B（经 RL 训练的模型）蒸馏回其训练前的检查点（pre-RL checkpoint）。

结果：学生的性能**完全退回**到训练前水平。这有力地证明了 OPD 本质上是在学习**思维模式**，而非单纯的知识迁移。

此外，R1-Distill-7B 和 R1-Distill-1.5B 作为教师，产生了几乎**无法区分**的训练轨迹，再次说明：教师的基准分数不能预测 OPD 的效果。

![各benchmark上思维模式兼容性分解](https://arxiv.org/html/2604.13016/x17.png)

*图17：不同基准任务上思维模式兼容性的细粒度分析*

## 核心机制：高概率 Token 的渐进对齐

### 动态指标体系

为了细致刻画 OPD 训练过程，作者定义了三个关键动态指标：

1. **重叠率（Overlap Ratio）**：学生与教师 top-k token 集合的平均交叉比例，衡量策略重叠程度；
2. **重叠 Token 优势（Overlap-Token Advantage）**：在共享 token 集上的分布一致程度；
3. **熵差（Entropy Gap）**：$|H(q_t) - H(p_t)|$，衡量学生与教师在置信度上的差距。

### 成功与失败的 OPD 训练动态对比

![成功与失败的OPD训练动态](https://arxiv.org/html/2604.13016/x6.png)

*图6：成功的 OPD（上）与失败的 OPD（下）的训练动态对比*

成功的 OPD 表现出鲜明的动态特征：
- 重叠率从约 **72% 逐步上升至 91%**；
- 熵差持续缩小；
- 重叠 token 优势向 0 收敛（学生与教师在共享 token 上逐渐一致）。

而失败的 OPD 中，**三个指标从训练初始就停滞不前**，无法建立有效的优化动力。

### 重叠 Token 是真正的优化载体

作者进行了一个精彩的消融实验：将 top-k（k=16）OPD 拆解为三种变体：

| 变体 | 优化目标 | 性能 |
|------|---------|------|
| Student Top-k | 学生自身的 top-k | 完整基线 |
| **Overlap Top-k** | **仅重叠的 token** | **与完整基线持平** |
| Non-Overlap Top-k | 仅非重叠的 token | 显著更弱 |

![重叠与非重叠token的消融实验](https://arxiv.org/html/2604.13016/x7.png)

*图7：仅优化重叠 token vs. 非重叠 token 的消融实验*

核心发现：**单独优化重叠 token 足以复现完整 OPD 的性能**，而非重叠 token 几乎没有贡献。

更重要的是，这些重叠 token 集合在整个训练过程中集中了 **97%–99%** 的联合概率质量，尽管其数量只占词表的一小部分。这揭示了 OPD 的核心机制：

> OPD 的本质是学生在高概率共享 token 上向教师的**渐进对齐**，形成自我强化的动态循环——优化重叠 token 进一步扩大重叠集，从而持续驱动蒸馏进程。

## 实践配方：如何修复失败的 OPD

### 策略一：离线策略冷启动（Off-Policy Cold Start）

思路：在 OPD 之前，先用教师模型的 rollout 做一轮**监督微调（SFT）**，帮助学生建立初始的思维模式兼容性，再开始 OPD。

![离线策略冷启动效果](https://arxiv.org/html/2604.13016/x8.png)

*图8：离线策略冷启动对 OPD 的改善效果*

实验结果：
- Qwen3-1.7B-SFT（经冷启动）在整个训练过程中持续优于 Qwen3-1.7B-Base；
- 冷启动后的模型展现出更高的初始重叠率、更小的熵差、更平滑的训练轨迹。

### 策略二：教师对齐的提示词选择（Teacher-Aligned Prompt Selection）

**模板对齐**：将学生的提示词格式切换为与教师一致的格式，可以提升重叠率和最终精度。

![提示词模板对齐效果](https://arxiv.org/html/2604.13016/x9.png)

*图9：提示词模板对齐对 OPD 的影响*

**内容对齐**：使用与教师训练分布更接近的题目数据（如与教师训练数据一致的 DeepMath 子集，而非通用的 DAPO-Math-17K）：

![提示词内容对齐效果](https://arxiv.org/html/2604.13016/x10.png)

*图10：提示词内容对齐对 OPD 的影响*

- 教师对齐的提示词带来更强的性能、更高的概率质量集中度；
- 但代价是**学生熵显著降低**，存在策略坍塌（policy collapse）风险；
- 建议：**混合使用教师对齐提示词与分布外提示词**，在性能与多样性间取得平衡。

## 讨论：OPD 能否扩展到长轨迹任务？

### 奖励质量随轨迹深度退化

OPD 的密集奖励信号在短序列上效果显著，但当序列变长时会遇到根本性挑战。

![不同响应长度下的精度与教师延续实验](https://arxiv.org/html/2604.13016/x11.png)

*图11：不同最大响应长度下的精度及教师延续实验*

![不同最大响应长度下的训练动态](https://arxiv.org/html/2604.13016/x12.png)

*图12：不同最大响应长度下的 OPD 训练动态*

实验结果显示：
- **最优响应长度约为 3K–7K token**；
- 超过 10K–15K token：后期出现重叠率崩溃、熵尖峰、梯度范数尖峰；
- 不稳定性起源于**序列末端的 token**，并沿时间方向向前传播。

![不同解码位置下学生熵的变化](https://arxiv.org/html/2604.13016/x13.png)

*图13：在 15K 最大响应长度设置下，学生熵在不同解码位置的分布*

教师在正确预测上的优势（accuracy advantage）随前缀深度**单调递减**：
- 在 1K token 处：**+0.37**
- 在 16K token 处：仅 **+0.02**

这说明教师的逐 token 监督信号在长轨迹末端几乎不包含可利用的信息。

### 全局有用 ≠ 局部可利用

即使是"失败"的教师，其 rollout 在全局层面仍有区分价值（正确/错误 rollout 的 AUROC：JustRL-1.5B 为 0.73，R1-Distill-7B 为 0.75）。

![序列平均奖励的分布](https://arxiv.org/html/2604.13016/x14.png)

*图14：序列平均奖励的分布对比*

失败的根本原因可能在于：更大的教师模型产生了**各向异性的逐 token 优势**，这些优势在梯度聚合时相互抵消，导致整体信号无效。

### 采样 Token 奖励已经足够

![不同k值的Top-k OPD效果](https://arxiv.org/html/2604.13016/x15.png)

*图15：不同支持集大小 k 下 Top-k OPD 的性能*

![不同k值下的训练动态](https://arxiv.org/html/2604.13016/x16.png)

*图16：不同 k 值下的训练动态对比*

三种 OPD 变体的实际性能对比：
- **Sampled-Token OPD ≈ Top-k OPD（k≥4）**：性能相当；
- **Top-1（argmax）**：不稳定，存在模式坍塌风险；
- Sampled-Token OPD 通过按比例采样，在整个训练过程中对重叠 token 提供无偏覆盖。

实践意义：无需计算完整词表上的 KL 散度，采样 token 级别的奖励已经足够驱动有效的 OPD。

## 总结与启示

本文对在线策略蒸馏进行了迄今为止最系统的分析，核心贡献可概括为以下五点：

1. **成功的两个必要条件**：思维模式兼容性（教师需经 RL 后训练）+ 教师需提供真正新颖的知识（不能来自同一训练流水线）；

2. **核心机制揭示**：OPD 的所有增益均来自高概率共享 token 上的渐进对齐，形成自我强化的正反馈循环；

3. **失败的修复手段**：离线策略冷启动（SFT 预热）+ 教师对齐的提示词选择，可显著改善初始 token 重叠率，从而使原本失败的 OPD 恢复有效；

4. **长轨迹的根本瓶颈**：OPD 的密集 token 级奖励在长序列末端退化为接近随机的噪声，这可能是 OPD 难以扩展到 Agent 等长视野任务的深层原因；

5. **实践简化**：采样 Token OPD 在计算效率和性能之间取得最佳平衡，无需完整词表 KL 计算。

### 对未来研究的启示

- 研究者在选择 OPD 教师时，应优先关注**思维模式兼容性**，而非单纯追求更高的基准分数；
- 对于长轨迹蒸馏（如 agent、代码生成），需要探索新的奖励设计方式，不能简单地将 token 级 OPD 扩展到超长序列；
- 冷启动策略提示了一种实用的两阶段训练范式：SFT 建立思维模式 → OPD 精细对齐分布。
