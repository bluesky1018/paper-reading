> 📄 **论文**：Temporal Multi-Signal Fusion for Token-Level Hallucination Detection
> 🔗 **arXiv**：[2608.18115](https://arxiv.org/abs/2608.18115)
> 🏢 **机构**：独立研究者

## 一句话总结

将幻觉检测重新定义为**序列标注任务**，利用 33 维多信号特征（文本统计+NLI+语言模型困惑度）训练 BiGRU，在 RAGTruth 数据集上达到 AUC 0.840，比独立逐 token 基线高 11 个百分点，且无需访问模型内部。

## 背景与问题

大语言模型在 RAG（检索增强生成）场景中的幻觉检测是保障 AI 可靠性的关键技术。然而，现有方法普遍将幻觉检测视为**逐 token 独立评分**问题——对每个 token 独立判断是否属于幻觉，忽略了相邻 token 之间的强时序依赖关系。

论文通过信息论分析揭示了这一盲点的严重性：

- **转移概率**：P(幻觉_t | 幻觉_{t-1}) = **0.902**
- **转移比率**：幻觉状态持续概率 vs 从正常切换到幻觉概率 = **150:1**
- **可解析熵**：76% 的标签熵可由单步时序上下文预测

这意味着：**一个 token 是否是幻觉，与前一个 token 的状态高度相关**，幻觉往往在连续的 span 中出现，而非随机散布。

## 核心方法

### 33 维多信号特征

论文构建了一个**闭源模型友好**的特征集，不需要访问模型内部状态：

**文本统计特征（20 维）：**
- Token 出现频率、词汇丰富度
- n-gram 重叠度（与上下文）
- 句法依存深度、命名实体标记
- 标点和格式特征

**NLI（自然语言推断）特征（7 维）：**
- 当前 token 所在句子与检索文档的蕴含/中立/矛盾分数
- 局部 token 置信度对比
- 蕴含分数的 delta（相邻 token 间的变化）

**语言模型特征（6 维）：**
- 代理 LLM 的 token 困惑度
- 多模型集成的不一致度
- 对数概率及其差分

### BiGRU 序列标注

在此 33 维特征流上训练双向 GRU（BiGRU）进行序列标注，以类权重 BCE 损失处理类别不平衡。

BiGRU 的双向特性允许模型同时利用**前向**（当前幻觉 span 正在展开）和**后向**（当前 token 是否在幻觉 span 内）的时序信息。

## 实验结果

### 主要消融结果（RAGTruth 数据集）

| 模型 | 文本特征 AUC | 全特征 AUC | F1 |
|------|-----------|---------|-----|
| 逻辑回归（基线）| 0.702 | 0.730 | 0.141 |
| 1D-CNN | 0.788 | 0.807 | 0.216 |
| BiLSTM | 0.826 | 0.843 | 0.247 |
| **BiGRU** | **0.832** | **0.845** | **0.242** |
| Transformer | 0.802 | 0.804 | 0.229 |

### 多种子稳定性（10 个随机种子）

| 模型 | AUC | F1 |
|------|-----|-----|
| **BiGRU** | **0.840 ± 0.007** | 0.257 ± 0.010 |
| 参数量匹配 MLP | 0.765 ± 0.002 | — |

MLP 仅弥合了 BiGRU vs 逻辑回归差距的 **32%**，说明提升主要来自时序建模而非模型容量。

### 时序优势分解（核心图）

| 来源 | AUC | 增益占比 |
|------|-----|---------|
| 逻辑回归（独立评分）| 0.730 | — |
| + 非线性容量（MLP）| 0.765 | 32% |
| + 序列聚合（打乱 BiGRU）| 0.791 | 24% |
| + **时序顺序（BiGRU）** | **0.840** | **44%** |

时序顺序本身贡献了 **44%** 的总增益，是三个来源中最大的单一贡献因素。

## 总结

本文的核心贡献是将"幻觉检测的时序依赖性"从直觉提升为理论支撑（信息论分析）和实证验证（详细消融实验）的系统性结论。33 维特征 + BiGRU 的方案在不需要访问模型权重的前提下，达到了接近使用内部状态方法的性能水平，具有重要的实用价值——尤其适用于对闭源商业 LLM 输出的可靠性审计。

局限性在于：当前评估局限于 RAGTruth 和 PsiloQA 数据集，长文本（>500 token）下 AUC 有所下降；此外，中文等非英文语言的幻觉检测性能尚未验证。未来方向包括：特征集扩展（如引入实体链接信号）和在线流式幻觉检测（实时 token 级监控）。
