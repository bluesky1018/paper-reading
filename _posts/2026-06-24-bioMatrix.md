> 📄 **论文**：BioMatrix: Towards a Comprehensive Biological Foundation Model Spanning the Modality Matrix of Sequences, Structures, and Language
> 🔗 **arXiv**：[2606.22138](https://arxiv.org/abs/2606.22138)
> 🏢 **机构**：Microsoft Research、北京大学等

## 一句话总结

BioMatrix 是首个在单一解码器架构中原生集成分子序列（SMILES/SELFIES）、分子结构、蛋白质序列、蛋白质结构和自然语言的多模态生物学基础模型，通过统一 token 化方案实现跨模态无缝生成与理解。

## 背景与问题

生物学研究涵盖多类实体（小分子、蛋白质等）和多种模态（序列、结构、语言），现有生物学基础模型面临以下局限：

1. **多模态与多实体覆盖割裂**：融合多模态的模型局限于单一实体类型（如仅蛋白质或仅分子）；覆盖多种实体类型的模型要么缺乏显式结构建模，要么依赖 Adapter 设计——在 Adapter 设计中，**模型无法原生生成它能读取的模态**

2. **无法统一生成**：现有模型通常需要针对不同模态配置不同的输出头，缺乏真正意义上的统一多模态生成能力

3. **跨模态知识整合不足**：分子-蛋白质相互作用、蛋白质-蛋白质相互作用等跨实体知识难以在单一模型中系统学习

## 核心方法

### 统一 Token 化方案

BioMatrix 的核心创新是**统一离散 token 空间**——将以下所有模态映射到共享离散 token 空间：

- **分子序列**：支持 SMILES 和 SELFIES 两种表示
- **分子结构**：3D 构型的离散化表示
- **蛋白质序列**：氨基酸序列
- **蛋白质结构**：3D 蛋白质构型的离散化表示
- **自然语言**：科学文献和注释文本

所有模态在**统一的下一 token 预测目标**下进行训练，无需外部编码器、投影 Adapter 或模态专用输出头——同一个模型既能读取，也能原生生成这些模态。

### 模型架构

基于 **Qwen3 语言模型**（1.7B 和 4B 参数），BioMatrix 进行持续预训练：

**预训练数据规模：304.4B token**，涵盖：
- 通用文本和领域专用文本
- 分子和蛋白质的序列与结构视图
- 跨模态语料（生物分子实体与科学文本交错）
- 分子-蛋白质和蛋白质-蛋白质相互作用数据

### 覆盖的"模态矩阵"

|  | 序列 | 结构 | 语言 |
|:---:|:---:|:---:|:---:|
| **小分子** | ✓（SMILES/SELFIES） | ✓ | ✓ |
| **蛋白质** | ✓ | ✓ | ✓ |

BioMatrix 是首个完整覆盖这 6 个"模态矩阵"单元的统一模型。

## 实验结果

BioMatrix 在多个下游任务上经过综合套件的精调验证：

### 分子任务
- **分子性质预测**：优于现有纯分子基础模型
- **逆合成预测**：在化学反应预测中表现强劲
- **分子描述生成**：高质量的分子-文本转化

### 蛋白质任务
- **蛋白质功能预测**：与蛋白质专用模型竞争
- **蛋白质-配体相互作用预测**：受益于跨模态训练

### 跨模态任务
- **分子-蛋白质相互作用**：统一架构在此类任务上展现独特优势
- **科学问答**：自然语言与生物实体的联合推理

## 总结

BioMatrix 通过统一 token 化和单一解码器架构，真正实现了跨越序列、结构和语言三种模态的多实体生物学理解与生成。这一设计消除了现有模型在"能读取 ≠ 能生成"上的根本矛盾，为药物发现、蛋白质工程等应用场景提供了更统一的基础能力。

局限性方面，304.4B token 的预训练数据量虽然可观，但与通用大语言模型相比仍相对有限。此外，3D 结构的离散化表示是否能保留足够的几何精度，在精细结构预测任务上仍有提升空间。
