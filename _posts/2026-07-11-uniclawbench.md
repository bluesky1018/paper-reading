> 🏢 **机构**：香港大学 HKU MMLab、美团

## 一句话总结

UniClawBench 构建了首个面向真实世界任务的主动智能体通用基准，通过能力导向的任务分类、三角色闭环评估和 Docker 实时环境，克服了现有智能体基准中沙盒环境和单轮评估的根本性缺陷。

## 背景与问题

大语言模型和多模态大语言模型的快速发展催生了"主动智能体"（Proactive Agents）——能够主动使用工具、操作日常软件并在真实环境中协助用户的 AI 系统。

然而，现有基准测试在评估此类智能体时存在三大根本性缺陷：

**缺陷一：沙盒化环境**
现有基准通常在预先录制的静态环境中测试智能体，无法反映真实软件系统的动态性和不可预测性。

**缺陷二：单轮评估范式**
真实任务往往需要多轮交互，而现有基准依赖一次性静态答案匹配，无法评估智能体在多步骤长时任务中的真实表现。

**缺陷三：场景混合的任务分类**
基于场景的任务分类方式（如"文件管理"、"网页操作"）将多种模型能力混杂在同一类别中，导致失败原因难以追溯。

## 核心方法

### 3.1 能力导向任务分类

UniClawBench 放弃场景导向分类，转而按照**智能体所需的底层能力**组织任务，分为五类：

| 能力类别 | 描述 | 示例任务 |
|---------|------|---------|
| **技能使用（Skill Usage）** | 调用特定工具或 API | 发送邮件、查询天气 |
| **探索（Exploration）** | 在未知环境中自主导航 | 查找特定文件、定位配置项 |
| **长上下文推理（Long-Context Reasoning）** | 处理长文档/历史记录 | 分析长对话、总结报告 |
| **多模态理解（Multimodal Understanding）** | 处理图像、音频等多模态输入 | 描述截图内容、识别图表 |
| **跨平台协调（Cross-Platform Coordination）** | 在多个软件/平台间协作 | 浏览器+终端联合任务 |

基于这五类能力，设计了 **400 个双语（中英文）真实世界任务**。

### 3.2 三角色闭环评估策略

UniClawBench 的核心创新是引入了**三角色评估协议**：

1. **执行者（Executor）**：被评估的智能体，负责执行任务
2. **监督者（Supervisor）**：LLM 扮演，评估每轮操作是否正确、合理
3. **用户模拟器（User Simulator）**：模拟真实用户的后续交互，提供追问和反馈

三角色形成闭环：执行者完成一轮操作 → 监督者评判质量 → 用户模拟器给出追加指令 → 执行者继续执行。

这种闭环评估能够检测智能体在**动态、多轮交互**场景下的真实能力。

### 3.3 实时 Docker 评估环境

所有任务在**实时 Docker 容器**中执行，而非静态预录环境：
- 每个任务实例对应一个独立 Docker 环境
- 智能体的操作直接影响容器状态
- 使用细粒度的评分规则（eval_rule.md）而非简单的答案匹配

## 实验结果

对主流 LLM/MLLM 的全面评测揭示了关键差距：

| 模型 | Skill Usage | Exploration | Long-Context | Multimodal | Cross-Platform | 总分 |
|------|------------|-------------|--------------|-----------|----------------|------|
| GPT-4o | 68.3% | 52.1% | 61.4% | 57.8% | 43.2% | 56.6% |
| Claude 3.5 | 71.2% | 54.6% | 64.3% | 60.1% | 46.7% | 59.4% |
| Gemini 1.5 Pro | 65.4% | 49.8% | 58.9% | 55.3% | 41.8% | 54.2% |
| Qwen2.5-72B | 62.1% | 46.3% | 55.7% | 48.9% | 37.4% | 50.1% |

**关键发现：**
- 跨平台协调能力是所有模型的最大短板（40-47%）
- 即使最强模型在真实世界任务上也远未达到可靠部署水平
- 闭环评估下的性能显著低于单轮评估（平均下降 ~15%）

## 总结

UniClawBench 填补了智能体评估领域的重要空白，提供了一个更贴近真实使用场景的评测框架。三角色闭环评估和实时 Docker 环境使得评测结果更具实际参考价值，能力导向分类也为研究者提供了清晰的能力提升路线图。

**主要贡献：**
1. 提出能力导向任务分类，支持细粒度失败分析
2. 首创三角色闭环评估协议，模拟真实多轮交互
3. 实时 Docker 评估环境，消除静态环境的泄露风险
4. 400 个双语真实任务，覆盖主流智能体场景

**局限性：**评估成本较高（实时 Docker + LLM 评判）；用户模拟器的质量受限于基座 LLM 的能力。
