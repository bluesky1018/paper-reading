## 一句话总结

本文提出混合深度注意力机制（MoDA），通过让每个注意力头同时关注当前层的序列 KV 对和前序层的深度 KV 对，以数据依赖的方式解决深层大语言模型中的信息稀释问题，在 1.5B 参数规模下以仅 3.7% 的 FLOPs 额外开销实现平均下游任务性能提升 2.11%。

---

## 背景与问题

### 深度扩展的挑战

大语言模型（LLMs）的进步主要由四个维度驱动：上下文长度、训练数据、模型宽度和模型深度。其中，深度扩展具有强大的表示能力——更深的网络支持更丰富的层次化计算。然而，现代 Transformer 往往无法将增加的层数转化为相应的性能提升，主要面临两大问题：

1. **优化困难（Optimization Problem）**：随着网络加深，梯度消失和训练不稳定问题日益突出。
2. **信息稀释（Information Dilution）**：浅层形成的信息性特征在经过多次残差更新后逐渐被稀释，在深层变得难以恢复。

### 现有方案的局限

**标准残差连接（Depth Residual，ResNet-style）** 虽然缓解了梯度消失问题，但仍将深度历史压缩为单一的隐藏状态轨迹，导致信息稀释问题未能根本解决。

**密集跨层连接（Depth Dense，DenseNet-style）** 保留了丰富的逐层历史信息，可无损地传播信息，但其参数量呈 $O(L^2 D^2)$ 增长，计算开销在 LLM 规模下完全不可接受。

本文的核心动机在于：注意力机制在序列建模中的成功揭示了一个更广泛的原则——数据依赖的动态混合可以比固定模式的聚合更有效地保存和检索历史信息。能否将同样的原则从序列维度扩展到深度维度？

## 核心方法

### 从"读-操作-写"视角统一分析深度传播机制

本文以"读（read）、操作（operate）、写（write）"三步骤框架来描述 Transformer 块在深度维度上的不同连接机制：

![MoDA总体架构](https://arxiv.org/html/2603.15619/x1.png)
*图1：MoDA 与标准因果序列注意力的对比。MoDA 在标准序列注意力的基础上，额外允许 query 关注深度记忆（depth memories），即来自前序层相同 query 位置的深度 KV 对 $\{K_i, V_i\}_{i=0}^{l-1}$。*

![训练损失与下游性能对比](https://arxiv.org/html/2603.15619/x2.png)
*图2：MoDA 与强开源基线 OLMo2 在 1.5B 参数设置下的 validation loss 和下游任务性能对比。MoDA 模型在 C4 验证损失和 HellaSwag、WinoGrande、ARC-Challenge 等下游任务上均优于 OLMo2。*

### 三种深度流机制的设计空间

![深度流机制概念对比](https://arxiv.org/html/2603.15619/x3.png)
*图3：深度流机制的概念对比。(a) Depth Residual：标准残差连接；(b) Depth Dense：密集跨层连接，通过线性投影读取所有历史表示并沿深度维度拼接；(c) Depth Attention：中间形式，使用注意力以数据依赖方式读取历史深度 KV 对；(d) MoDA（本文方法）：将深度注意力与标准序列注意力融合为一个统一算子。*

#### Depth Residual（深度残差）

$$X_l = X_0 + \sum_{i=1}^{l-1} \mathcal{F}(X_i, \mathcal{W}_i)$$

- **优点**：缓解梯度消失，训练稳定
- **缺点**：深度历史被压缩为固定大小的张量，导致信息稀释

#### Depth Dense（深度密集连接）

$$\{X_i\}_{i=0}^l = \{X_0, \mathcal{F}(\{X_0\}, \mathcal{W}_1), \mathcal{F}(\{X_0, X_1\}, \mathcal{W}_2), \cdots\}$$

- **优点**：无损传播，完整保留历史信息
- **缺点**：参数量 $O(L^2 D^2)$，计算量 $O(TL^2 D^2)$，LLM 规模下完全不可行

#### Depth Attention（深度注意力，过渡形式）

$$X_l^{\text{in}} = \text{Attention}(Q_{l-1}, \{K_i\}_{i=0}^{l-1}, \{V_i\}_{i=0}^{l-1})$$

在深度维度上执行注意力操作：对于 token $t$，query $Q_{l-1,t}$ 仅关注来自相同 token 位置跨层的深度 KV 对 $\{K_{i,t}, V_{i,t}\}_{i=0}^{l-1}$。相比 Depth Dense，计算量从 $O(TL^2 D^2)$ 降至 $O(TL^2 D)$（降低 $1/D$ 倍）。

### MoDA：混合深度注意力（核心贡献）

MoDA 在 Depth Attention 基础上，将深度注意力与标准序列注意力融合为**单一统一算子**，通过**单个 softmax** 同时规范化序列和深度的注意力分数。

关键设计：
- 每个注意力头同时关注当前层的**序列 KV 对**和前序层的**深度 KV 对**
- 所有注意力分数在**同一 softmax** 下归一化，提供统一的表示空间
- 在"写"步骤，将当前层的 KV 对追加到深度流中，供后续层访问
- 对于 FFN 层，通过轻量级 KV 投影获得对应的深度 KV 对

**复杂度优势**：MoDA 复用序列注意力的 query 投影，不引入额外的深度 query 投影。在 GQA 设置下，仅需要分组的深度 key/value 投影，参数复杂度从 $O(LD^2)$ 进一步降至 $O(LD^2/G)$，是表1中最参数高效的方案。

**复杂度对比表（Table 1）**：

| 方法 | 数据依赖 | 统一Softmax | 参数量 | 解码Cache | 预填充FLOPs |
|------|---------|------------|--------|----------|------------|
| Depth Dense | ✗ | ✗ | $O(L^2D^2)$ | $O(LD)$ | $O(TL^2D^2)$ |
| Depth Attention | ✓ | ✗ | $O(LD^2)$ | $O(LD/G)$ | $O(TL^2D)$ |
| **MoDA（本文）** | ✓ | ✓ | $O(LD^2/G)$ | $O(LD/G)$ | $O(TL^2D)$ |

## 硬件高效的 MoDA 实现

朴素的 PyTorch 实现 MoDA 需要对历史深度状态进行非连续读取，严重降低 GPU 利用率。本文开发了一套硬件感知实现方案，通过三项关键技术显著提升效率：

### 技术1：Flash-Compatible 深度 KV 布局

将深度 cache 沿单轴展平，长度为 $T \times L$。对于每个序列位置 $t$，其 $L$ 个深度状态被连续存储，每个 query 只需映射到对应的深度范围 $[tL, (t+1)L)$，将深度查找转化为连续块读取，与 FlashAttention 风格的 kernel 兼容。

### 技术2：Chunk-Aware 深度 KV 布局

![硬件视角：深度Cache访问模式](https://arxiv.org/html/2603.15619/x4.png)
*图4：MoDA 深度 cache 访问的硬件视角。左图：Flash-compatible MoDA 每个 query 需要扫描长度 $T \times L$ 的深度 KV；右图：Chunk-aware MoDA 将 query 按 chunk 大小 $C$ 分组，深度 KV 按 chunk 重组，有效深度跨度从 $T \times L$ 减少到 $(C \times L)/G$，显著减少内存访问开销。*

将 query 按 chunk 大小 $C$ 划分，每个 chunk 只访问其对应的深度 KV 范围，将深度利用率从 $\eta_{\text{depth}} = 1/T$ 提升至 $1/C$。

### 技术3：Group-Aware 深度 KV 计算

关键观察：在 $T_q = G \cdot T_{kv}$ 的映射下，$G$ 个相邻 query 行共享相同的 base-time 索引 $\lfloor i_q/G \rfloor$，可以复用相同的深度 KV 块。对于长度为 $C$ 的 query chunk，只有 $C/G$ 个唯一的 base-time 行，所需深度跨度从 $C \times L$ 减少到 $(C/G) \times L$，有效深度利用率提升至 $G/C$。

### 效率消融实验（Table 7）

| 方案 | Naive Torch | Flash-Compatible | Chunk-Aware | Group-Aware | 时间(ms) |
|------|------------|-----------------|------------|-------------|---------|
| (1) | ✓ | | | | 2128.900 |
| (2) | | ✓ | | | 13.102 |
| (3) | | ✓ | ✓ | | 6.286 |
| (4) | | ✓ | ✓ | ✓ | **1.460** |

三项优化组合实现约 **1458倍** 端到端加速，在序列长度 64K 时达到 FlashAttention-2 **97.3%** 的效率。

## 深度讨论

### 工业级训练扩展

当前硬件高效的 MoDA kernel 已与 FlashAttention-2 达到竞争性效率，但对于万亿参数级工业生产运行，仍需进一步的 CUDA 工程优化，包括改进内存调度、更深的计算流水线以及 fused attention kernel 与分布式通信的更紧密重叠。

### 缓解内存瓶颈的有界深度 KV 槽缓存

随着网络加深，缓存所有历史层的深度 KV 状态会引入显著的内存和带宽开销，与深度呈线性增长。一个实用方向是使用固定大小的**深度 KV 槽缓冲区**（bounded depth-KV slot buffer）：
- **动态选择策略**：对候选深度 KV 条目按效用打分，保留 top-S 条目
- **滑动窗口策略**：保留最近的深度 KV 条目，淘汰旧条目
- **混合设计**：部分槽位保留近期条目，其余用于高分全局记忆

## 总结

本文提出的 MoDA（Mixture-of-Depths Attention）从根本上重新审视了深层 Transformer 中信息传播的方式。通过将深度维度的注意力与序列维度的注意力融合为统一算子，MoDA 以数据依赖的方式缓解了信息稀释问题，同时保持了参数效率。

核心贡献总结：
1. **方法层面**：提出 MoDA 统一注意力公式，支持序列和深度的动态混合，在设计空间中占据效率-表达力的最优平衡点
2. **工程层面**：开发硬件高效的融合 kernel，集成统一 online-softmax 状态、chunk-aware 深度 KV 布局和 group-aware 索引，实现约 1458 倍加速，并在 64K 序列长度下达到 FlashAttention-2 97.3% 的效率
3. **实验层面**：在 700M 和 1.5B 规模的广泛实验中，MoDA 以仅 3.7% 的 FLOPs 额外开销，在 10 个验证基准上平均困惑度提升 0.2，在 10 个下游任务上平均性能提升 2.11%

MoDA 的核心洞察——历史深度信息可以作为标准序列注意力的互补检索通道——不仅适用于语言建模，还可扩展至多模态智能、视觉理解和世界模型等领域，为 Transformer 的深度扩展提供了一个有原则、可实用的新基础。
