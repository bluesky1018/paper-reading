## 基本信息

- **作者**: Albert Gu, Tri Dao
- **类型**: 开源代码仓(Apache 2.0)
- **仓库**: [state-spaces/mamba](https://github.com/state-spaces/mamba)
- **论文**: [2312.00752](https://arxiv.org/abs/2312.00752)(Mamba)· [2405.21060](https://arxiv.org/abs/2405.21060)(Mamba-2 / SSD)

## 一句话总结

Mamba 作者亲自维护的**官方实现**,包含:
1. **Selective Scan CUDA kernel**(Mamba 最关键的 hardware-aware 算法)
2. **Mamba-2 的 SSD 实现**(把 SSM 与线性 attention 统一到一个 matmul 家族)
3. **预训练模型权重**(130M / 370M / 790M / 1.4B / 2.8B)
4. **示例训练脚本 + LM Eval 集成**

如果你要做任何与 Mamba 相关的工作——复现实验、魔改递推规则、对比 benchmark、做 hybrid 架构——**这是唯一真正 reference-grade 的实现起点**。

## 仓库组成

- `mamba_ssm/` —— 模型层与 kernel 绑定
  - `modules/mamba_simple.py` —— 可读性最好的 Mamba block
  - `modules/ssd_minimal.py` —— SSD(Mamba-2)最小实现
  - `ops/selective_scan_interface.py` —— Selective Scan Python wrapper
  - `ops/triton/` —— Triton 版本的 SSD kernel
  - `csrc/selective_scan/` —— 原始 CUDA kernel 源码
- `benchmarks/` —— 训练/推理 benchmark 脚本
- `evals/` —— LM Eval Harness 集成

## 对研究者最有价值的几个文件

| 文件 | 看什么 |
|------|-------|
| `modules/mamba_simple.py` | 理清 Mamba block 的前向:in_proj → Conv1d → Selective SSM → 门控 → out_proj |
| `modules/ssd_minimal.py` | 在 50 行内看完 Mamba-2 的 chunkwise SSD 算法 |
| `ops/selective_scan_interface.py` | 理解为何"forward 只保存 Δ, A_log, B, C,反向重算"的训练配方 |
| `csrc/selective_scan/` | 真正想深入到 CUDA 层面的读者的终极参考 |

## 使用场景

- **复现 Mamba 论文表格**:clone + 下载权重 + `evals/lm_eval_harness/run.sh` 即可
- **训练自己的 Mamba**:基于 `benchmarks/benchmark_generation_mamba_simple.py` 改训练脚本
- **魔改 Selective Scan**:在 `csrc/selective_scan/` 里改 CUDA,或者在 `ops/triton/` 里改 Triton kernel(后者改起来友好得多)
- **Hybrid 架构**:把 Mamba block 当作层插入自己的 Transformer 模型,用 fla 提到的方式做 attention-SSM 混搭

## 与 flash-linear-attention 的分工

| 仓库 | 定位 | 适合 |
|------|------|------|
| `state-spaces/mamba` | 原作者官方 + CUDA kernel 最快 | 复现论文、高性能训练 |
| `fla-org/flash-linear-attention` | 多种线性 attention 变体统一 | 做跨架构消融、换架构研究 |

实际项目里**两个仓库都会装**:用 fla 做研究,用 state-spaces/mamba 做生产级跑 Mamba 的时候当备份 kernel。

## 安装注意事项

- 需要预编译 CUDA kernel(`pip install mamba-ssm`),对 CUDA/PyTorch 版本有较强耦合
- 若编译失败,可以用 `mamba_ssm --no-build-isolation` 或走 Triton 版 SSD
- Windows 原生不支持;WSL2 / Linux / Mac(仅 CPU 调试)可用
