## 一句话总结

KVM（Key-Value Means）提出了一种新颖的块递归注意力机制，通过动态压缩溢出 token 并支持可增长状态，实现了线性 RNN 的内存效率与全注意力长上下文召回能力的统一。

## 背景与问题

Transformer 在现代硬件上高效运行，但其 KV 缓存随上下文长度线性增长，导致内存和每个输出 token 的计算时间均呈线性扩展。现代线性 RNN（LRNN）仅需常数内存和固定计算，但受限于固定状态大小，在长上下文场景下的记忆召回能力有限。

**现有方案的局限**：固定状态架构（如块递归 Transformer、TransformerFAM、RWKV-7 等）具有固定的内存上界，难以处理超长序列；可扩展状态架构（如 Compressive Transformer）压缩方式较为粗糙，质量有损；全注意力虽然精确，但计算和内存成本为 O(N²)，难以扩展至极长上下文。

| 架构 | 状态大小 | 预填充时间 | 解码时间 | 召回能力 | 并行预填充 |
|------|---------|---------|---------|---------|---------|
| Linear RNN | O(1) | O(N) | O(1) | 有限 | 分块 |
| KVM (固定) | O(1) | O(N) | O(1) | 有限 | 分块 |
| **KVM (√N)** | **O(√N)** | **O(N^1.5)** | **O(√N)** | **强** | **分块** |
| Full Attention | O(N) | O(N²) | O(N) | 精确 | 完全 |

## 核心方法

### KVM 架构设计

KVM 采用**块滑动窗口注意力（BSWA）**框架，将压缩后的状态（类似 KV 缓存形状）与当前窗口 token 一同参与注意力计算。当一个块从窗口溢出时，触发压缩递归，将溢出块的信息融合进状态。

**状态压缩策略**：通过计算溢出 key 与状态 key 之间的注意力矩阵，确定每个溢出 key 应压缩入哪个状态 key 的比例。在大量实验后，论文选择了类似 winner-take-all 的余弦相似度归并规则（即对每行最大 logit 取 1.0，其余取 0），这与 OVQ 的设计相似，但有多项改进：
- **即时归一化（JIT norm）**：避免状态向量随时间收缩，在注意力前对状态 key 进行重归一化
- **值归一化**：存储每个状态值的初始范数，并以此为基准进行 JIT 归一化，允许不同状态行保持各自的归一化半径
- **sink token 保留**：识别并保留 sink token（Guo et al., 2024），避免注意力分配失衡

### 状态初始化与扩展

KVM 采用基于**信息新颖度**的状态扩展策略：
- 当首次创建状态时，溢出 token 直接初始化状态
- 后续溢出 token 中，"最令人惊讶"（与现有状态相似度最低）的 token 被追加到状态中
- 其余溢出 token 则归并入新扩展的状态

这一机制使得状态大小随序列长度呈亚线性增长（实验中配置为 O(√N)），而非无限增长。

### 位置编码处理

由于压缩状态中的 key 可能来自序列中位置各异的溢出窗口，论文提出了**部分 RoPE 方案**：对前 p 个维度施加 RoPE，对剩余维度不加位置编码（NoPE），使模型在既需要位置信息又需要位置无关性的混合场景中保持良好表现。

## 实验结果

论文在 RULER 和 LongBench 两个长上下文基准上进行了评测，并通过消融研究验证了各设计选择的重要性。

### 核心性能

- **固定大小 KVM**：与全注意力 Transformer 基线相比，仅增加极少量新参数，在 O(N) 预填充时间下形成了强大的分块 RNN
- **可增长 KVM（√N 状态）**：在次二次方预填充时间和亚线性状态增长下，在长上下文测试中取得具有竞争力的性能
- **关键消融发现**：
  - Winner-take-all 归并规则显著优于 softmax 归并
  - JIT 归一化对性能至关重要
  - 运行均值优于指数移动平均（EMA）
  - 加权溢出 token 对性能有重要影响

### 短上下文性能

KVM 模型在标准短上下文评测（如 GPTAlpha-2 Transformer 基线）上保持了与基础 Transformer 相当的性能，证明了该方法不以牺牲短上下文能力为代价。

## 总结

KVM 提出了一种优雅的长上下文解决方案，通过将 BSWA 与动态可扩展的压缩状态相结合，在线性 RNN 的效率和全注意力的长上下文召回能力之间实现了可调节的权衡。其无需自定义内核、支持分块并行训练和预填充的特性，使其具有良好的工程实用性。

局限性方面，当前状态扩展使用固定调度（而非自适应阈值），后续工作可探索学习型阈值策略；此外，KVM 目前在中小规模模型（GPTAlpha-2 架构）上验证，其在更大规模模型和实际生产部署中的效果有待进一步证明。
