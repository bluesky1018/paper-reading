## 一句话总结

GeoSR 发现并解决了"几何注入失效"问题——VLM 倾向于忽略注入的3D几何 token 而依赖2D外观捷径，通过几何解放掩码（Geometry-Unleashing Masking）和几何引导融合（Geometry-Guided Fusion）两项机制，在动态空间推理基准 DSR-Bench 上将性能从 58.9 提升到 66.1。

## 背景与问题

视觉语言模型（VLMs）虽然在通用视觉语言任务上表现强劲，但在空间推理上存在明显短板——难以精确判断物体距离、方向、尺寸等空间关系。一种直观的改进思路是将预训练3D模型产生的几何 token（如深度图、点云）注入 VLM，为其提供3D空间信息。

然而，本文揭示了一个关键问题：**几何注入往往无效，甚至有害**。VLM 倾向于走"2D外观捷径"，将注入的几何 token 视为可有可无的辅助信号，仍然主要依赖 2D 视觉特征进行推理。在静态场景中，这导致几何注入的收益极为有限；在动态场景中，情况更糟——几何注入反而会**降低**模型性能（图1实验验证）。

这一问题的根本原因是：VLM 的预训练过程使其形成了强烈的"依赖2D特征"的习惯，即便几何 token 提供了更准确的空间信息，模型也不会主动"学会"使用它们。因此，需要在训练阶段强制模型去依赖几何信息。

## 核心方法

### 几何感知框架（基线）

给定视频帧序列和文本提示，框架分三路产生特征：
- **视觉 token** $F_V$：来自 VLM 视觉编码器
- **文本 token** $F_P$：来自文本编码器
- **几何 token** $F_G$：来自冻结的预训练3D模型

![几何感知基线框架](https://arxiv.org/html/2603.26639/x3.png)
*图2：几何感知基线框架概览，展示视觉/文本/几何三路特征的融合方式*

静态场景使用加法融合（Additive Fusion），动态场景使用 QFormer 融合（瓶颈 token 先查询文本，再查询几何 token）。这两种融合方式均面临"几何信息被忽视"的问题。

### GeoSR 的两大核心组件

![GeoSR 方法总览](https://arxiv.org/html/2603.26639/x4.png)
*图3：GeoSR 方法总览，左侧为几何解放掩码，右侧为几何引导融合*

#### 组件一：几何解放掩码（Geometry-Unleashing Masking）

核心思想：**在训练时主动遮盖视觉 token，迫使模型向几何 token 寻求信息**。

- **静态场景**：随机 MAE 风格掩码，掩码率 γ=0.8，以概率 β=0.5 启用（防止过度依赖几何）
- **动态场景**：更精细的有针对性掩码——利用 QFormer 交叉注意力权重计算"几何相关性分数"，优先掩码对问题最相关的几何 token 位置，强制模型从几何信息中提取答案所需的空间线索

相关性分数 $s$ 通过对多头注意力概率和瓶颈 token 维度求平均并归一化得到，实现与问题内容自适应的掩码策略。

#### 组件二：几何引导融合（Geometry-Guided Fusion）

核心思想：**引入可学习门控，让几何信息在需要的位置获得更大权重**。

学习门控 $\alpha \in (0,1)$：

$$\alpha = \sigma(W_g[\text{LN}_v(\tilde{F}_V) \| \text{LN}_g(\tilde{F}_G)] + b_g)$$

$$F = \alpha \odot V + (1-\alpha) \odot G$$

- $\alpha$ 接近1时：更多依赖视觉特征（外观主导区域）
- $\alpha$ 接近0时：更多依赖几何特征（需要精确空间信息的区域）

动态场景中，QFormer 产生的紧凑几何证据通过 CrossAttn 重新分配到细粒度几何特征图，再参与门控融合。

### 实现细节

- **主干 VLM**：Qwen2.5-VL-7B
- **静态3D模型**：VGGT；**动态3D模型**：π³
- **训练数据**：SPAR-7M + LLaVA-Hound（静态）；DSR-Train（动态）
- **硬件**：4× H200 GPU，静态训练约14小时，动态训练约20小时

## 实验结果

### 静态空间推理（VSI-Bench）

| 模型 | 平均分 |
|------|--------|
| GPT-4o | 47.8 |
| Gemini-1.5-Pro | 48.8 |
| Spatial-MLLM | 48.4 |
| VG-LLM | 50.7 |
| **GeoSR（本文）** | **51.9** |

### 动态空间推理（DSR-Bench）

| 模型 | 平均分 |
|------|--------|
| GPT-5 | 30.8 |
| Gemini-2.5-Pro | 31.7 |
| GSM（此前SOTA） | 58.9 |
| **GeoSR（本文）** | **66.1** |

GeoSR 在动态场景每个子任务上均大幅超越 GSM：绝对方向（84.4 vs 73.8）、相对距离（83.0 vs 76.1）、相对方向（83.8 vs 77.7）、相对朝向（76.5 vs 60.6）。

### 消融实验

| 配置 | VSI-Bench | DSR-Bench |
|------|-----------|-----------|
| (a) GeoSR 完整版 | **51.9** | **66.1** |
| (b) 替换为朴素融合 | 51.2 | 65.0 |
| (c) 无几何引导融合 + 掩码 | 50.8 | 64.3 |
| (d) 无掩码 + 几何引导融合 | 51.5 | 64.8 |
| (e) 朴素几何注入（基线） | 50.4 | 57.8 |
| (f) 无几何信息 | 50.1 | **58.5** |

关键发现：配置 (f) 无几何 vs. (e) 朴素注入 的对比完美验证了论文动机——在动态场景上，**不加入几何信息（58.5）反而优于朴素几何注入（57.8）**，再次证明未经处理的几何注入确实有害。

## 总结

GeoSR 的核心贡献是识别并解决了"几何注入失效"这一系统性问题。通过两个互补的机制——训练阶段的几何解放掩码（让模型学会依赖几何）和推理阶段的几何引导融合（让模型知道何时依赖几何），GeoSR 实现了几何信息的有效利用，在静态和动态空间推理任务上均取得最优结果，尤其在动态场景下将SOTA从58.9大幅提升到66.1。

本工作的局限性和未来方向在于：基准测试本身存在一定的标注歧义性（图7、图8展示了部分难以客观判断的案例），这是动态空间推理任务的固有挑战；此外，如何将该方法推广到更多3D基础模型和更复杂的空间关系类型也值得进一步探索。
