## 一句话总结

S2D2 利用"块扩散模型在块大小缩减为1时退化为自回归模型"这一关键洞察，让同一个预训练模型同时充当"草稿生成者"和"验证者"，在无需任何额外训练的前提下，实现相对自回归解码最高 **4.7×** 的推理加速。

---

## 背景与问题

### 扩散语言模型的兴起与瓶颈

近年来，以 LLaDA、SDAR、Fast-dLLM 为代表的**块扩散语言模型（Block Diffusion LLMs）**引发了广泛关注。这类模型结合了自回归的块间顺序生成和扩散模型的块内并行去噪，理论上能够在保持生成质量的同时大幅提升推理吞吐量。

然而，扩散语言模型的实际解码效率面临严峻挑战：

- **置信度阈值解码（Confidence-Thresholded Decoding）** 是最常见的加速策略——在每个去噪步骤中，只有置信度超过阈值的 token 才被固定，其余继续迭代。
- **静态策略**（固定阈值）：过于保守则速度无法提升，过于激进则生成质量严重下降。
- **动态策略**（自适应调整块大小）：虽有改进，但在少步数场景下仍然脆弱——模型往往会自信地生成错误答案，置信度阈值无法有效过滤噪声。

核心矛盾在于：**扩散模型的置信度与输出正确性之间的对齐性远不如自回归模型**，这使得单纯依赖置信度的解码策略存在内在缺陷。

### 推测解码的局限

推测解码（Speculative Decoding）是加速自回归模型的成熟技术：用小模型快速生成草稿，再用大模型并行验证，理论上可在不损失输出分布的情况下显著提速。但将其迁移到扩散语言模型时面临新的障碍：

1. 需要专门训练一个扩散草稿模型，增加开销；
2. 现有方法（如 ASSD、SSD）依赖特定架构或需要额外微调；
3. 扩散模型的并行去噪机制与传统推测解码的顺序验证逻辑不兼容。

**S2D2 的研究目标**：能否设计一种无需额外训练的自推测解码框架，仅利用单个预训练扩散语言模型，同时完成草稿生成和验证？

## 核心方法

### 关键洞察：块大小为1时，扩散模型即自回归模型

S2D2 的理论基础源于一个简洁而深刻的观察：

> 当块扩散模型的块大小（Block Size）设置为 1 时，块内并行去噪退化为单 token 生成，模型行为与自回归模型完全等价。

这意味着，**同一个预训练的块扩散模型**，通过改变注意力掩码（Attention Mask），可以在两种模式之间无缝切换：
- **草稿模式（Drafter）**：使用标准块扩散解码，大块大小，并行生成多个 token
- **验证模式（Verifier）**：使用块大小为1的自回归模式，逐 token 精确验证

### 整体框架

![S2D2 整体流程图](https://arxiv.org/html/2603.25702/x1.png)

*图1：S2D2 框架概览。左：草稿生成阶段（标准块扩散）；中：验证阶段（自回归模式，自定义注意力掩码）；右：路由策略决定是否触发验证。*

整个解码过程如下：

1. **草稿生成**：块扩散模型以大块大小（如 B=32）并行生成一批候选 token，得到草稿序列及每个 token 的概率分布 $p_i$
2. **验证触发**：路由策略评估当前草稿质量，决定是否值得调用验证器
3. **自回归验证**：验证器以自回归模式计算每个位置的条件概率 $q_i$
4. **拒绝采样接受**：逐 token 以概率 $\min(1, q_i/p_i)$ 接受草稿 token，被拒绝的 token 从修正分布中重新采样
5. **最长接受前缀**：找到第一个被拒绝位置，接受其前的所有 token，进入下一轮块解码

### 自我验证掩码：一次前向传播完成所有验证

对于位置对齐的模型（如 LLaDA、SDAR），S2D2 设计了一个精妙的**"2L 技巧"**：将输入序列复制为上下两半，构造特殊的块状注意力掩码：

$$\mathbf{M}_{\mathrm{ver}}=\begin{bmatrix}\mathbf{A}_{L} & \mathbf{0}_{L}\\ \mathbf{A}_{L}^{<} & \mathbf{I}_{L}\end{bmatrix}$$

- 上半部分（行1～L）：标准双向注意力（用于草稿生成）
- 下半部分（行L+1～2L）：严格因果注意力（用于自回归验证）
- 关键：下半部分的每个位置只能看到上半部分对应位置之前的 token，实现了真正的因果条件概率计算

**效果**：所有位置的验证器置信度 $q_1, q_2, \ldots, q_L$ 可在**一次前向传播**中同时计算，而非逐 token 串行验证，大幅摊薄了验证开销。

对于右移型模型（如 Fast-dLLM v2），直接使用标准因果掩码即可，无需 2L 技巧。

### 可选的部分因果草稿掩码

S2D2 还提出了一种**部分因果草稿掩码（Partially Causal Drafting Mask）**，在草稿生成阶段引入部分因果约束：

$$\mathbf{M}_{\mathrm{draft}}^{(j)}=\begin{bmatrix}\mathbf{A}_{j} & \mathbf{0}_{j,\,B-j}\\ \mathbf{1}_{B-j,\,j} & \mathbf{1}_{B-j,\,B-j}\end{bmatrix}$$

前 $j$ 个位置使用因果注意力（类自回归），后续位置使用双向注意力。这种混合策略使草稿分布 $p_i$ 更接近验证器分布 $q_i$，提高接受率，但也会略微增加计算量。实验中这是一个可调的超参数配置选项。

### 预期接受前缀长度估计

为了支持智能路由决策，S2D2 需要**在不实际执行验证的情况下**估计预期接受的 token 数量 $\hat{K}$：

$$\hat{K}=\sum_{k=1}^{L}\prod_{i=1}^{k}\alpha_i$$

其中 $\alpha_i$ 是第 $i$ 个 token 的估计接受概率，论文提出两类代理估计器：

**基于边际（Margin-based）**：
$$\alpha_i = \mathbf{1}[m_i \geq \tau_{\text{margin}}], \quad m_i = p_{i,1} - p_{i,2}$$

即用草稿模型 top-1 和 top-2 概率之差作为置信度指标。

**基于熵（Entropy-based）**：
$$\alpha_i = \exp(-\beta\tilde{H}_i), \quad \tilde{H}_i = H_i/\log V$$

用归一化熵作为不确定性的软度量。

消融实验表明：边际估计器对前缀长度预测最准确（MAE 最低），但熵估计器在下游准确率上表现更好，主实验中采用熵估计器。

### 四种路由策略

路由策略是 S2D2 的核心设计之一，决定了何时值得付出额外的验证计算开销：

**1. 最小跨度策略（Minimum-Span）**
$$\text{verify if } |C_t| \geq \tau_{\mathrm{span}}$$
当当前仍未确定（masked）的连续 token 段长度超过阈值时触发验证。直觉：短段验证收益小，只对较长的不确定段才值得验证。

**2. 得分阈值策略（Score-Threshold）**
$$s = \hat{K} - c, \quad \text{verify if } s \geq \tau_{\mathrm{score}}$$
估计接受长度 $\hat{K}$ 减去验证成本常数 $c$，当净收益为正时触发。动态版本使用 $s = \hat{K} - c \cdot N_{\mathrm{hi}}$，$N_{\mathrm{hi}}$ 是近期高置信度步骤的计数。

**3. 迟滞策略（Hysteresis）**
设置触发阈值 $\tau_{\mathrm{on}}$ 和关闭阈值 $\tau_{\mathrm{off}}$（$\tau_{\mathrm{on}} > \tau_{\mathrm{off}}$），通过状态机减少频繁切换带来的振荡。

**4. 上下文赌博机策略（Contextual Bandit）**
采用 UCB（Upper Confidence Bound）风格的自适应路由。奖励定义为：
$$r = \frac{\texttt{本步骤解码 token 数}}{\texttt{时间开销}}, \quad \texttt{时间开销} = \begin{cases}2 & \text{触发验证}\\ 1 & \text{未触发验证}\end{cases}$$
上下文特征：跨度长度分 bin × 解码进度分 bin × 熵值分 bin，在线学习最优路由策略。

### 局部能量视角

从能量函数的角度，S2D2 有一个优雅的理论诠释。定义每个 token 的**局部残差能量**：
$$E_i(\hat{x}_i) := -\log q_i(\hat{x}_i) + \log p_i(\hat{x}_i)$$

则接受概率 $\min(1, q_i/p_i) = \min(1, e^{-E_i(\hat{x}_i)})$。

- 当草稿概率 $p_i$ 接近验证器概率 $q_i$ 时，能量接近零，token 被接受
- 当两者差异大时，能量高，token 更可能被拒绝并从修正分布重采样

这使得 S2D2 的验证机制本质上是一种**随机贪婪的自回归能量修正**：将扩散模型生成的序列向自回归模型的分布方向"拉"，同时保持扩散解码的并行优势。

## 总结

### 核心贡献回顾

S2D2 提出了一套简洁而有效的无训练自推测加速框架，其核心贡献可归纳为三点：

1. **理论洞察**：块扩散模型在块大小为1时等价于自回归模型，这使得单模型自推测在数学上成为可能。

2. **工程实现**：通过 2L 注意力掩码技巧，在一次前向传播中同时完成草稿生成概率 $p_i$ 和验证概率 $q_i$ 的计算，将验证开销从 $O(L)$ 次传播降至 $O(1)$ 次。

3. **路由策略**：设计了四种从简单到复杂的路由策略（最小跨度、得分阈值、迟滞、上下文赌博机），在不同速度-精度需求下均有合适选项。

### 方法的普适性

S2D2 是**架构无关**的即插即用方案：
- 支持位置对齐型模型（LLaDA、SDAR）：使用 2L 掩码技巧
- 支持右移型模型（Fast-dLLM v2）：使用标准因果掩码
- 与 LLaDA2.1 的内置 token 编辑自我修正机制**互补**，可叠加

### 局限性与未来方向

- 在某些配置（如 Fast-dLLM v2 配置-C 的 MBPP）下，S2D2 相比 AR 基准仍有准确率差距，说明扩散解码固有的分布偏差不能完全通过验证消除。
- 上下文赌博机策略的自适应潜力尚未完全发挥，未来可探索更强的在线学习算法。
- 本文仅评测了数学和代码基准，在更广泛的自然语言任务上的表现有待验证。

### 更广泛的意义

S2D2 的工作揭示了一个更深层的问题：**扩散语言模型和自回归语言模型并非截然对立**，而是同一族模型在不同块大小下的连续谱。这种统一视角不仅为推理加速提供了新思路，也为理解两类模型的生成机制差异提供了新工具——AR-ness 分析和置信度演化研究本身就有独立的理论价值。

对于实践者而言，S2D2 提供了一条**零成本升级路径**：任何已有的块扩散语言模型，无需重新训练，只需插入 S2D2 解码框架，即可在准确率基本不变甚至提升的情况下获得显著的推理加速。
