## 一句话总结

提出 **BitNet b1.58**——一个彻底颠覆"高精度训练必然 → 低精度量化"范式的工作。核心主张:**从零开始训练一个只用 $\{-1, 0, 1\}$ 三值权重**(每个权重的信息量 $\log_2 3 \approx 1.58$ bit)的 LLM,并在 3B 参数规模上**匹敌同样 FP16 从零训练的模型**。不是量化已有模型,而是**quantization-aware pretraining**——把极低精度融入训练流程。带来的收益是数量级的:**模型显存缩 10×、能耗缩 71×、矩阵乘法从浮点退化为加减法**,甚至可以设计**专用硬件**(无需乘法器)。BitNet b1.58 是"后摩尔定律"时代 LLM 架构的一个激进想象。

## 背景:量化的极限在哪里?

### PTQ 的天花板

GPTQ / AWQ 等 post-training 量化方法已经把大模型压到 **INT4 且几乎无损**。能不能更低?

- INT3:质量开始明显掉
- INT2:基本崩溃
- 1-bit:完全不能用

原因:**PTQ 只是后处理**——一个以 FP32/FP16 训练出来的模型,权重分布不适合 1-bit 表示。强行压的话会丢太多信息。

### QAT 的潜力

Quantization-Aware Training(QAT)——训练时就用低精度——理论上能突破 PTQ 的限制。但:

- 训练不稳定
- 成本高(不能直接从头训)
- 过去只在 CV 小模型上成功

BitNet b1.58 的贡献:**证明 QAT 对 LLM 在 3B+ 规模可行,且极低精度能匹配全精度**。

## 核心机制:三值权重 $\{-1, 0, 1\}$

### 为什么是 1.58-bit 而不是 1-bit

原始 BitNet(Wang et al., 2023, arXiv 2310.11453)用**二值** $\{-1, +1\}$——每个 weight 1 bit。b1.58 加入 **0** 作为第三个值:

- $\{-1, 0, +1\}$ 有 3 种状态 → $\log_2 3 \approx 1.58$ bit
- **0 的作用**:让模型能"跳过"不重要的连接——类似 sparse 权重

这个小小的扩展(从 2 态到 3 态)在实验上让模型能匹敌 FP16,而纯 1-bit 总是明显掉分。

### 量化函数

对 FP32 训练中保持的 full-precision weight $W_{\text{fp32}}$:

$$
W_{\text{1.58}} = \text{RoundClip}\!\left( \frac{W_{\text{fp32}}}{\gamma}, -1, 1 \right)
$$

其中:

- $\gamma = \frac{1}{nm}\sum |W_{\text{fp32}}|$:全局平均绝对值,作为归一化因子
- $\text{RoundClip}(x, a, b)$:四舍五入后 clip 到 $[a, b]$

### Activation 也量化

激活用 **per-token 动态 INT8**:

$$
\hat X = \text{Quant}_{\text{INT8}}(X)
$$

所以实际是 **W1.58A8** 的组合。

### Straight-Through Estimator (STE)

反向传播时,量化是不可导的。BitNet b1.58 用经典的 STE:

$$
\frac{\partial \text{RoundClip}(x, \ldots)}{\partial x} \approx 1
$$

梯度**"穿过"**量化步骤直接传递给 full-precision weight。这让训练可以进行。

## 架构调整:为三值而生的 Transformer

![BitLinear 模块替代标准 Linear:前向量化 weight + activation,用 INT8 kernel 做矩阵乘,加入 LayerNorm 保护。反向 STE。](/assets/img/bitnet/x2.png)
_Figure 2:BitLinear layer——替代标准 Linear_

### BitLinear layer

BitNet 的所有 `nn.Linear` 被替换为 **BitLinear**:

```
def forward(x):
    # 量化 activation
    x_q = activation_quant(x)            # INT8
    # 量化 weight
    w_q = weight_quant(W_fp32)           # {-1, 0, 1}
    # 矩阵乘法(INT8 × Ternary)
    y = matmul(x_q, w_q.T)
    # 反量化
    return y * activation_scale * weight_scale
```

Attention 的 Q/K/V/O 投影、FFN 的 up/down proj 全部是 BitLinear。仅 **embedding 和 LayerNorm 保留 FP16**。

### 其他不变

- RoPE 位置编码:不变
- SwiGLU FFN:不变
- Pre-LN 结构:不变
- 唯一的改动就是所有 Linear → BitLinear

## 实验结果

### 质量:与 FP16 LLaMA 打平

![BitNet b1.58 vs FP16 LLaMA 在不同规模下的 perplexity:700M 稍差,1.3B 追平,3B+ 反超。规模越大,b1.58 的优势越明显。](/assets/img/bitnet/x3.png)
_Figure 3:BitNet b1.58 vs LLaMA 的 PPL scaling_

关键发现——**规模越大,b1.58 的相对优势越大**:

| 规模 | LLaMA FP16 PPL | **BitNet b1.58 PPL** |
|------|---------------|---------------------|
| 700M | 11.44 | 12.33(差 0.9) |
| 1.3B | 10.81 | 10.74(**追平**) |
| 3B | 9.91 | **9.88**(**反超**) |
| 3.9B (b1.58) | — | 9.62 |

到 3B+ 规模,**三值权重完全不掉分**。

### 效率:压倒性

![b1.58 vs FP16 的效率对比:显存 3.55×、能耗 71.4×、latency 8.9×。规模越大优势越明显。](/assets/img/bitnet/x4.png)
_Figure 4:b1.58 的效率碾压_

在 3B 模型上对比:

| 指标 | FP16 LLaMA | **BitNet b1.58** | 优势 |
|------|------------|------------------|------|
| 显存 | 11.2 GB | **3.2 GB** | **3.5×** |
| 延迟(1 token) | 7 ms | **0.8 ms** | **8.9×** |

| 吞吐量 | 1.4k tok/s | **7.2k tok/s** | **5×** |

### 专用硬件的可能

三值矩阵乘法有一个**令人兴奋的性质**:

$$
y_i = \sum_j x_j \cdot w_{ij},\quad w_{ij} \in \{-1, 0, +1\}
$$

- $w_{ij} = 1$:加 $x_j$
- $w_{ij} = -1$:减 $x_j$
- $w_{ij} = 0$:跳过

**完全不需要乘法器**!只需加法器 + 符号位。这让设计**专用 BitLLM 推理芯片**成为可能——成本远低于 GPU,能耗再降 5-10×。Groq、D-Matrix 等芯片公司已经讨论围绕三值 LLM 的硬件设计。

## 讨论:为什么三值能工作?

### 1. LLM 的权重本身稀疏 + 接近二值

分析预训练 LLM 权重分布发现:

- 大多数权重幅度在 $[-0.1, 0.1]$
- 只有少数重要权重幅度大
- 对 LLM 的预测贡献最大的是**方向**(+ 或 -),而非精确幅度

三值编码保留了"方向",舍弃了"精确幅度"——恰好丢掉了信息量最少的部分。

### 2. QAT 让训练适应量化

从零训练时,STE 的"梯度流"让 full-precision weight 学到**一个三值友好的分布**——让 RoundClip 后的近似误差自然最小化。这是 PTQ 办不到的。

### 3. 激活的 INT8 保住了表达力

weight 极度压缩但 activation 仍是 INT8(有 256 个 code words)。乘积 $y_i = \sum_j x_j w_{ij}$ 的表达力主要由 activation 贡献——这让整体精度不崩。

## 影响与余波

### 1. 改变人们对量化极限的认知

在 BitNet b1.58 之前,业界普遍相信"4-bit 是 LLM 的底线"。b1.58 证明 **1.58-bit 从零训练可以做到**——直接把理论极限往下推 2.5×。

### 2. 催生一批 1-bit / ternary 架构

2024 年后半年出现大量后继:

- **BitNet a4.8** (Wang 2024):激活也 4-bit
- **OneBit** (Xu 2024):用 two-weight matrices 代替 single ternary
- **MatMul-free LLM** (Zhu 2024):完全无乘法的 LLM 架构

这整条"超低 bit LLM"路线可以追溯到 BitNet 和 b1.58。

### 3. 推动专用硬件研发

NVIDIA、AMD 的下一代芯片讨论加入 ternary / binary 原生支持。创业公司如 [Recogni](https://recogni.com/) 明确围绕 1-bit LLM 做芯片。

### 4. 重新思考 training-inference trade-off

以前:**训练贵,推理便宜**。现在有了新方向:**训练同样贵,但推理便宜 10-100×**。对部署密集的 AI 服务,这个 trade-off 可能更优。

---

## 局限

### 1. 训练成本不降反升

BitNet b1.58 需要从零训练——**训练成本和 FP16 相同甚至更高**(量化引入额外步骤)。只有推理阶段受益。

### 2. 无法利用现有预训练模型

所有现有的 LLaMA、Mistral、Qwen 权重都是 FP16——**不能直接转换成 b1.58**。想用 b1.58 就要重新训一套。这让产业采用门槛很高。

### 3. 最大规模验证有限

论文最大只测到 3.9B。更大规模(70B、400B)的 b1.58 行为尚未充分验证。

### 4. 硬件支持仍欠缺

GPU 的 tensor core 没有 ternary 原生支持,所以实际加速依赖 custom kernel(BitNet 团队发布了 [T-MAC](https://github.com/microsoft/T-MAC))。生产环境的硬件生态还在建设中。

## 读完这篇你真正该带走的 4 件事

<callout emoji="white_check_mark" background-color="light-green" border-color="green">
1. **从零 QAT 可以突破 PTQ 的极限**:PTQ 压到 4-bit 就难再降,但 QAT 可以到 1.58-bit 几乎无损——这说明"量化的极限"不是数学上的,是"训练策略"决定的
2. **$\{-1, 0, +1\}$ 比 $\{-1, +1\}$ 决定性地好**:加入 0 让权重能 "不连接",获得 sparsity 的好处——这个看似微小的改动是 b1.58 成功的核心
3. **压缩到乘法都没有了**:三值 matmul 退化为加减法,让专用无乘法硬件成为可能。这是跨越"算法 / 硬件"边界的想象
4. **规模放大,b1.58 优势变大**:这是 scaling 规律的一个新维度——低精度在大模型上**反而更稳**。背后原因是大模型权重的"冗余"更多,适合激进压缩
</callout>
