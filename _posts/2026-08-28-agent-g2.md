> 🏢 **机构**：浙江大学、百度公司、山东大学

## 一句话总结

Agent-G² 提出了基于高斯分布的引导深度调度框架，通过在线从已有 rollout 统计中估算每个任务的最优引导范围（而非探测额外 rollout），在 ALFWorld 上以不到三分之一的探测代价超越最强基线 7.4 个点。

## 背景与问题

在长时域智能体任务中训练 LLM，一个关键挑战是**稀疏奖励**：任务跨越数十个序列化决策，但只在终止时给出二元信号。这导致从初始状态出发的在策略探索几乎永远无法到达成功终止状态。

**提示引导 RL（Hint-based RL）** 的解决方案：保留专家轨迹的前缀，让策略从更靠近成功的状态开始探索。有效性的关键在于**引导深度**（保留多少前缀）。

**现有方法的缺陷：**
- **调度方法（Scheduled）**：所有样本共享一个引导深度值 $d_t$，忽略了每个任务的异质性
- **探测方法（Probe-based）**：为每个样本单独估计深度，需要 $O(\log n)$ 的额外探测 rollout，代价高昂

*图：三种提示引导 RL 范式对比——(a) 调度方法：样本共享 $d_t$；(b) 探测方法：$O(\log n)$ 探测；(c) Agent-G²：从高斯分布采样 $d_i \sim \mathcal{N}(\mu_t, \sigma_t^2)$*

## 核心方法

### 关键观察：有效引导具有高斯形态

Agent-G² 的理论动机来自两个观察：

**观察 1：有效引导占据一个"深度带"**
- 成功率 $p_i(d)$ 关于深度 $d$ 的图形显示，"恰好可学习"制度跨越多个相邻深度，而非单一最优点
- 专注于精确定位单一深度的调度器忽略了一个信息丰富的邻域

**观察 2：信息量呈高斯形态**
- 以 Bernoulli 方差 $p_i(d)(1-p_i(d))$ 作为训练信息量的代理
- 以任务特定有效深度 $d_i^*$ 为中心对齐后，信息量分布与高斯拟合高度一致（$R^2 = 0.92$）

### Agent-G² 框架

基于上述观察，Agent-G² 为每个任务分配一个引导比例高斯分布 $\mathcal{N}(\mu_i, \sigma_i^2)$：

**全局基线 $\mu_{\text{global}}$**：
- 追踪当前策略所需的总体引导水平
- 基于批次平均成功率 $\text{acc}_\mathcal{B}$ 向目标成功率 $p_{\text{target}} = 0.5$ 方向调整

**聚类统计 $(A_k, V_k)$**：
- 任务按难度离线聚类
- EMA 估计每个聚类 $\mathcal{C}_k$ 的成功率水平 $A_k$ 和离散度 $V_k$

**每任务高斯中心 $\mu_i$**：全局基线 + 聚类难度偏移

**核心优势**：
- 无需额外探测 rollout
- 复用已为策略优化收集的 rollout 统计
- 同一批 rollout 同时更新策略和调度参数

## 实验结果

### ALFWorld 主要结果

在 Qwen2.5-1.5B / 7B-Instruct 上，与最强基线对比：

| 基线类型 | 方法 | ALFWorld All (%) |
|---------|------|-----------------|
| 提示引导 | 最强竞争方法 | - |
| 提示无关 | 最强竞争方法 | - |
| Aux-RL | 最强竞争方法 | - |
| **Agent-G²** | **本文** | **超过三者分别 +2.3 / +3.9 / +7.4** |

**探测成本对比**：Agent-G² 以**不到三分之一的 rollout 代价**超越探测方法。

### 各任务类型表现

| 任务类型 | GPT-4o | Gemini-2.5-Pro | Agent-G²（7B） |
|---------|--------|----------------|----------------|
| Pick | 75.3 | 92.8 | - |
| Look | 60.8 | 63.3 | - |
| Clean | 31.2 | 62.1 | - |
| Heat | 56.7 | 69.0 | - |
| Cool | 21.6 | 26.6 | - |

Agent-G² 在 7B 模型上的 All 成功率超越 GPT-4o 和 Gemini-2.5-Pro 的提示结果。

## 总结

Agent-G² 的贡献在于将"最优引导深度"从标量扩展为高斯分布，抓住了有效引导的统计结构，实现了零额外探测代价的自适应引导。核心洞见——有效引导形成高斯形态的信息量分布——为长时域智能体 RL 的课程设计提供了新的理论视角。

局限性：目前验证限于 ALFWorld 和 WebShop 两个基准；如何获取高质量专家轨迹仍是实际应用的前提条件；高斯假设是否在所有任务类型上成立需要更多验证。
