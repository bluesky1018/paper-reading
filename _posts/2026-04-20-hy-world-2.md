## 一句话总结

HY-World 2.0 是首个开源的系统性多模态世界模型框架，通过四阶段生成流水线与前馈式重建模型，将三维世界的生成与重建统一到以 3D Gaussian Splatting（3DGS）为表示的单一框架中，并达到开源方法中的最优性能，可与闭源模型 Marble 媲美。

## 背景与问题

三维世界建模长期面临"生成"与"重建"两条路线割裂的困境。生成式方法（如视频扩散模型）具备丰富的生成先验，但缺乏精确的几何一致性；重建式方法（如 NeRF、3DGS）几何精度高，但依赖密集输入视角，无法凭借稀疏输入或文本描述创建新场景。

现实应用（游戏、具身智能、自动驾驶仿真）迫切需要一种能够以多种模态作为输入——文本、单张图像、多视角图像或视频——并输出可渲染、可交互的完整三维世界的统一模型。此前的 HY-World 1.0 奠定了基础框架，但在全景生成质量、轨迹规划多样性、视频扩展的时序一致性以及重建精度等方面仍有较大提升空间。

HY-World 2.0 在上述挑战上全面升级：引入新一代全景生成模型 HY-Pano 2.0、语义驱动的轨迹规划器 WorldNav、带有几何感知记忆的视频扩展模型 WorldStereo 2.0、前馈式通用三维预测模型 WorldMirror 2.0，以及高性能渲染平台 WorldLens，形成端到端的完整系统。

## 核心方法

### 整体架构

HY-World 2.0 的世界生成流水线由四个串联阶段构成，世界重建则由独立的 WorldMirror 2.0 负责，两者共享最终的 3DGS 表示。

### 阶段一：全景生成（HY-Pano 2.0）

HY-Pano 2.0 基于多模态扩散 Transformer（MMDiT）架构，接受文本或图像输入，生成等距柱面投影（ERP）格式的全景图作为三维世界的"种子"。

核心创新点：
- **隐式透视到 ERP 的映射**：无需显式相机元数据，通过训练隐式学习视角转换
- **无缝边界处理**：采用循环填充（circular padding）结合像素混合（pixel blending），消除左右边界的接缝伪影
- **数据来源多样化**：结合真实世界全景数据与虚幻引擎（Unreal Engine）合成资产进行训练

### 阶段二：轨迹规划（WorldNav）

WorldNav 负责在生成的全景场景中规划相机探索轨迹，为后续视频扩展提供输入。

场景解析流程：
- **几何感知初始化**：使用 MoGe-2 进行深度估计，采样 42 个视角（默认为 12 个）以提高精度
- **语义锚定**：结合 Qwen3-VL 与 SAM3 识别场景地标，使用 Recast Navigation 生成可导航网格（NavMesh）

WorldNav 支持五种轨迹模式，共可生成最多 35 条轨迹：

| 模式 | 最大条数 | 是否附着到物体 | 是否迭代 |
|------|---------|----------------|---------|
| 常规（Regular） | 9 | 否 | 否 |
| 环绕（Surrounding） | 5 | 是 | 否 |
| 重建感知（Reconstruct-Aware） | 10 | 是 | 是 |
| 漫游（Wandering） | 3 | 否 | 否 |
| 航拍（Aerial） | 8 | — | 否 |
| **合计** | **35** | | |

### 阶段三：世界扩展（WorldStereo 2.0）

WorldStereo 2.0 以规划好的轨迹为输入，生成多段时序一致的视频序列，是整个系统中最核心的扩散模型组件。

**训练三阶段**：

1. **域适应**：在大规模视频数据上进行基础训练
2. **中间训练（记忆引入）**：加入全局几何记忆与空间立体记忆机制
3. **后蒸馏**：改进的 DMD（Distribution Matching Distillation）将推理步数压缩至 4 步

**核心技术**：

**Keyframe-VAE**：仅在空间维度压缩（无时间压缩），保留高频细节，避免常规视频 VAE 时序压缩带来的关键帧质量损失。

**全局几何记忆（GGM）**：将历史轨迹生成的点云汇聚为扩展点云作为跨轨迹的三维先验，解决多段视频间几何不一致问题。

**空间立体记忆++（SSM++）**：在主 DiT 分支中引入基于检索的帧拼接机制，并修改 RoPE 位置编码，实现高效的长程上下文利用。

与其他范式的对比：

| 特性 | 原生视频扩散 | 自回归 | WorldStereo 2.0 |
|-----|------------|--------|-----------------|
| 感受野 | 双向 | 自回归 | 双向 |
| 轨迹长度/数量 | 长/单条 | 长/单条 | 中等/多条 |
| 潜在空间 | 视频片段 | 视频片段 | 关键帧图像 |
| 帧质量 | 一般 | 一般 | 高 |
| 帧冗余 | 高 | 高 | 低 |
| 精确相机控制 | 部分支持 | 部分支持 | 支持 |
| 一致性 | 部分 | 部分 | 强 |
| 效率 | 一般 | 低 | 高 |

### 世界重建：WorldMirror 2.0

WorldMirror 2.0 是一个前馈式通用三维预测模型，给定任意视角的图像输入，直接预测点图（point maps）、深度、表面法线、相机参数及 3DGS 属性，无需迭代优化。

WorldMirror 1.0 → 2.0 核心改进：

| 模块 | v1.0 | v2.0 |
|------|------|------|
| 位置编码 | 绝对 RoPE | 归一化 RoPE |
| 深度监督 | 仅 GT 深度 | GT 深度 + GT/伪法线 |
| 无效像素建模 | 仅置信度 | 置信度 + 深度 Mask Head |
| 加速方案 | 无 | Token/Frame SP + BF16 + FSDP |
| 训练数据 | 开源数据集 | + 内部 UE 渲染数据 |
| 分辨率采样 | 100K–250K 像素 | 50K–500K 像素 |
| 课程学习阶段 | 2 阶段 | 3 阶段 |

**归一化 RoPE**：将 patch 索引映射到 [-1, 1] 区间，而非绝对位置，使得跨分辨率的特征余弦相似度保持在 0.95 以上，而标准 RoPE 在分辨率外推时会显著退化（相当于将分辨率外推问题转化为内插问题）。

**深度到法线损失（L_d2n）**：通过反投影与叉积将预测深度转换为法线，再与法线目标计算角度误差，强化几何一致性。

### 阶段四：世界合成与 WorldLens 渲染

**世界合成**通过 WorldMirror 2.0 预测各关键帧的点图，结合深度对齐进行点云扩展，再利用自定义初始化、MaskGaussian 生长策略与网格提取完成 3DGS 场景构建。

**WorldLens** 是专为 3DGS 设计的高性能渲染平台，支持：
- 灵活的引擎无关架构（engine-agnostic）
- 自动 IBL（基于图像的光照）
- 高效碰撞检测

归一化 RoPE 在各分辨率下的跨分辨率余弦相似度稳定保持在 **0.95 以上**，而标准绝对 RoPE 随分辨率偏移显著退化，验证了归一化位置编码在处理可变分辨率输入时的优越性。

## 总结

HY-World 2.0 是首个将三维世界生成与重建统一到单一开源框架的系统性工作。通过 HY-Pano 2.0、WorldNav、WorldStereo 2.0、WorldMirror 2.0 四大核心模块的协同设计，框架能够从文本、单图、多视图或视频等多种模态出发，生成高质量、可交互的 3DGS 三维世界。

在技术贡献层面，Keyframe-VAE 避免了时序压缩对帧质量的损害，GGM 与 SSM++ 两种记忆机制解决了多轨迹间几何一致性的长期难题，归一化 RoPE 将分辨率外推转化为内插从而大幅提升跨分辨率稳定性，4 步蒸馏推理则将实际部署效率提高到可用水平。

作为完全开放的工作（权重、代码、技术报告全部公开），HY-World 2.0 为学术界和工业界在具身智能、游戏场景生成、自动驾驶仿真等领域的应用奠定了重要基础，也为后续世界模型研究提供了强有力的开源基线。
