> 🔗 **arXiv**：[2603.27460](https://arxiv.org/abs/2603.27460)

## 一句话总结

Project Imaging-X 对 1,000 余个开放访问的医学影像数据集进行了迄今最大规模的系统性调研，揭示了当前数据生态系统规模有限、任务碎片化、器官/模态分布不均等核心问题，并提出元数据驱动的融合范式（MDFP）和交互式发现门户，为构建强大医学基础模型提供实践路径。

## 背景与问题

基础模型在各种领域和任务上展现出卓越能力，其成功在很大程度上源于大规模、多样化、高质量数据集的支撑。然而，在医学影像领域，大规模统一数据集的构建面临独特挑战：

**1. 临床专业依赖**：医学影像数据的标注需要专业医学知识，不同影像模态（CT、MRI、超声、内镜、病理切片等）需要对应科室的专家标注，人力成本极高。

**2. 伦理与隐私约束**：患者数据受到严格的隐私法规保护（如 HIPAA、GDPR），数据共享需要完整的伦理审批流程，使得大规模数据集聚合极为困难。

**3. 数据孤岛效应**：现有开放数据集往往针对特定器官（如肺部、肝脏、脑部）、特定模态（如 CT、MRI）或特定任务（如肿瘤分割、疾病分类），导致严重的碎片化，无法直接用于训练通用医学基础模型。

**4. 生态现状不明**：尽管有大量医学影像数据集已公开，但缺乏系统性的调研和分类，研究者难以快速发现、评估和整合适合自身需求的数据集。

## 核心贡献

### 调研规模与方法

Project Imaging-X 对 **1,000+ 个开放访问**的医学影像数据集进行了系统性调研，为每个数据集构建了结构化的元数据目录，涵盖：

| 维度 | 描述 |
|------|------|
| **影像模态** | CT、MRI、X-Ray、超声、内镜、病理切片、PET/SPECT、眼底等 |
| **任务类型** | 分类、检测、分割、配准、重建、生成等 |
| **解剖部位** | 脑部、肺部、心脏、肝脏、肾脏、骨骼、皮肤等 |
| **标注类型** | 像素级分割、边界框、图像级标签、报告文本等 |
| **局限性** | 样本量、类别不均衡、标注质量、采集来源等 |
| **集成潜力** | 与其他数据集融合的可行性评估 |

### 核心发现：当前医学影像数据生态的三大问题

**问题一：规模有限（Modest Scale）**
与自然图像数据集（ImageNet 含 1,400 万图像）和语言数据集（Common Crawl 含数万亿 token）相比，医学影像数据集规模普遍偏小，大多数数据集包含数百到数千个样本，真正达到数万级别的数据集仅占少数。

**问题二：任务碎片化（Fragmented Across Tasks）**
现有数据集高度专注于狭窄范围的任务，例如专门用于肺结节检测、视网膜血管分割或脑肿瘤分类的数据集。这种碎片化使得没有任何单一数据集足以支撑通用医学基础模型的训练。

**问题三：分布不均（Uneven Distribution）**
器官和模态覆盖严重不均衡：少数常见疾病（如糖尿病视网膜病变、肺癌）和常用模态（如胸部 X-Ray、脑部 MRI）数据集丰富，而罕见病、儿科疾病、发展中国家常见疾病的数据集极度匮乏。

### 元数据驱动的融合范式（MDFP）

针对数据碎片化问题，论文提出 **元数据驱动的融合范式（Metadata-Driven Fusion Paradigm, MDFP）**：

**核心思想**：利用共享模态或任务作为桥梁，整合多个公共数据集，将分散的小数据孤岛转化为更大、更一致的资源。

**MDFP 工作流程**：
1. **元数据标准化**：为所有数据集建立统一的元数据模式（影像格式、标注格式、坐标系等）
2. **相似性分析**：基于元数据自动识别可融合的数据集组
3. **跨数据集对齐**：处理不同数据集间的标注差异、类别不一致、分辨率差异等
4. **质量控制**：验证融合后数据集的质量和多样性

**MDFP 示例**：
- 将多个肺部分割数据集（来自不同医院、不同设备的 CT 扫描）融合，扩大训练集规模
- 将相同解剖部位的不同任务数据集（如胸部 X-Ray 的疾病分类和肺炎检测）整合为多任务数据集

### 交互式发现门户

基于 MDFP，论文发布了：
1. **交互式发现门户**：支持端到端、自动化的医学影像数据集集成
2. **统一结构化数据表**：汇总所有调研数据集的关键特征（模态、任务、样本量、标注格式等）并提供参考链接

## 实验结果

**调研规模统计**：

| 统计维度 | 数值 |
|----------|------|
| 调研数据集总数 | 1,000+ |
| 覆盖影像模态 | 10+ 种（CT、MRI、X-Ray、超声等） |
| 覆盖解剖部位 | 20+ 个器官/系统 |
| 覆盖任务类型 | 分类、分割、检测、报告生成等 |

**数据生态分析发现**：
- 胸部 X-Ray 数据集数量最多，占所有开放数据集的约 15-20%
- 分割任务数据集占主导（约 40%），分类任务次之（约 30%）
- 超过 60% 的数据集样本量少于 5,000 个
- 皮肤科、眼科、病理等领域的数据集相对丰富，内镜、核医学、牙科等相对匮乏

**MDFP 融合效果**：通过 MDFP 将若干相关小数据集融合，在下游任务上展示了明显的性能提升，验证了数据融合的有效性。

## 总结

Project Imaging-X 是迄今为止规模最大的医学影像开放数据集调研，通过系统性地揭示当前数据生态的碎片化和分布不均问题，为医学基础模型的发展指明了明确的路径。元数据驱动的融合范式（MDFP）提供了将分散数据孤岛聚合为高质量大规模数据集的可操作框架，配合交互式发现门户，大幅降低了研究者发现、评估和整合医学影像数据的成本。

**局限性与未来方向**：
- 当前调研主要关注开放访问数据集，大量机构内部私有数据集未被覆盖
- 跨机构数据融合时的 domain shift（领域偏移）问题仍需系统解决
- 标注质量参差不齐的问题在大规模融合中尤为突出，自动质量控制方法有待研究
- 多语言医学报告（非英文）的覆盖有限，限制了对非英语国家医疗数据的整合
