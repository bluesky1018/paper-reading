> 📄 **论文**：YoCausal: How Far is Video Generation from World Model? A Causality Perspective
> 🔗 **arXiv**：[2605.30346](https://arxiv.org/abs/2605.30346)
> 🏢 **机构**：国立阳明交通大学（NYCU）、Shanda AI Research Tokyo

## 一句话总结

YoCausal 通过时间反转真实世界视频构建零成本反事实基准，在 13 个最先进视频扩散模型上系统验证：**感知时间箭头并不等于理解因果关系**，所有模型均显著落后于人类水平。

## 背景与问题

视频扩散模型（VDMs）被寄望成为世界模型的基础，但关键问题是：这些模型真的理解因果关系，还是仅仅学到了统计时间模式？

现有物理和因果推理基准（PhyWorld、LikePhys、Physion）全部依赖**合成数据**，存在严重的 sim-to-real 差距。更重要的是，能识别"哪个方向是正向播放"（时间箭头感知）和"理解因果关系"是两种不同的能力，现有基准无法区分它们。

YoCausal 受认知科学 VoE（违反预期）范式启发——婴儿看到时间倒放的因果事件时会表现出惊讶，说明人类天生具备因果感知能力。论文将这一范式引入视频生成模型评测。

## 核心方法

### 数据集构建

对**真实世界视频**进行时间反转，零成本生成反事实样本：

| 子集 | 数据来源 | 时长 | 视频数量 |
|------|----------|------|----------|
| General（通用） | Moments in Time | 3 秒 | 500 |
| Physics（物理） | Physics IQ | 5 秒 | 132 |
| Human Action（人类动作） | Kinetics-400 | 3 秒 | 400 |
| Animal Action（动物动作） | Animal Kingdom | 3 秒 | 200 |
| **总计** | | | **1,232 个** |

### 两级评测指标

**Level 1 — 逆转惊讶指数（Reverse Surprise Index, RSI）**

测量时间箭头感知能力，通过去噪损失计算：

$$\text{RSI}(D) = \frac{|\{v \in D : \mathcal{L}(v_{\text{rev}}) > \mathcal{L}(v)\}|}{|D|}$$

RSI ∈ [0,1]；50% = 随机猜测，值越高表示模型越能感知时间方向。

**Level 2 — 因果认知指数（Causality Cognition Index, CCI）**

用 VLM 将数据划分为因果子集 D_c 和非因果子集 D_nc：

$$\text{CCI}(D) = \text{RSI}(D_c) - \text{RSI}(D_{nc})$$

关键逻辑：反转**因果**视频引入两种异常（反转时间 + 反转因果），而反转**非因果**视频只引入一种（反转时间）。真正理解因果的模型 CCI 应 > 0。

## 实验结果

### Level 1：RSI 结果（13 个模型 + 人类基准）

| 模型 | RSI（总体） |
|------|------------|
| AnimateDiff-SDXL | 41.18% |
| CogVideoX-2B | 41.50% |
| Wan2.1-T2V-1.3B | 45.51% |
| CogVideoX1.5-5B | 46.83% |
| HunyuanVideo | 52.05% |
| Wan2.1-T2V-14B | 53.24% |
| Wan2.2-T2V-A14B | 54.19% |
| LTX-Video-13B | 56.48% |
| **LTX-Video-2B** | **58.86%（最佳）** |
| **Human（人类）** | **79.08%** |

最佳模型仅 58.86%，与人类 79.08% 差距显著。

### Level 2：CCI 结果（两个指标捕获不同维度）

![Level-2 CCI结果](https://arxiv.org/html/2605.30346v1/x8.png)
*图：各模型的 CCI 结果（越高越好）*

| 模型 | CCI | RSI(D_c) | RSI(D_nc) |
|------|-----|-----------|-----------|
| AnimateDiff-SD-1.5 | **-5.21%** | 43.40% | 48.61% |
| LTX-Video-13B | **-4.32%** | 54.65% | 58.97% |
| LTX-Video-2B | -0.20% | 57.95% | 58.15% |
| Mochi-1-preview | +3.85% | 49.11% | 45.26% |
| Wan2.1-T2V-14B | **+5.91%（最佳）** | 54.80% | 48.89% |
| **Human（人类）** | **+8.67%** | 85.09% | 76.42% |

**关键发现：LTX-Video-2B 的 RSI 最高（58.86%），但 CCI 接近零（-0.20%）**——它感知了时间方向，却没有理解因果关系。这正是两级指标设计的价值所在。

### 规模定律延伸到因果认知（Kendall's τ相关性）

| 相关变量 | τ | p-value |
|---------|---|---------|
| 美学质量 | 0.000 | 1.000（无相关） |
| 人类偏好 | 0.333 | 0.469（不显著） |
| LikePhys（物理基准） | 0.511 | **0.047（显著）** |
| 发布日期 | 0.596 | **0.032（显著）** |
| 参数量 | **0.688** | **0.009（高度显著）** |

参数量和发布时间均与因果认知高度相关，而美学质量与因果理解零相关，证明基准捕获了独特维度。

## 总结

YoCausal 揭示了当前视频扩散模型的两大核心问题：（1）所有模型的因果认知能力显著落后于人类，最佳模型 CCI 约 5.91% vs 人类 8.67%；（2）时间箭头感知与因果认知是可分离的两种能力，现有基准无法区分它们。

相比现有合成基准，YoCausal 使用真实世界视频（1,232 个 vs 最多 260 个场景），零成本可无限扩展，更贴近真实应用场景。规模定律分析表明，随着模型参数量增大，因果认知能力也在持续提升，但仍有很大的提升空间。局限性在于无法处理时间对称事件（如牛顿摆），且需要访问模型权重。
