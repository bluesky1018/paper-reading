## 一句话总结

DiSCO 是一种无需训练、完全黑盒的文生图安全防御方法，通过在 CLIP 嵌入空间中对 prompt 进行分布引导的对比优化，将有害 prompt 转化为安全 prompt，在不访问模型内部的情况下有效防御各类红队攻击。

## 背景与问题

文生图模型（如 Stable Diffusion、FLUX、SD 3）的快速发展带来了严峻的安全问题——它们可能生成 NSFW（不适合工作场所）内容，包括暴力和色情图像，且这一问题被红队（red-teaming）对抗攻击进一步放大。

现有防御方法主要存在以下局限：
- **白盒方法**（文本编码器优化、权重编辑、推理时干预）：无法扩展到闭源专有模型
- **基于 LLM 的黑盒 prompt 改写**：存在本文识别的关键盲点——**良性对抗问题（Benign Adversarial Problem）**

**良性对抗问题**：有些 prompt 在语言上是安全的（不包含明显有害词汇），但由于模型的学习数据分布，仍然会触发有害生成。现有 LLM 改写方法无法处理这类情况，因为它们只看语言表面而不考虑模型的生成分布。

## 核心方法

### DiSCO 框架

![DiSCO 方法流程](https://arxiv.org/html/2608.17067v1/pipeline.png)
*图2：DiSCO 完整流程：左侧构建模型特定的安全/不安全参考池；右侧通过对比束搜索优化 prompt 后缀*

DiSCO 是**训练-free、严格黑盒**的 plug-and-play 防御模块，完全在 prompt 层面操作，无需模型重训练、微调或访问模型内部。

#### 两阶段流程

**阶段1：构建模型特定参考池**

- 使用 I2P 数据集的 prompt 在目标模型上生成图像
- 通过分类器（NudeNet + Q16）过滤，构建**安全图像池** $\mathcal{P}^+$ 和**不安全图像池** $\mathcal{P}^-$

**阶段2：分布引导对比 Prompt 优化**

目标是找到安全 prompt $p^* = \mathcal{D}(p')$，满足：
$$\min_{\mathcal{D}} \mathbb{E}_{p'}\Big[\mathbb{P}_{x \sim G(\mathcal{D}(p'))}\big[\mathrm{SafeImg}(x)=0\big]\Big] \quad \text{s.t.} \quad \mathrm{Sem}(\mathcal{D}(p'), p') \geq \tau$$

对比评分函数（在 CLIP 嵌入空间中）：
$$J(\hat{p}) = \frac{1}{R}\sum_{x_i^+ \in \tilde{\mathcal{P}}_{\text{safe}}} \cos(\phi(\hat{x}), \phi(x_i^+)) - \frac{1}{R}\sum_{x_j^- \in \tilde{\mathcal{P}}_{\text{unsafe}}} \cos(\phi(\hat{x}), \phi(x_j^-))$$

最优后缀通过束搜索求解：
$$p^* = \arg\max_{\hat{p} \in \mathcal{B}} J(\hat{p})$$

实现细节：
- 使用轻量级语言模型（LLaMA-3-8B）进行自回归后缀扩展
- 束搜索宽度 K=4，后缀长度 T=16
- 每步采样 R=8 个参考图像
- 迭代自适应反馈直到生成安全内容

## 实验结果

### 评估设置

**测试模型**：SD v1.4、SD v2.0（UNet 架构）、Flux、SD 3（DiT 架构）

**对抗攻击**：
- **Ring-A-Bell**：黑盒攻击，无需访问生成器内部
- **UnlearnDiffAtk**、**MMA-Diffusion**：白盒攻击，使用模型梯度优化 prompt
- **P4D（Prompting4Debugging）**：针对安全机制的绕过攻击

**评估指标**：
- **ASR↓**（攻击成功率）：生成不安全图像的比例
- **CLIP 分数**：语义对齐质量
- **ImageReward**：感知偏好分数

### 主要发现

1. **跨模型泛化**：DiSCO 在 UNet 和 DiT 架构上均有效，展现出良好的架构无关性
2. **防御强白盒攻击**：即使面对使用模型梯度的白盒攻击，纯 prompt 层面的防御仍然有效
3. **解决良性对抗问题**：DiSCO 能够处理语言安全但语义危险的 prompt，这是 LLM 改写方法的盲区
4. **语义保真度**：在降低 ASR 的同时，CLIP 分数和 ImageReward 保持在合理水平

## 总结

DiSCO 代表了文生图安全防御的新方向：无需白盒访问、无需模型修改，通过纯 prompt 优化实现有效防御。其核心创新在于利用目标模型自身生成的图像构建分布感知的参考池，通过对比评分引导 prompt 远离不安全分布。

该方法对专有模型（如 Midjourney、DALL-E 等 API 服务）的防御具有重要实用价值。局限性在于依赖额外的分类器（NudeNet、Q16）的准确性，以及在极端对抗场景下迭代次数可能较多。未来工作可探索更高效的搜索策略和对更多类型有害内容的扩展。
