> 📄 **论文**：KVarN: Variance-Normalized KV-Cache Quantization Mitigates Error Accumulation in Reasoning Tasks
> 🔗 **arXiv**：[2606.03458](https://arxiv.org/abs/2606.03458)
> 🏢 **机构**：HUAWEI Computing Systems Lab（Lorenz K. Muller, Philippe Bich, Chiara Boretti 等）

## 一句话总结

KVarN 通过 Hadamard 旋转 + 双轴方差归一化的组合变换，消除 KV-Cache 量化中的 token 幅度误差，在 2-bit 精度下于 MATH500、AIME24、HumanEval 等生成式推理基准上树立新的 SOTA。

## 背景与问题

测试时扩展（test-time scaling）是当前推理型 LLM 的核心能力——通过生成更长的思维链来提升推理质量。但随着解码序列增长，KV-Cache 成为内存瓶颈：长序列推理会产生巨量的 K/V 矩阵需要缓存。

**KV-Cache 量化**是解决这一问题的主流方案（每个元素从 16-bit 压缩到 2-4 bit）。然而现有方法（如 KIVI、TurboQuant）主要在**预填充（prefill）场景**下评估，即对一个固定的长上下文做并行量化。而在**自回归解码**场景下，量化误差的行为截然不同：

**误差会随时间步累积！** 每次生成新 token 时，新 token 的 KV 向量被量化后加入 cache，量化误差逐步积累；而现有方法未针对此机制设计，尤其无法处理 **token 幅度误差**（token magnitude error），导致长序列推理性能急剧下降。

## 核心方法

### 关键诊断：token 幅度误差是罪魁祸首

![误差来源分析](https://arxiv.org/html/2606.03458/x1.png)
*图1：K 矩阵最大误差中，误差主要来自于幅度（magnitude）而非方向（direction）。KVarN 有效抑制了 token 幅度误差。*

研究发现，K 矩阵最大的量化误差 **70%+ 来自于错误的 token 幅度**，而非通道方向错误。仅用 Hadamard 旋转（QuaRot/SpinQuant 的方法）可以均衡通道离群点，但对 token 幅度误差无效。

### KVarN 两步变换

![KVarN 架构示意](https://arxiv.org/html/2606.03458/x2.png)
*图2：KVarN 流程。每个 token 在通道维做 Hadamard 旋转，生成一个 block（128 个 token）后在 token 和通道两个轴做方差归一化，最后用 RTN 量化。存储标准缩放、零点加一个额外缩放因子，平均 2.3 bit/元素。*

**步骤 1：Hadamard 旋转（通道维）**
- 在通道维应用 Hadamard 变换，消除通道离群点
- 可以预计算并吸收到相邻权重矩阵中，在线开销极小（O(N log N)）

**步骤 2：双轴方差归一化（Variance Normalization, VarN）**
- 在 token 维和通道维同时做 Sinkhorn 启发的方差归一化
- 防止量化过程改变最差情况 token 的 L2 范数（幅度）
- 与 Hadamard 旋转的误差抑制效果形成协同

**最终量化**：用 round-to-nearest (RTN) 量化，存储标准缩放/零点 + 一个额外缩放因子
- 平均 bit 宽：**2.3 bit/元素**（相比 2-bit 微增，但效果大幅提升）

### 无需校准（Calibration-Free）

KVarN 不需要任何校准数据集，可直接应用于任意 LLM，已提供 **vLLM 实现**。

### 误差累积分析

![重建误差随上下文增长](https://arxiv.org/html/2606.03458/x5.png)
*图5：Qwen3-4B 所有注意力层输出的平均重建误差。KVarN 在所有上下文长度下误差均低于 KIVI，且随上下文增长优势越来越大。*

引入"伪解码评估"（pseudo-decode evaluation）方法：将序列分成块，每块生成后即时量化，准确模拟自回归长序列解码中的误差累积。结果显示：
- **KIVI 的误差随上下文长度线性累积**
- **KVarN 有效抑制了这种累积趋势**

![离群误差对 KL 散度的影响](https://arxiv.org/html/2606.03458/x3.png)
*图3：5% 的最大离群误差对端到端 KL 散度的影响远大于其余 95%。KVarN 精准修复了这 5% 离群误差。*

## 实验结果

在 Qwen3-4B 等模型上，2-bit KV-Cache 量化的生成式基准测试：

| 方法 | MATH500 | AIME24 | HumanEval | IFEval |
|------|---------|--------|-----------|--------|
| BF16（无量化） | 基准 | 基准 | 基准 | 基准 |
| KIVI (2-bit) | 低 | 低 | 低 | 低 |
| Hadamard + KIVI | 中 | 中 | 中 | 中 |
| **KVarN (2.3-bit)** | **SOTA** | **SOTA** | **SOTA** | **SOTA** |

KVarN 在 2.3 平均比特精度下，性能超越或匹配现有 2-bit 方法，在所有推理和指令遵循基准上取得新 SOTA。

## 总结

KVarN 的贡献在于准确诊断了自回归 KV-Cache 量化的失效原因（token 幅度误差累积），并用优雅的双变换方案予以解决。Hadamard 旋转 + 方差归一化的组合既无需校准，又对推理任务的长序列解码高度友好。

该工作为测试时扩展场景下的 LLM 高效推理提供了重要基础。局限性：目前主要验证于 Qwen3 等模型，对不同架构（如 MLA/GQA）的适应性有待进一步研究；额外的去量化开销在极端批量大小下可能成为瓶颈。
