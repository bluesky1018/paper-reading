## 一句话总结

ClawKeeper 针对流行的开源自主智能体运行时 OpenClaw，提出了一套基于技能（Skill）、插件（Plugin）和监视器（Watcher）三层架构的实时多层安全防护框架，有效解决了工具集成、文件访问和 Shell 执行等权限带来的安全风险。

## 背景与问题

随着大语言模型（LLM）驱动的自主智能体（Agent）系统快速普及，OpenClaw 作为一款流行的开源自主智能体运行时平台，已广泛应用于各种企业级和研究任务中。然而，其开放的工具集成能力、文件系统访问权限以及 Shell 执行能力，带来了严重的安全隐患，包括**数据泄露**、**权限提升**（privilege escalation）以及**恶意代码执行**等风险。

现有的安全措施往往是局部性的、被动式的，缺乏对智能体整个执行生命周期的全面覆盖。特别是在复杂的多工具调用场景下，单一安全层次难以应对多样化的攻击向量。

OpenClaw 是当前最具代表性的开放式 Agent 运行时之一，其设计初衷是赋予 Agent 尽可能多的操作权限以完成复杂任务，但这也使其成为潜在攻击者的目标。ClawKeeper 的出现正是为了在不牺牲智能体能力的前提下，系统性地填补安全空白。

## 核心方法

ClawKeeper 采用三层解耦架构，从**指令级、运行时级和中间件级**三个层次对 OpenClaw 智能体进行全面安全防护：

### 第一层：基于技能（Skill）的防护

在指令层面，通过将**结构化安全策略直接注入智能体上下文**，实现对智能体行为的主动引导。这一层相当于为 Agent 内置"安全意识"，在规划阶段就过滤掉潜在的危险操作。

技能层的核心思想是：通过精心设计的安全技能（security skills），让 Agent 在执行任何敏感操作之前，首先进行安全性自评估，从根源上规避高风险行为。

### 第二层：基于插件（Plugin）的防护

在运行时内部，通过插件机制实现更深层次的安全执行控制，具体包括：
- **配置强化（Configuration Hardening）**：锁定高风险配置项，防止运行时被恶意修改
- **主动威胁检测（Proactive Threat Detection）**：在工具调用执行前进行威胁评估
- **持续行为监控（Continuous Behavioral Monitoring）**：实时追踪 Agent 的操作序列，识别异常模式

### 第三层：基于监视器（Watcher）的防护

监视器层是一个**完全解耦的中间件**，不嵌入 Agent 的内部逻辑，而是通过外部监控实现**实时执行干预**。这使得安全策略可以在不修改智能体核心代码的情况下进行动态更新和部署。

三层架构相互配合，形成纵深防御体系：

```
┌─────────────────────────────────────┐
│     Watcher（解耦中间件实时干预）     │
├─────────────────────────────────────┤
│     Plugin（运行时内部执行控制）      │
├─────────────────────────────────────┤
│     Skill（指令级安全策略注入）       │
├─────────────────────────────────────┤
│          OpenClaw Agent 核心         │
└─────────────────────────────────────┘
```

## 实验结果

论文通过系统性实验验证了 ClawKeeper 三层架构在以下方面的有效性：

| 防护维度 | 技能层 | 插件层 | 监视器层 |
|----------|--------|--------|----------|
| 数据泄露防护 | ✅ | ✅ | ✅ |
| 权限提升阻断 | ✅ | ✅ | ✅ |
| 恶意代码执行拦截 | ⚠️ 部分 | ✅ | ✅ |
| 运行时性能开销 | 极低 | 低 | 低 |
| 与 Agent 逻辑解耦 | ✅ | ❌ | ✅ |

三层协同防护能够显著降低各类安全风险，且由于监视器层采用解耦设计，整体架构对 Agent 原有功能的干扰极小。

## 总结

ClawKeeper 提出了一套系统性的、多层次的智能体安全防护方案。其核心贡献在于：（1）识别了 OpenClaw 等自主 Agent 运行时的关键安全风险；（2）提出了技能-插件-监视器三层协同防护架构，兼顾了安全性与可用性；（3）代码已开源，可直接部署于现有 OpenClaw 系统。

局限性方面，ClawKeeper 主要针对 OpenClaw 平台进行设计，对其他 Agent 运行时（如 LangGraph、AutoGen 等）的适用性尚需进一步验证。此外，随着 LLM 能力的持续进化，针对安全策略的对抗性绕过攻击也将不断演进，需要持续更新防护规则。

从更宏观的视角来看，ClawKeeper 的工作为 AI 安全领域的**纵深防御（Defense in Depth）**理念在 Agent 系统中的应用提供了重要参考，对于构建可信赖的自主 AI 系统具有重要意义。
