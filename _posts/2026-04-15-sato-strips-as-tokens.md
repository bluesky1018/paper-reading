# SATO：以三角条带为 Token，面向艺术家级网格生成的原生 UV 分割框架

> 论文：*Strips as Tokens: Artist Mesh Generation with Native UV Segmentation*
> 机构：香港大学、上海科技大学、德克萨斯 A&M 大学、Deemos Technology
> arXiv：[2604.09132](https://arxiv.org/abs/2604.09132)

---

## 背景：现有网格 Tokenization 的困境

在 3D 内容生成领域，如何将三角网格（mesh）转化为适合自回归模型处理的 token 序列，一直是核心难题。

### 现有方法的三大问题

**问题一：边流（Edge Flow）丢失**

传统方法（如逐顶点或逐面片的序列化）将网格"打散"为孤立的几何元素，完全丢失了专业建模师精心设计的**边流（Edge Flow）**——即网格边的走向应与肌肉走势、弯曲方向等高层语义对齐。

**问题二：UV 展开与网格生成割裂**

纹理映射需要 UV 坐标，而现有方法将网格生成和 UV 展开作为两个独立步骤：先生成几何，再用参数化算法展 UV。这种分割导致 UV 图不尊重几何边界，造成严重的纹理扭曲。

**问题三：三角面与四边形面不统一**

专业建模工作流同时使用三角面（渲染友好）和四边形面（变形友好），而现有生成模型只能处理其中一种，无法满足实际生产需求。

![现有方法对比](https://arxiv.org/html/2604.09132/figures/pipeline9.jpg)

## 核心创新：三角条带 Tokenization

SATO 的核心灵感来自计算机图形学中的经典数据结构——**三角条带（Triangle Strip）**。

### 什么是三角条带？

三角条带是一种紧凑表示三角网格的方式：相邻三角形共享一条边，形成"拉链"状的增长链。传统 GPU 渲染大量使用三角条带以减少顶点数据传输。

SATO 将这一思想用于网格 tokenization：

- **贪心拉链生长**：从坐标最小的未访问面出发，沿边流方向贪心地扩展条带
- **每个条带成为一段 token 序列**：条带内的面共享上下文，天然保留了边流信息
- **条带切换 token**：当一条条带结束时，插入特殊的"条带切换 token"，标记新条带的起点

![三角条带示意](https://arxiv.org/html/2604.09132/figures/Strip111.jpg)

---

## 三大核心创新

### 创新一：三角条带 Tokenization（保留边流）

**算法流程**：

1. 从全局坐标最小的未访问面作为种子
2. 沿两侧方向贪心扩展，优先选择与当前条带边流对齐的相邻面
3. 当无法继续扩展时，结束当前条带，发射"条带切换 token"
4. 重复步骤 1-3，直到所有面都被覆盖

**三级层级量化**：

为了用有限词表表示连续的顶点坐标，SATO 采用三级量化方案：

| 量化级别 | 分辨率 | 用途 |
|----------|--------|------|
| 粗粒度 | 4³ = 64 桶 | 快速定位大概位置 |
| 中粒度 | 8³ = 512 桶 | 区域精细化 |
| 细粒度 | 16³ = 4096 桶 | 局部高精度 |

三级联合编码理论精度达到 **512³**（约 1.34 亿个离散坐标）。

**增强词表结构**：

$$\text{Vocabulary} = \text{Geo Tokens} \cup \text{Strip-Transition Tokens} \cup \text{UV-Island Tokens}$$

![Tokenization 示意](https://arxiv.org/html/2604.09132/figures/tokenizer.jpg)

### 创新二：统一三角面/四边形面解码（δ 参数化）

SATO 用同一套 token 序列实现了三角面和四边形面的**统一表示**，核心在于引入步幅参数 δ：

- **δ=1**：相邻 token 对之间共享一条边 → **三角面**
- **δ=2**：隔一个 token 共享一条边 → **四边形面**

这意味着**模型只需改变解码参数，无需重新训练**，即可在三角和四边形网格之间切换。

![三角/四边形统一表示](https://arxiv.org/html/2604.09132/figures/quadtri.jpg)

**技术意义**：

| 特性 | 三角面（δ=1）| 四边形面（δ=2）|
|------|------------|--------------|
| 渲染友好性 | 高（GPU 原生）| 需转换 |
| 变形（绑定）友好性 | 低 | 高 |
| 生产工作流 | 游戏/实时渲染 | 影视/动画 |

### 创新三：原生 UV 图分割（首个此类框架）

UV 展开是纹理绘制的前提。传统方法：

1. 生成几何 → 2. 用参数化算法（如 LSCM、ABF）展 UV → 3. 纹理绘制

**问题**：参数化算法不了解网格的语义边界，UV 接缝位置不合理，导致纹理扭曲。

SATO 的方案：将 UV 图分割（UV chart partition）直接编码进 token 序列。

**UV 岛 Token（UV-Island Token）** 标记每个 UV 图的边界，模型在生成网格几何的同时，直接预测哪些面应该属于同一 UV 图。这样生成的 UV 分割**天然尊重几何语义**（如前脸、后脑、躯干等区域自然分割），大幅减少 UV 扭曲。

![UV 分割示意](https://arxiv.org/html/2604.09132/figures/uvseg1.jpg)

## 模型架构

SATO 采用 **0.5B 参数自回归沙漏变换器（Hourglass Transformer）**：

| 组件 | 参数量 | 细节 |
|------|--------|------|
| 点云编码器 | ~0.27B | 将输入点云编码为条件向量 |
| 沙漏 Transformer | ~0.23B | 21 层，变分辨率注意力 |
| 总参数 | ~0.5B | — |

**沙漏设计**：中间层使用压缩的 token 表示，减少长序列的计算复杂度；两端保留高分辨率特征，保证细节质量。

## 实验结果

### ShapeNet 几何质量（F1 Score）

| 方法 | F1 Score | 相对提升 |
|------|----------|----------|
| DeepMesh | 0.532 | 基准 |
| BPT | 0.605 | +13.7% |
| **SATO（本文）** | **0.807** | **+51.7%** |

SATO 的 F1 分数比 BPT 高 **33%**，比 DeepMesh 高 **52%**，达到显著 SOTA。

### 专业用户评分

邀请专业 3D 艺术家对生成的网格质量进行盲评（满分 3 分）：

| 方法 | 用户评分 |
|------|----------|
| BPT | 1.4 / 3.0 |
| **SATO（本文）** | **2.61 / 3.0** |

SATO 的用户评分接近 BPT 的 **2 倍**，表明其生成的网格更符合专业建模规范。

![网格质量对比](https://arxiv.org/html/2604.09132/figures/vs1.jpg)

### UV 质量（4 项指标，均优于 PartField）

UV 质量用 4 个指标评估（越接近 1.0 越好，面积失真越小越好）：

| 方法 | L2 Stretch（越小越好）| Area Distortion（越小越好）| 各向同性 | 连续性 |
|------|---------------------|--------------------------|----------|--------|
| PartField（GT 网格）| 0.921 | 0.849 | — | — |
| **SATO（本文）** | **0.979** | **0.562** | **更优** | **更优** |

SATO 在所有 4 项 UV 指标上均优于使用真实网格的 PartField——这意味着 SATO 生成的 UV 分割甚至比基于真实几何的传统参数化算法更好。

### UV 用户评分

| 方法 | 说明 | 评分 |
|------|------|------|
| PartUV（使用 GT 网格）| 最优参考条件 | 1.36 / 3.0 |
| **SATO（本文）** | 端到端生成 | **2.6 / 3.0** |

SATO 的 UV 用户评分是"使用真实网格的最优传统方法"的近 **2 倍**。

![UV 对比](https://arxiv.org/html/2604.09132/figures/uvcomp1.jpg)

### Tokenization 效率对比

| 方法 | Token 数 | 条带切换次数 | Tokenization 时间 |
|------|----------|------------|------------------|
| DeepMesh | 24,674 | 1,654 | 2.061 s |
| **SATO（本文）** | **20,830** | **981** | **0.319 s** |

SATO 的 token 序列更短（**-15.6%**）、条带切换更少（**-40.7%**），tokenization 速度快 **6.5×**。

## 局限性与未来方向

**当前局限**：

1. 训练需要大规模高质量网格数据（1.47M+），数据收集成本高
2. 四边形微调阶段数据量（120K）相对较少，复杂拓扑的四边形生成质量有提升空间
3. 当前模型以单个物体为输入，尚未支持场景级别的网格生成

**未来方向**：

1. **文本/图像驱动生成**：将 SATO 与多模态条件相结合，支持从文字描述直接生成带 UV 的网格
2. **动态网格生成**：将边流概念扩展到时序动画网格的生成
3. **更大规模模型**：当前 0.5B 参数规模有扩展空间，更大模型有望进一步提升复杂拓扑的生成质量

## 结论

SATO 通过三角条带 tokenization 这一核心创新，系统性地解决了现有网格生成方法的三大痛点：

| 问题 | SATO 的解决方案 | 效果 |
|------|----------------|------|
| 边流丢失 | 条带贪心生长 + 条带切换 token | F1 score 0.807，SOTA |
| UV 需要后处理 | 原生 UV 岛 token | UV L2 stretch 0.979，优于传统方法 |
| 三角/四边形割裂 | δ 参数化统一解码 | 同一模型支持两种拓扑 |

特别值得关注的是，**SATO 生成的 UV 质量甚至超越了使用真实几何的传统参数化方法**——这一结果表明，深度生成模型在学习几何-UV 联合分布方面具有传统算法所不具备的优势。

对于 3D 内容生产管线而言，SATO 代表了一个重要里程碑：**端到端生成满足专业标准的、带有规范 UV 展开的生产级网格**，正从概念走向现实。
