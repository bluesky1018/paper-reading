## 一句话总结

SpecEyes 提出"推测性感知"框架，用轻量小模型推测性回答视觉查询，通过**答案可分离性（Answer Separability）**置信门控来决定是否启用完整智能体工具调用链，实现 1.1–3.35× 加速，同时准确率提升高达 +6.7%。

## 背景与问题

智能体多模态大模型（Agentic MLLM）在视觉任务中会迭代调用感知工具（缩放、裁剪、OCR 等）构成工具调用链，每步依赖前步的观察结果，导致三大瓶颈：

1. **延迟爆炸**：端到端延迟与智能体深度 D 线性扩展，总复杂度 O(BDC)（B 个查询，深度 D，每步代价 C）
2. **并发崩溃**：每个查询的状态突变阻止了 GPU 批处理，严重降低吞吐量
3. **顺序依赖**：工具调用链的严格序列性无法并行化

现有的 token 级推测解码和 token 剪枝方法仍在固定的智能体循环内操作，无法从根本上突破这一结构性瓶颈。

## 核心方法

### 四阶段推测性推理流水线

SpecEyes 的核心思路是：**在启动昂贵的工具调用链之前，先尝试用轻量模型直接回答**。

| 阶段 | 操作 |
|------|------|
| Phase I | 大模型 M_L 判断是否需要工具调用（二元分类） |
| Phase II | 小型无状态模型 M_S（Qwen3-VL-2B）生成推测性答案 + 完整 logits |
| Phase III | **认知门控**：若 S_sep ≥ τ 则接受推测答案，否则回退 |
| Phase IV | 在 M_L 上运行完整智能体循环 |

### 答案可分离性评分（核心创新）

对于第 n 个 token，取排序后的 logit 值 ℓ[1] ≥ ℓ[2] ≥ ...，定义可分离性得分：

$$S_{\text{sep}}^{(n)} = \frac{\ell[1] - \mu_K}{\sigma_K + \epsilon}$$

其中 μ_K、σ_K 是 top-K logits 的均值和标准差。

**关键优势**：
- **尺度不变**（不同于 softmax）：不受 logit 绝对大小影响
- **竞争性度量**：衡量最优候选相对于其他候选的优势幅度
- **Min 聚合策略**：取序列中最低可分离性得分，作为最坏情况保障

实验对比三种聚合策略（mean、min、bottom-r），**Min 聚合**达到最佳判别性：错误样本坍缩到低分峰值，正确样本形成高分尖峰，两者分布差距（Δ）最大。

## 实验结果

**实验设置**：小模型 M_S = Qwen3-VL-2B，大模型 = DeepEyes/Thyme（最多5步工具调用），测试集 V\* Bench + HR-Bench + POPE，硬件 NVIDIA A100 40GB。

### 主要结果

| 方法 | 平均准确率 | 平均加速比 |
|------|-----------|---------|
| DeepEyes 基线 | 81.39% | 1.00× |
| SpecReason | 66.85% | 0.43×（反而变慢！） |
| **SpecEyes(min) + DeepEyes** | **84.26%** | **1.73×** |
| Qwen3-VL-2B 单独使用 | 78.93% | 4.13× |

| 方法 | 平均准确率 | 平均加速比 |
|------|-----------|---------|
| Thyme 基线 | 82.29% | 1.00× |
| **SpecEyes(min) + Thyme** | **83.99%** | **1.42×** |

**重要发现**：SpecReason（基于 token/轮次的推测）平均需要额外 414 token 和 3.48 轮交互，导致推理速度**反而降低至 0.37–0.61×**。SpecEyes 通过在查询层面而非 token 层面进行推测，从根本上避免了这一问题。

### 各子任务亮点

- V\* 相对位置：82.89% → **89.47%**（+6.58%），加速 1.90×
- POPE 对抗集：78.43% → **85.13%**（+6.70%），加速 2.13×
- HR-Bench：适度提升（1.08–1.13×，高分辨率输入同时抑制接受率）

## 总结

SpecEyes 提出了一种在**查询层面**而非 token 层面进行推测加速的全新范式，通过精心设计的答案可分离性置信评分实现准确的接受/拒绝决策。在实际测试中，SpecEyes 不仅加速推理，还因为过滤了难以直接回答的简单查询，反而**提升了整体准确率**。

局限性：对于需要大量高分辨率感知的任务（HR-Bench），小模型推测能力有限，加速收益较小；此外，对于不同任务域需要手动调整阈值 τ。代码已开源：[github.com/MAC-AutoML/SpecEyes](https://github.com/MAC-AutoML/SpecEyes)
