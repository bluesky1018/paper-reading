> 📄 **论文**：Video2GUI: Synthesizing Large-Scale Interaction Trajectories for Generalized GUI Agent Pretraining
> 🔗 **arXiv**：[2605.14747](https://arxiv.org/abs/2605.14747)
> 🏢 **机构**：Peking University

## 一句话总结

Video2GUI 提出了一个全自动框架，通过从无标注的互联网教程视频中提取 GUI 交互轨迹，构建了包含 1200 万条交互序列的大规模预训练数据集 WildGUI，显著提升了 GUI 智能体的泛化能力。

## 背景与问题

多模态大语言模型（MLLM）的快速发展推动了图形用户界面（GUI）智能体研究的兴起，但其泛化能力仍受到大规模训练数据匮乏的制约。现有数据集严重依赖昂贵的人工标注，且通常局限于狭窄的应用领域，难以覆盖真实世界的多样化应用场景。

GUI 智能体需要理解屏幕截图、识别 UI 元素并执行交互操作（点击、输入等），这要求训练数据既要覆盖广泛的应用类型，又要包含精确的动作标注。人工标注这类数据的成本极高，严重限制了 GUI 智能体的规模化发展。

互联网上存在大量 GUI 操作教程视频（如屏幕录制视频），这些视频中隐含着丰富的 GUI 交互知识，但如何自动提取结构化的训练数据一直是个难题。

## 核心方法

### 全自动视频数据提取框架

Video2GUI 采用从粗到细的过滤策略来识别高质量的 GUI 教程视频，并将其转换为结构化的智能体轨迹：

1. **视频筛选**：从 5 亿条视频元数据中识别 GUI 操作教程视频
2. **帧提取与对齐**：提取关键帧，识别 UI 状态变化
3. **动作标注**：自动识别点击、输入、滚动等交互动作的位置和类型
4. **轨迹构建**：将帧序列和动作整合为结构化的智能体交互轨迹

### WildGUI 数据集

通过将该流程应用于 5 亿条视频元数据，研究团队构建了 WildGUI：
- **规模**：1200 万条交互轨迹
- **覆盖范围**：超过 1500 个应用程序和网站
- **多样性**：覆盖 Web 浏览器、办公软件、创意工具等多种 GUI 环境

## 实验结果

在 Qwen2.5-VL 和 Mimo-VL 上使用 WildGUI 进行预训练，在多个 GUI 基准测试上取得了一致的性能提升：

| 模型 | 基准提升幅度 |
|------|------------|
| Qwen2.5-VL | 5-20% 性能提升 |
| Mimo-VL | 5-20% 性能提升 |

实验结果表明，WildGUI 的多样性和规模使模型获得了更强的跨应用泛化能力，在见过和未见过的应用上均有显著提升。

## 总结

Video2GUI 提供了一个可扩展的、无需人工标注的 GUI 训练数据构建方案，通过挖掘互联网视频中的隐含知识，极大地降低了构建大规模 GUI 智能体训练数据的成本。

该工作的局限性在于：视频质量参差不齐可能引入噪声；自动提取的轨迹精度可能不如人工标注；此外，视频教程可能偏向特定类型的 GUI 操作，导致数据分布偏差。
