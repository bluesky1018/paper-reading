## 一句话总结

LEAD 是一种即插即用的解码策略，通过在高熵推理阶段将离散 token 替换为概率加权连续嵌入，有效缓解多模态大推理模型（MLRM）中的幻觉问题。

## 背景与问题

多模态大推理模型（Multimodal Large Reasoning Models, MLRMs）在视觉问答任务上取得了显著进步，但幻觉问题（生成与视觉内容不符的文本）依然严峻。本文通过深入分析，发现了幻觉发生的关键模式：

**过渡词与高熵状态的关联**：诸如"because"、"however"、"wait"等过渡性词语往往伴随着高熵（高不确定性）状态，而这些高熵状态与幻觉的发生高度相关。

**离散推理的局限性**：传统的逐 token 自回归生成方式迫使模型在每个步骤做出"硬"的离散决策，即使模型内部对多个候选语义都有较高置信度，也只能选择其中一个 token 继续推理。这导致模型在不确定的推理节点上会走向某条固定路径，而忽略了其他同样合理的可能性，最终产生幻觉。

受**叠加表示理论**（Superposed Representation Theory）的启发，研究者提出：在高不确定性阶段，模型应当同时维护多个候选语义轨迹，而非强制坍缩为单一离散选择。

## 核心方法

LEAD（Latent Entropy-Aware Decoding）是一种高效的即插即用解码策略，其核心是**熵感知推理模式切换**机制。

![LEAD 整体框架](https://arxiv.org/html/2603.13366v1/x1.png)
*图1：LEAD 框架示意图。在高熵状态下，模型切换到概率加权连续嵌入；在低熵状态下，恢复离散 token 生成。*

### 熵感知模式切换

LEAD 在每个推理步骤实时监测 token 概率分布的熵值：

- **高熵状态**（不确定性高）：不使用argmax选取单个最高概率 token，而是计算**概率加权的连续嵌入**，将 top-k 候选 token 的嵌入按概率加权平均，作为下一步的输入。这保留了语义的多样性，避免过早收窄推理路径。

- **低熵状态**（不确定性低）：恢复标准的离散 token 选择，确保推理的确定性和可读性。

![过渡词熵值分析](https://arxiv.org/html/2603.13366v1/x2.png)
*图2：过渡词（because, however, wait 等）与高熵状态的相关性分析，验证了高熵与幻觉的关联假设。*

### 先验引导视觉锚点注入

为进一步防止模型在推理过程中"遗忘"视觉信息，LEAD 引入**先验引导视觉锚点注入**（Prior-Guided Visual Anchor Injection）策略：在高熵推理阶段，额外注入视觉特征作为锚点，鼓励模型持续关注图像内容而非单纯依赖语言先验。

![连续嵌入与离散 token 对比](https://arxiv.org/html/2603.13366v1/x3.png)
*图3：概率加权连续嵌入（左）与标准离散 token 选择（右）在高熵状态下的行为对比。*

### 算法流程

```
输入：问题 Q，图像 I，阈值 τ
1. 初始化：标准自回归生成
2. 在每个步骤 t：
   a. 计算 token 概率分布的熵 H_t
   b. 若 H_t > τ（高熵）：
      - 计算 top-k token 的概率加权嵌入 e_t = Σ p_i * embed(token_i)
      - 注入视觉锚点特征
      - 使用 e_t 作为下一步输入
   c. 若 H_t ≤ τ（低熵）：
      - 标准 argmax 选择 token
输出：生成文本
```

## 总结

LEAD 提供了一个优雅而高效的幻觉缓解方案：不需要额外的训练，不修改模型权重，只需在解码时引入熵感知的连续嵌入切换机制，便能有效减少多模态推理模型的幻觉现象。这种即插即用的特性使其具有广泛的实用价值。

局限性方面，连续嵌入在推理中不对应真实 token，使得推理链的可读性有所降低；此外，熵阈值的最优设置可能因模型和任务而异，仍需经验性调参。
