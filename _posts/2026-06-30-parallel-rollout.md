> 📄 **论文**：Parallel Rollout Approximation for Pixel-Space Autoregressive Image Generation
> 🔗 **arXiv**：[2606.27978](https://arxiv.org/abs/2606.27978)
> 🏢 **机构**：北京大学、深势科技（DP Technology）

## 一句话总结

PRA（并行展开近似）通过端到端学习低维中间状态代替高维像素块生成（解决输出侧难题），并通过同一像素解码器并行构建推理时像素输入近似（解决训练-推理差距），使 135M 参数的 PRA-S 超越 10 亿级像素空间 AR 模型，PRA-L（511M）以 FID=1.94 刷新 SOTA。

## 背景与问题

像素空间连续 Token 自回归（AR）生成直接将图像建模为原始像素块序列，无需离散化或预训练的 Tokenizer，概念简洁。然而，现有方法面临**两个耦合挑战**：

**输出侧：高维 Token 生成困难**
每个原始像素块是一个高维连续向量（16×16×3=768 维），单步预测误差大。

**输入侧：训练-推理差距**
教师强制（Teacher Forcing）训练在干净的真实前缀上训练，而推理时需要在自己生成的像素块上条件化。一旦生成错误，误差会通过自回归循环不断累积。

实验证明，这两个问题是相互耦合的：高维预测引入大误差，自回归循环将这些误差变成有缺陷的未来上下文，形成自增强的失败模式。

## 核心方法

### PRA 框架

PRA 通过两个互补的设计联合解决这两个挑战：

![PRA 框架图](https://arxiv.org/html/2606.27978v1/x1.png)
*图2：PRA 同时解决输出侧和输入侧挑战。输出侧：生成低维中间状态并解码为像素；输入侧：通过同一像素解码器并行构建类推理时像素输入。*

### 1. 端到端中间目标（输出侧）

为每个真实像素 Token $\mathbf{x}_i \in \mathbb{R}^d$ 学习低维中间状态 $\mathbf{z}_i \in \mathbb{R}^{d_z}$（$d_z = 16 \ll d = 768$），通过因果像素解码器 $D_\phi$ 映射回像素空间：

$$\mathbf{z}_i = g_\psi(\mathbf{x}_i, \mathbf{h}_{i-1})$$

**上下文感知目标**：将当前 Token 与 AR Transformer 的因果前缀表示 $\mathbf{h}_{i-1}$ 结合构建中间目标，比纯局部目标（仅编码当前 Token）效果更好。Token 掩码（$p_{\text{mask}}=0.5$）强制中间表示融合因果上下文。

推理时：AR 模型生成 $\hat{\mathbf{z}}_i$，像素解码器将其映射回 $\hat{\mathbf{x}}_i = D_\phi(\hat{\mathbf{z}}_i, \hat{\mathbf{z}}_{<i})$。

### 2. 并行构建类推理时像素输入（输入侧）

对每个中间目标状态 $\mathbf{z}_i$ 采样扰动版本：
$$\tilde{\mathbf{z}}_i^t = (1-t)\mathbf{z}_i^0 + t\mathbf{z}_i, \quad \mathbf{z}_i^0 \sim \mathcal{N}(\mathbf{0}, \mathbf{I}), \quad t \sim \mathcal{U}(t_{\min}, 1)$$

通过同一像素解码器解码为类推理时像素输入：
$$\bar{\mathbf{x}}_i = D_\phi(\tilde{\mathbf{z}}_i^t, \tilde{\mathbf{z}}_{<i}^t)$$

**关键**：所有位置独立构建，保持完全并行训练，无需昂贵的序列展开。

### 训练与推理

**训练**：两次并行 AR 前向传播：
1. 教师强制前向 → 获取中间目标 $\mathbf{z}_i$ 和类推理时输入 $\bar{\mathbf{x}}_i$
2. 在 $\bar{\mathbf{x}}_{<i}$ 条件下训练 Flow Matching 头生成 $\mathbf{z}_i$

**推理**：完全自回归，每步生成中间状态并解码为像素，保持"像素进、像素出"接口。

## 实验结果

### ImageNet 256×256 条件生成主要结果

| 方法 | 参数量 | FID↓ | IS↑ |
|------|--------|------|-----|
| **像素空间 AR 基线** | | | |
| FARMER-1.9B（最佳基线） | 1.9B | 3.60 | 269.2 |
| FractalMAR-H | 848M | 6.15 | 348.9 |
| **PRA（本文）** | | | |
| PRA-S | **135M** | **2.58** | 273.9 |
| PRA-B | 250M | **2.21** | 276.9 |
| PRA-L | 511M | **1.94** | 287.3 |
| **两阶段 AR 参考** | | | |
| MAR-L | 479+49M | 1.78 | 296.0 |
| SphereAR-L | 479+49M | 1.54 | 295.9 |
| **像素空间扩散参考** | | | |

PRA-S（135M）即超越最佳基线 FARMER-1.9B（10 倍大），PRA-L（511M）以 FID=1.94 刷新像素空间 AR SOTA。

| 模型 | 范式 | 空间 | Top-1 准确率(%) |
|------|------|------|---------------|
| DiT-XL/2 | 扩散 | 隐空间 | 43.28 |

PRA 在图像理解上显著超越所有 AR 和扩散基线，表明端到端像素空间 AR 学习对统一生成与理解的潜力。

## 总结

PRA 揭示了像素空间 AR 的两个根本瓶颈，并通过端到端低维中间目标和并行类推理时输入构建同时解决。训练只需两次并行前向传播，无需昂贵的序列展开，推理保持标准像素接口。在显著更少参数下超越现有最佳基线，且图像理解表现出色。

**主要局限性**：两次前向传播增加约 2 倍训练开销；中间状态维度 $d_z$ 的选择对性能敏感（$d_z=16$ 最优，$d_z=64$ 退化明显）；目前仅在 ImageNet 256 验证，更大分辨率和多样化数据上的表现有待探索。
