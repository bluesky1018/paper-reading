## 一句话总结
Kimi K3 是一个拥有 2.8 万亿参数的混合专家（MoE）大语言模型，激活参数量为 1040 亿，支持原生视觉能力和百万 Token 上下文窗口，并已完全开源权重。

## 背景与问题

随着大语言模型（LLM）规模的不断扩大，如何在维持推理效率的同时实现模型能力的突破，成为业界面临的核心挑战。混合专家（Mixture-of-Experts, MoE）架构作为一种有效的稀疏激活方案，能够在保持激活参数量适中的情况下大幅提升总参数规模。

Kimi 团队在前代 Kimi K2 的基础上，进一步探索了 MoE 模型的架构创新、训练效率提升以及后训练强化学习策略，推出了新一代旗舰模型 Kimi K3。与此同时，随着 Claude Fable 5、GPT-5.6 Sol 等商业闭源模型的崛起，开源社区迫切需要能够缩小与闭源前沿模型差距的高质量开源模型。

Kimi K3 正是在这一背景下诞生的，旨在成为开源社区中性能最强的模型之一，推动前沿智能的民主化。

## 核心方法

### 架构创新

Kimi K3 在架构层面引入了两项关键创新：

**1. Kimi Delta Attention（KDA）与 Attention Residuals**

传统 Transformer 在处理极长序列时，信息在序列长度和模型深度维度上的传递效率较低。KDA 通过改进注意力机制的信息流动路径，配合 Attention Residuals 设计，显著提升了跨序列长度和模型深度的信息传递效率，这对于支持百万 Token 上下文尤为关键。

**2. Stable LatentMoE**

在 MoE 路由方面，Kimi K3 采用了 Stable LatentMoE 设计，每个 Token 从 896 个路由专家中激活 16 个，实现了约 5.7% 的稀疏激活率。该设计在保持训练稳定性的同时，有效管理了专家均衡分配问题。

### 规模与效率

| 规格项目 | 数值 |
|---------|------|
| 总参数量 | 2.8 万亿 |
| 激活参数量 | 1040 亿 |
| 路由专家总数 | 896 个 |
| 每 Token 激活专家数 | 16 个 |
| 上下文窗口 | 100 万 Token |
| 相比 K2 的扩展效率提升 | ~2.5× |

### 后训练强化学习

后训练阶段是 Kimi K3 的重要亮点之一，覆盖多个维度：
- **通用推理**：提升模型在数学、逻辑等任务上的推理深度
- **代码智能**：强化复杂编程任务的长程执行能力
- **Agentic 场景**：通过 RL 训练模型在工具调用、多步任务执行中的鲁棒性
- **多推理强度等级**：支持按需调节推理深度，平衡延迟与质量

### 基础设施创新

为支持如此大规模的训练与推理，团队在基础设施层面进行了全方位创新：
- **算法-系统协同设计**：针对 KDA 的专项系统优化
- **完美均衡的专家并行训练**：结合高效内存管理实现稳定训练
- **百万 Token Agentic RL**：持久化 Rollout 和沙箱状态，支持超长序列强化学习
- **推理部署优化**：在延迟和吞吐量两方面均有针对性提升

## 实验结果

Kimi K3 在多个权威基准上展示了卓越性能：

| 评测维度 | 表现 |
|---------|------|
| 长程代码任务 | 前沿级性能 |
| Agentic 任务 | 前沿级性能 |
| 知识推理 | 前沿级性能 |
| 数学推理 | 前沿级性能 |
| 视觉理解 | 前沿级性能 |

**竞争格局**：
- 仍落后于 Claude Fable 5 和 GPT-5.6 Sol
- 优于所有其他经评测的开源及商业模型
- 是目前开源社区性能最强的模型之一

## 总结

Kimi K3 代表了开源大语言模型领域的重要里程碑。通过 Kimi Delta Attention、Stable LatentMoE 等架构创新以及多域强化学习后训练，该模型在保持高训练效率的同时，实现了接近顶级商业模型的性能水平。

模型权重的完整开源（CC BY-NC-ND 4.0 许可）将极大促进学术研究和技术应用的发展。主要局限在于总参数量达 2.8T，推理部署对硬件要求较高；此外，在最难任务上与 Claude Fable 5、GPT-5.6 Sol 仍有一定差距，后续版本有望在架构和训练数据方面进一步突破。
