> 📄 **论文**：Not All Tokens Deserve Equal Credit: Counterfactual Sensitivity Credit Reallocation for Long-CoT Reasoning
> 🔗 **arXiv**：[2607.27888](https://arxiv.org/abs/2607.27888)
> 🏢 **机构**：南京大学、上海交通大学

## 一句话总结

揭示 GRPO 均匀 token 信用分配和 OPSD 特权似然偏移的根本缺陷，提出 CSCR（反事实敏感度信用重分配）：降低高敏感 token 的信用权重，在五个竞赛级数学基准上比 GRPO 提升最高 +8.1pp。

## 背景与问题

在长思维链（Long-CoT）推理的 RLVR 训练中，存在两种主流方法：

**方法一：GRPO（无需评论器）**
将响应级奖励均匀广播到序列中所有 token，**默认所有 token 贡献相等**。直觉上这是有问题的：推理过程中的"Therefore"、"Let x ="与真正关键的计算步骤重要性肯定不同。

**方法二：OPSD（在策略自蒸馏）**
使用特权自教师（带有正确答案提示的版本）提供密集的分布监督，假设似然偏移编码了可靠的答案对齐信息。

本文提出核心问题：**OPSD 的特权似然偏移真的可靠吗？**

## 核心发现：特权偏移不可靠

### 反事实分析实验

通过固定 400 个 on-policy 轨迹，在两种对立条件下重新计分：
- **正特权**：断言答案正确（"这是一个绝佳的解答，推理过程完美无缺..."）
- **负特权**：断言答案错误

**惊人发现：**

| 指标 | 含义 | 数值 |
|------|------|------|
| 方向一致率（M） | 正负条件下偏移方向相同的比例 | **均值 0.068** |
| 正负重叠（D） | 两条件优化信号的重叠程度 | **均值 0.028** |
| 反向转换率（CPC） | 真正有用的方向性信号比例 | **均值仅 0.583** |

**这意味着大多数 token 在正负两种对立条件下向同一方向偏移**——特权偏移主要反映的是 **token 的表面形式替代性（可被替换的程度）**，而非答案对齐的真实方向性信息。

### 高敏感 Token 的特征

分析最高/最低偏移 token 的统计：

| Token 类型 | 代表性 token | 特征 |
|-----------|------------|------|
| 大正偏移 | "The"(8328), "."(6233), ","(4354) | 高度可替换的表面形式 token |
| 大负偏移 | "The"(13979), "."(11061), ","(7399) | 同类表面形式 token |
| 接近零偏移 | "<空格>"(256692), ","(168425) | 功能性、内容无关 token |

**关键洞察**：大偏移主要集中在高度可替换的表面形式 token（冠词、标点、连接词），而承载问题特定推理内容的 token 反而不敏感。

## CSCR：反事实敏感度信用重分配

基于上述发现，**CSCR（Counterfactual Sensitivity Credit Reallocation）** 通过以下方式扩展 GRPO：

1. **计算反事实敏感度**：对每个 token 计算在正/负两种条件下的偏移差异
2. **重分配信用**：高敏感 token 获得更低的 token 级权重
3. **归一化**：重归一化 token 级优势以保持信用预算不变

GRPO 的均匀加权：
$$\mathcal{L}_{GRPO} = -\frac{1}{|y|} \sum_i A_i \log \pi_\theta(y_i|x, y_{<i})$$

CSCR 的加权：
$$\mathcal{L}_{CSCR} = -\frac{1}{|y|} \sum_i w_i \cdot A_i^{CSCR} \log \pi_\theta(y_i|x, y_{<i})$$

其中 $w_i$ 与 token $i$ 的反事实敏感度成反比，$A_i^{CSCR}$ 是归一化后的优势。

## 实验结果

在五个竞赛级数学推理基准上（AMC23、AIME24、AIME25、AIME26、SMT25），所有结果报告为 Mean@32：

| 方法 | AMC23 | AIME24 | AIME25 | AIME26 | SMT25 |
|------|------|--------|--------|--------|-------|
| **Qwen3-1.7B 基线** | 84.1 | 45.5 | 35.5 | 35.2 | 38.1 |
| + GRPO | 84.1 | 47.4 | 36.7 | 37.4 | 39.5 |
| + OPSD | 83.6 | 45.8 | 34.2 | 33.8 | 36.1 |
| + SDPO | 84.5 | 46.3 | 36.2 | 34.1 | 37.7 |
| + RLCSD | 84.8 | 47.7 | 37.2 | 36.9 | 40.8 |
| **+ CSCR** | **88.8** (+4.7) | **50.1** (+4.6) | **43.6** (+8.1) | **42.2** (+7.0) | **44.0** (+5.9) |

| 方法 | AMC23 | AIME24 | AIME25 | AIME26 | SMT25 |
|------|------|--------|--------|--------|-------|
| **Qwen3-4B 基线** | 96.2 | 70.7 | 62.9 | 62.8 | 55.4 |
| + GRPO | 96.9 | 71.5 | 65.0 | 65.3 | 57.4 |
| **+ CSCR** | **97.8** (+1.6) | **74.4** (+3.7) | **68.3** (+5.4) | **67.2** (+4.4) | **59.0** (+3.6) |

CSCR 在 1.7B 规模上对 GRPO 提升最高 **+8.1pp**（AIME25），且 OPSD 在所有基准上均未能超越 GRPO，印证了特权偏移不可靠的核心发现。

## 总结

本文通过精心设计的反事实实验，揭示了当前主流 Long-CoT RLVR 方法中两个被忽视的根本缺陷：GRPO 的均匀信用分配忽略了 token 的差异化贡献，OPSD 的特权偏移主要反映表面形式替代性而非真实的答案对齐方向。基于此提出的 CSCR 方法简洁有效，在多个竞赛级数学基准上取得显著提升。

局限性方面，CSCR 需要为每个 token 计算反事实敏感度，增加了额外的前向传播开销；同时，当前实验主要集中在数学推理任务，对代码生成等其他 RLVR 场景的适用性有待验证。反事实重打分的高质量引导提示设计也需要一定的人工工程，其自动化方法是未来工作的重要方向。
