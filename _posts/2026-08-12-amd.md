> 📄 **论文**：Agent Memory Distillation: Empowering Small LLM Agents with Hierarchical Teacher Memory
> 🔗 **arXiv**：[2608.07169](https://arxiv.org/abs/2608.07169)
> 🏢 **机构**：KAIST AI

## 一句话总结

AMD（Agent Memory Distillation）是一个无需训练的框架，通过工作流记忆、子任务记忆和函数记忆三层次结构，将大型教师智能体的结构化知识迁移至小型学生智能体（4B/8B），在工具调用任务上平均提升 27.2% 准确率。

## 背景与问题

记忆系统对提升智能体性能已展现出巨大潜力，但对小型语言模型的探索几乎是空白。小型模型（4B/8B）的核心困境在于：它们难以自主生成足够多的成功轨迹来从自身经验中学习，因此依赖自我进化的记忆方法对它们效果极差。

现有记忆方法（如 Reflexion、ExpeL、AWM）虽然有效，但大多假设智能体本身足够强大，能够从经验中提炼有效知识。对于小型模型，这一假设不成立。将大型教师模型的成功经验结构化地传递给小型学生模型，是一条更有前景的路径——但如何有效组织和利用这种迁移的知识，是核心挑战。

## 核心方法

**AMD 框架概述**

AMD 从教师智能体的成功轨迹中构建三种互补记忆类型，在推理时注入学生智能体：

![AMD 框架架构](https://arxiv.org/html/2608.07169v1/x1.png)
*图1：AMD 框架整体架构——三层次记忆生成、检索和注入流程*

**三层次记忆设计**

设 $\mathcal{M} = \mathcal{M}^{wf} \cup \mathcal{M}^{st} \cup \mathcal{M}^{fn}$ 为完整记忆库：

1. **工作流记忆（Workflow Memory, $\mathcal{M}^{wf}$）**：编码任务级策略，从成功轨迹中提取高层任务完成策略，在任务开始前注入系统提示词
2. **子任务记忆（Subtask Memory, $\mathcal{M}^{st}$）**：以中间粒度提供具体行为示例，捕捉子任务层面的有效操作模式
3. **函数记忆（Function Memory, $\mathcal{M}^{fn}$）**：捕获每个函数的调用规范和常见陷阱，在调用相关函数前动态检索注入

工作流和子任务记忆在任务开始前主动注入，函数记忆则在调用相关函数前实时检索注入。

![三层次记忆结构示意](https://arxiv.org/html/2608.07169v1/x2.png)
*图2：三层次记忆的粒度对比——从任务级策略到函数调用规范*

**记忆检索与注入**

推理时，学生智能体通过基于嵌入的余弦相似度从 $\mathcal{M}$ 检索相关记忆，低于最小相似度阈值的记忆被丢弃：
- 工作流记忆：以任务指令为检索查询，检索 top-k 条目，前置到系统提示词
- 子任务记忆：以当前子目标为检索查询，在任务开始前注入
- 函数记忆：以函数名和描述为检索查询，在调用前动态注入

![记忆检索流程](https://arxiv.org/html/2608.07169v1/x3.png)
*图3：推理时的记忆检索和注入流程详图*

## 实验结果

**三个基准测试：**
- **AppWorld**：多应用智能体基准，通过 Python API 调用完成复杂多步任务（168 个测试用例）
- **BFCL V3**：函数调用基准，评估正确调用函数的能力
- **ToolSandbox**：工具使用多样性评估

**主要结果：**

| 基准 | AMD vs 零样本（平均提升） | vs 最强基线 |
|------|------------------------|------------|
| AppWorld | **+27.2%p** | +稳定提升 |
| BFCL V3 | **+11.2%p** | +稳定提升 |
| ToolSandbox | **+3.4%p** | +稳定提升 |

AMD 在所有模型（Qwen3-4B、Qwen3-8B 及其 Instruct 变体）和所有基准上一致超越所有基线，而对比的三个基线记忆方法（ReasoningBank、MemP、SASM）效果不稳定，在多种情况下性能甚至低于零样本。

**消融实验（记忆组件贡献）：**

| 记忆组合 | AppWorld (Qwen3-4B) |
|---------|-------------------|
| 零样本 | 14.88% |
| + 工作流记忆 | 提升 |
| + 子任务记忆 | **最大增量提升**（+25.0%p 超过仅工作流） |
| + 函数记忆 | 额外小幅提升 |

子任务记忆的贡献最为关键，表明具体行为示例对复杂长程任务至关重要。

## 总结

AMD 提出了一条解决小型模型智能体能力不足的新路径：不依赖小型模型自身的自我进化，而是将大型教师模型的成功经验结构化蒸馏为层次化记忆，在推理时高效注入。这一无需训练的框架在工具调用任务上展示了显著而稳定的性能提升。

论文的主要局限在于：记忆的质量高度依赖教师模型的成功轨迹质量，如果教师模型在特定任务上表现不佳，记忆蒸馏效果也会受限。此外，随着任务和工具集扩展，记忆库的管理和检索效率可能成为挑战。未来方向包括动态更新记忆库的机制，以及研究如何在学生模型通过记忆积累经验后进一步提升其自主生成高质量轨迹的能力。
