## 一句话总结

本文提出了一个名为 **Agent Humanization Benchmark（AHB）** 的评测框架，系统研究移动端 GUI Agent 的触控行为是否能通过"屏幕上的图灵测试"——即在完成任务的同时，让自动化行为在运动学层面无法被检测器识别为非人类操作。

---

## 背景与问题

### GUI Agent 的时代困境

随着大型多模态模型（LMM）的迅速发展，移动端 GUI Agent 已经能够自主完成刷视频、下单购物、规划旅程等复杂任务。然而，这些 Agent 在数字平台上正面临一个日益严峻的现实挑战：**平台的反自动化检测机制**。

现实中，各大平台（社交媒体、电商、短视频等）都部署了行为分析系统，通过分析用户的触控轨迹、点击时长、操作节奏等特征，区分"真人用户"与"自动化脚本"。一旦被识别为 Bot，轻则限流封号，重则触发平台的安全响应。

这引出了一个核心问题：**GUI Agent 能不能不仅"做得到"，还要"做得像人"？**

### 传统研究的盲点

过去对 GUI Agent 的研究几乎全部聚焦于**任务成功率**（Task Success Rate），即"Agent 有没有完成指定任务"。然而，这些研究完全忽视了"Agent 的行为方式是否符合人类运动模式"这一维度。

本文作者发现，哪怕是当前最先进的 LMM-based Agent（如 UI-TARS、MobileAgent-E），其触控行为在统计特征上与真人存在显著差异，可以被简单的机器学习分类器以接近 100% 的准确率识别出来。

### 问题形式化：对抗性 MinMax 优化

作者将这一问题建模为检测器与 Agent 之间的 **MinMax 博弈**：

- **检测器 D_Θ**：目标是最大化区分人类与 Agent 行为的能力
- **Agent G_Φ**：目标是在完成任务的前提下，最小化被检测器识别的概率

Agent 的优化目标可以写作：

```
min_{G_Φ} λ · L_detect(G_Φ, D_Θ) + (1 - λ) · L_utility(G_Φ)
```

其中 λ 控制**可模仿性（Imitability）与实用性（Utility）的权衡**。这一框架揭示了拟人化研究的核心张力：过度追求"像人"可能会牺牲任务完成能力。

## 核心方法

### 数据集构建

研究团队构建了一个覆盖 **21 款应用、5 大场景类别** 的移动端触控行为数据集：

| 场景类别 | 代表应用 |
|----------|----------|
| 社交媒体 | 微博、Instagram 等 |
| 购物 | 淘宝、Amazon 等 |
| 旅行规划 | 携程、Airbnb 等 |
| 视频流媒体 | 抖音、YouTube 等 |
| 办公与学习 | 钉钉、Coursera 等 |

人类受试者涵盖三类人群：**年轻男性/女性、中年人、老年人**，以覆盖真实世界中多样化的触控习惯。

参与测试的 Agent 包括：**UI-TARS、MobileAgent-E（GPT-4o）、MobileAgent-E（Claude-3.5-Sonnet）、AgentCPM、AutoGLM**。

所有触控事件提取 **24 个统计特征**，涵盖运动学（速度、加速度）、几何学（轨迹偏差、端点精度）和时序动态（动作间隔、点击时长）三个维度。

### 行为差异的初步发现

作者在正式建立基准之前，首先对人类与 Agent 的行为差异进行了系统分析，发现三类核心差异：

**差异一：滑动轨迹的形态**

人类的滑动轨迹因生理运动特性呈现自然的弧线形态，并伴有细微的肌肉颤抖（motor noise）；而 Agent 的滑动轨迹几乎是完美的直线向量，缺乏任何生理噪声。

![人类滑动 vs Agent 滑动对比](https://arxiv.org/html/2604.09574v1/icml2026/images/20251012_114348_gesture_on_image_17.png)

*图2a：真人用户的滑动轨迹（带有自然弧度和细微抖动）*

![Agent 滑动轨迹](https://arxiv.org/html/2604.09574v1/icml2026/images/20250925_105538_gesture_on_image_8.png)

*图2b：GUI Agent 的滑动轨迹（近乎完美的直线，缺乏人类运动噪声）*

**差异二：动作时间间隔的分布**

人类的动作间隔呈长尾分布，峰值集中在接近 0 的位置（快速连续操作）；而 Agent 由于需要等待 LMM 推理，间隔时间显著偏长：
- UI-TARS：5–10 秒
- MobileAgent-E：50–80 秒

![动作间隔分布对比](https://arxiv.org/html/2604.09574v1/x2.png)

*图3a：人类与 Agent 动作时间间隔的分布差异*

**差异三：点击持续时长**

真人点击呈近似高斯分布，峰值在 0.05–0.10 秒；Agent 的点击时长则几乎集中在接近零的尖峰处。

![点击时长分布对比](https://arxiv.org/html/2604.09574v1/x3.png)

*图3b：人类与 Agent 点击持续时长的分布差异*

### Agent Humanization Benchmark（AHB）评测框架

AHB 从两个维度评估 Agent 的拟人化效果：

**可模仿性（Imitability）**：以检测器分类准确率的反向指标衡量。当分类器准确率趋近于 0.5 时，意味着 Agent 的行为已无法与真人区分，即通过了"图灵测试"。

**实用性（Utility）**：即在施加拟人化约束后的任务成功率，衡量拟人化改造对任务完成能力的影响。

检测器分为两个层级：
- **基于规则的检测器**：滑动精度、时间间隔精度、点击时长精度
- **基于学习的检测器**：使用 24 维特征训练的 SVM 和 XGBoost 分类器

### 四种拟人化策略

**策略一：B 样条噪声注入（B-Spline Noise Injection）**

在滑动路径的直线轨迹附近随机生成控制点，利用 B 样条曲线生成带有自然弯曲的轨迹：

```
S(t) = Σ N_{i,p}(t) · c_i
```

该方法计算效率高，无需离线数据库，能有效解决轨迹形态问题，但在统计层面可能仍然可被区分。

**策略二：数据驱动的历史轨迹匹配（History Matching）**

从真人历史轨迹数据库中采样，通过仿射变换将参考轨迹对齐到目标操作向量。这种方法完整保留了真实人类的速度曲线和微小抖动，效果更优，但需要离线数据库支撑。

**策略三：伪动作注入（Fake Actions）**

在 Agent 推理等待期间，注入微小的交互行为（微滚动、悬停等），以掩盖 LMM 推理带来的异常长时间间隔。

**策略四：延长点击时长（Longer Presses）**

从拟合真实人类数据的高斯分布中采样点击持续时长，替换 Agent 原有的近零点击。

## 实验结果

### 基线脆弱性：原始 Agent 几乎 100% 可被检测

未经任何拟人化处理的 Agent，在所有应用场景的检测准确率接近满分：

| 检测器 | 检测准确率 |
|--------|-----------|
| XGBoost | ~0.995（接近完美检测） |
| SVM | ~0.98 |

这一结果证实了研究的出发点：当前所有主流 GUI Agent 的行为都极易被检测。

### 拟人化策略效果对比

以社交媒体场景为例：

| 模式 | 策略 | SVM 准确率 | XGBoost 准确率 | 时间间隔准确率 | 点击时长准确率 | 任务成功率 |
|------|------|-----------|--------------|-------------|-------------|-----------|
| 原始 | 无 | 0.9817 | 1.0000 | 0.8838 | 0.9977 | 0.4833 |
| 在线 | 历史匹配 | 0.9756 | 1.0000 | 0.9060 | 0.9976 | 0.6667 |
| 离线 | 历史匹配 | 0.9633 | 0.9450 | 0.8838 | 0.9977 | — |
| 离线 | B 样条 | 0.9633 | 0.9817 | 0.8838 | 0.9977 | — |

**关键发现**：历史匹配策略在检测规避效果上持续优于 B 样条方法，在所有应用场景中表现一致。

### 实用性代价：伪动作的双刃剑效应

伪动作注入策略在旅行规划场景中暴露出严重的实用性问题：任务成功率从 **0.75 骤降至 0.15**。这说明盲目注入伪动作会干扰 Agent 的任务执行逻辑，造成巨大的性能损失。

![拟人化策略对检测准确率的影响](https://arxiv.org/html/2604.09574v1/x4.png)

*图4：不同拟人化策略在各应用场景下对检测准确率的影响对比*

### 特征分析：什么最难模仿？

**容易拟人化的特征**（路径形态类）：
- `maxDev`（轨迹最大偏差）：从 0.9969 降至 0.5515（在线历史匹配后）
- `ratio_end_to_len`（端点与长度比）：从 0.9878 降至 0.5798

**难以拟人化的特征**：
1. **端点精度（endY）**：Agent 必须精确点击 UI 控件中心，添加坐标噪声会导致点击失败，因此无法有效模糊。
2. **动作间隔**：伪动作能绕过规则检测，但会引入其他可被学习型检测器捕捉的统计特征，且严重损害任务成功率。

![特征数量与检测准确率的关系](https://arxiv.org/html/2604.09574v1/x5.png)

*图5：检测准确率随使用特征数量增加的变化趋势（原始 Agent 与拟人化 Agent 对比）*

检测准确率与特征数量呈**对数关系**，5–10 个特征后趋于饱和。即使施加拟人化策略，当前方法与真人行为之间仍存在持续的可检测差距。

### 理论支撑

作者在附录 C 中证明了三个定理：

1. 检测器效能的上界由人类分布与 Agent 分布之间的 **Jensen-Shannon 散度** 决定
2. 方差注入（B 样条）**严格减小** JS 散度
3. 历史匹配策略是**渐近最优**的，使 Agent 行为分布收敛于人类分布

## 深度思考：这项研究的更大意义

### 从"能做到"到"做得像"的范式转变

本文提出的核心洞察在于：衡量 GUI Agent 的标准不应仅是"任务是否完成"，还必须包括"行为是否自然"。这一视角的转变，对 Agent 的实际部署和生态融入具有重要意义。

### 拟人化的固有张力

研究揭示了一个深层矛盾：**拟人化所需的某些特征（如端点精度的随机化）与任务成功所需的特征（精确点击目标元素）存在本质冲突**。这意味着完全的拟人化可能在技术上存在理论上限。

### "Guard Agent"架构的启示

作者提出了一个未来架构设想：使用轻量级"卫兵 Agent"来识别安全注入伪动作的时机，而不干扰主 LMM 的推理流程。这种解耦设计思路或许是解决实用性-可模仿性权衡的有效路径。

### 伦理维度

需要指出的是，GUI Agent 的拟人化研究本身具有双重性：一方面，它使 Agent 在合法使用场景（如辅助功能、自动化办公）中更好地融入人类数字生态；另一方面，也可能被滥用于绕过平台的反欺诈机制。这一伦理张力值得研究社区持续关注。

## 未来方向

| 方向 | 描述 |
|------|------|
| 端到端拟人化训练 | 训练 LMM 在生成动作时直接输出拟人化轨迹，而非事后修正 |
| 个性化拟人化 | 模拟特定用户的运动习惯，而非群体平均特征 |
| 跨模态拟人化 | 将方法扩展至打字动态、滚动阅读等其他行为模态 |
| 意图层检测 | 未来检测器可能从运动学层面转向对行为意图的建模，需要更深层的应对策略 |

## 总结

本文做出了以下几项重要贡献：

1. **提出了 GUI Agent 拟人化这一新研究范式**，将评测维度从"任务成功"扩展到"行为自然度"
2. **构建了首个专门用于移动端触控行为检测的基准数据集**，覆盖 21 款应用、多类人群
3. **系统量化了当前主流 Agent 的行为暴露程度**，证明其在简单检测器面前几乎没有隐蔽性
4. **提出并评估了四种拟人化策略**，揭示了历史匹配方法的优越性及各策略的适用边界
5. **用理论证明支撑了实验发现**，建立了拟人化改进效果的理论上界

尽管当前方法距离真正"通过屏幕上的图灵测试"还有相当差距，但本文开创性地定义了这一问题的研究框架，为 GUI Agent 在真实数字生态中的可持续部署奠定了基础。
