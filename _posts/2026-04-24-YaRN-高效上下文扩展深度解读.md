## 基本信息

- **作者**: Bowen Peng, Jeffrey Quesnelle, Honglu Fan, Enrico Shippole
- **机构**: Nous Research, EleutherAI, U. Geneva
- **发表**: arXiv 2023-08
- **arXiv**: [2309.00071](https://arxiv.org/abs/2309.00071)

## 一句话总结

提出 **YaRN (Yet another RoPE extensioN method)**——把 RoPE 的频率缩放技术系统化到极致,在 NTK-aware、NTK-by-parts 的基础上再加 **attention 温度系数**,用极少 fine-tune 步数(**400 步**、**0.1% token 预算**)就把 LLaMA 的 4K context 扩到 **64K-128K** 且质量几乎无损。是现代长上下文 LLM 的事实标准扩展方法之一,被 Mistral 7B、Qwen、DeepSeek 等大量采用。

## 背景:RoPE 的长度外推困境

### 问题:RoPE 直接外推会崩

RoPE(Rotary Position Embedding)用复数旋转编码相对位置:

$$
(q_m)_k = q_k \cdot e^{i m \theta_k},\quad \theta_k = b^{-2k/d}
$$

其中 $b$ 通常取 10000。当推理长度 $m$ 超过训练长度时,**高频分量**(小 $k$)的 $m \theta_k$ 很快进入训练没见过的范围,attention 分数飘移 → PPL 爆炸。

### 已有方案的局限

1. **Position Interpolation (PI, Chen 2023)**:直接把 $m$ 缩小 $s$ 倍($s =$ 扩展比例),等价于把所有 $\theta_k$ 压 $s$ 倍。**问题**:高频分辨率被牺牲,模型对短距离的辨别能力下降
2. **NTK-aware (bloc97 2023)**:对 $b$ 做非线性放缩 $b' = b \cdot s^{d/(d-2)}$。**问题**:完全不 fine-tune 时效果好,但再训一点反而会退化(因为高频仍被压缩)
3. **NTK-by-parts (bloc97 2023)**:把频率分为高/中/低三段,低频压缩、高频不动、中间插值。**问题**:手工分段边界难调

YaRN 站在 NTK-by-parts 的肩膀上,加入关键的**注意力温度修正**。

---

## 核心机制

### 1. NTK-by-parts 的延续:频段分治

RoPE 的维度 $k$ 对应"旋转波长"$\lambda_k = 2\pi / \theta_k = 2\pi b^{2k/d}$。

YaRN 定义一个**频段判别函数** $r(k)$:

- $r(k) \leq \alpha$:"高频",旋转快,对短距离敏感,**不缩放**(保留局部信息)
- $r(k) \geq \beta$:"低频",旋转慢,在训练中未完整见过,**线性缩放**(PI 式)
- $\alpha < r(k) < \beta$:过渡区,**平滑插值**

默认 $\alpha = 1, \beta = 32$,这是实验上对 LLaMA 最优的设定。

### 2. YaRN 的独门武器:attention 温度

![YaRN 在训练中动态调整 attention 的温度系数,使 softmax 概率分布不因 context 变长而过度平坦化。](/assets/img/yarn/x2.png)
_Figure 2:Dynamic scaling 中的注意力温度调整_

长 context 下一个微妙的问题:**softmax 熵增**。

- attention 分数矩阵变大($N$ 从 4K → 64K)
- 即使分数分布不变,softmax 后每个 token 的相对权重会被"摊薄"(熵增)
- 模型的选择性关注能力下降,表现为 PPL 升高

YaRN 的修复:给 attention logits 乘一个温度 $1/t$:

$$
\text{softmax}\!\left(\frac{q^\top k}{t \sqrt{d}}\right),\quad \frac{1}{t} = 0.1 \ln(s) + 1
$$

其中 $s$ 是扩展比例。这个公式是从一堆经验拟合得到的,效果惊人:**单加这一项在 64K 上 PPL 再降 10-20%**。

![不同 mscale(即 1/t)参数对 PPL 的影响,存在明显最优点,YaRN 公式恰好逼近这个最优。](/assets/img/yarn/x4.png)
_Figure 4:Attention 温度系数与 PPL 的关系——YaRN 公式精确命中最优点_

### 3. 综合公式

对第 $k$ 维旋转角:

$$
\theta_k^{\text{YaRN}} = \theta_k \cdot (1 - \gamma(k)) + \theta_k \cdot \frac{1}{s} \cdot \gamma(k)
$$

其中 $\gamma(k) \in [0,1]$ 是 NTK-by-parts 的平滑插值权重。再配合 softmax 温度 $1/t$ 作为 attention 一端修正。

## 训练成本:零头中的零头

YaRN 宣称的最大突破是**训练效率**:

| 方法 | Fine-tune Token 数 | 最终 Context |
|------|-------------------|-------------|
| PI (Chen 2023) | 2500 步 × 64k = 160B tokens | 32K |
| NTK-aware | 0 步(免 fine-tune) | 8K 可用 |
| **YaRN-64K** | **400 步 × 64k = 26B tokens** | **64K** |
| **YaRN-128K** | **600 步 × 64k = 39B tokens** | **128K** |

相比 PI 节省 **~6×** 训练量,相比从头训练节省 **~1000×**。

## 实验结果

![在 Proof-pile 等长文本数据集上,不同 context 长度下的 PPL 对比。YaRN 在所有长度上显著优于 baseline,特别是 64K+ 长度段。](/assets/img/yarn/x3.png)
_Figure 3:各方法在不同长度的 PPL——YaRN 全线领先_

关键数字(LLaMA-2 7B,64K context):

| 方法 | Proof-pile PPL @ 64K |
|------|---------------------|
| Raw RoPE (no fine-tune) | > 1000(崩溃) |
| PI (2500 步) | 3.81 |
| NTK-aware | 4.82 |
| NTK-by-parts | 3.57 |
| **YaRN (400 步)** | **3.40** |

训练量减少 $6\times$,PPL 还更低。

## Dynamic YaRN:推理时在线调整

一个实用小技巧:**推理时根据当前 seq_len 动态调整扩展比例 $s$**,而不是固定。

- 输入 2K tokens 时,$s = 1$(完全不扩展)
- 输入 32K tokens 时,$s = 32000/4000 = 8$
- 输入 128K tokens 时,$s = 32$

这样短输入不受长扩展的性能损失,长输入自动适配。几行代码实现,但带来更平滑的性能曲线。

---

## 为什么影响大

### 1. 让"2K → 128K" 成为"周末能做的事"

在 YaRN 之前,扩到 128K 要么不可用(免 fine-tune 方案质量糟),要么天价(全量重训)。YaRN 让**一张 A100 训几小时**就能完成,直接改变了社区的长上下文经济学。

### 2. 作为 Mistral、Qwen 长版本的默认方案

- Mistral 7B v0.2(32K)
- Qwen 2.5(128K 和 1M)
- DeepSeek-V2(128K)

都采用 YaRN 或其变体。"YaRN + Flash Attention 2 + GQA + SWA" 成为 2024 年长上下文 LLM 的标配组合。

### 3. 推动"频段分治"思维普及

YaRN 让业界普遍接受:**位置编码的不同频段扮演不同角色,对它们应当区别对待**。后续 LongRoPE(2024)、CLEX(2024)等继续在这条路线上精细化。

### 4. 温度修正是一个可跨方法复用的小技巧

$1/t = 0.1 \ln(s) + 1$ 这个公式虽然是为 YaRN 拟合的,但后续很多长上下文方案(包括非 RoPE 的)都借鉴了"扩展时补偿 attention 熵增"这个思想。

---

## 局限

1. **依赖 RoPE**:YaRN 只适用于使用 RoPE 的模型。ALiBi / T5 bias / 可学绝对位置无法直接用
2. **固定扩展比**:训练时要提前决定扩展比例 $s$。想用 Dynamic 要在推理侧处理
3. **超长 (256K+) 质量依然下降**:YaRN 不是"免费午餐",~32× 扩展(4K→128K)是实用边界,更长仍有退化
4. **短文本可能略有退化**:训练了 long context 的 YaRN 模型在 <2K 输入上可能略差于原模型(0.1~0.3 PPL)

---

## 读完这篇你真正该带走的 4 件事

<callout emoji="white_check_mark" background-color="light-green" border-color="green">
1. **RoPE 的扩展不是"统一缩放",而是"频段分治"**:高频保留、低频压缩、中间平滑——这是 YaRN 的核心思想,影响了所有后续长上下文工作
2. **Attention 温度是长 context 的隐藏变量**:softmax 熵随 $N$ 增大会稀释选择性,$1/t = 0.1 \ln(s) + 1$ 是一个可以直接复用的补偿公式
3. **扩展的成本可以压到 0.1% 训练预算**:YaRN 证明了长 context 能力是"微调可解决的问题"而非"必须从头训练"——这是长 context 时代经济可行的关键
4. **Dynamic scaling 让短输入也受益**:推理时根据实际 seq_len 在线调 $s$,几行代码的工程改动带来全程平滑性能
</callout>
