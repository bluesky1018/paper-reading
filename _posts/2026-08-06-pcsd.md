> 📄 **论文**：PCSD: Persistent Consistency for Self-Distillation in Agentic Reinforcement Learning
> 🔗 **arXiv**：[2608.01837](https://arxiv.org/abs/2608.01837)
> 🏢 **机构**：北京理工大学、中科院等

## 一句话总结
PCSD 通过在多个时间尺度上聚合教师-学生对数概率差异，计算连续的token级蒸馏权重，实现了在智能体强化学习中的自适应、位置感知的教师监督分配，在 ALFWorld 和 WebShop 上显著超越基线方法。

## 背景与问题

强化学习（RL）已成为 LLM 后训练的主流范式，并被延伸至智能体交互轨迹的训练场景。在 Agentic RL 中，**在策略自蒸馏（On-Policy Self-Distillation, OPSD）** 通过冻结的特权上下文教师（privileged-context teacher）在策略采样轨迹上提供密集监督，辅助稀疏环境奖励，改善细粒度信用分配。

然而，现有 OPSD 方法存在一个根本问题：**无差别地将教师指导应用于所有 token 位置**。但实际上，教师指导的有用性在 token 位置间差异显著——对某些位置的指导能有效提升策略，而对其他位置则可能产生噪声甚至负面影响。

如何在智能体 RL 训练中自适应地分配教师监督强度，实现位置感知的精细信用分配，是本文要解决的核心问题。

## 核心方法

### PCSD 框架

**PCSD（Persistent Consistency Self-Distillation）** 是一种在策略自蒸馏方法，通过持久一致性模式计算连续的 token 级蒸馏权重，选择性地分配教师监督。

![PCSD 框架](https://arxiv.org/html/2608.01837v1/x1.png)
*图1：PCSD 框架。学生通过多轮交互收集在策略轨迹，冻结的技能增强教师为学生生成的 token 评分。PCSD 跨多个时间尺度聚合教师-学生对数概率差异，生成精细化的 token 级权重。*

### 关键组件

#### 1. 持久一致性评估（Persistent Consistency Assessment）

对于 token 位置 $i$，计算教师-学生对数概率差异 $\delta_{k,i}$——值越大，说明教师对该采样 token 的相对支持度越高。

**核心思想**：单点差异仅提供一个 token 的证据，过于嘈杂。因此在局部窗口内聚合差异，利用持久一致的差异模式估计教师指导的局部有用性：

$$w_{k,i} = f\left(\{\delta_{k,j}\}_{j \in \mathcal{W}(i)}\right)$$

#### 2. 自适应聚合机制（Adaptive Aggregation Mechanism）

单一固定窗口无法捕捉响应中异质的差异模式：
- **短窗口**：保留细粒度位置信息，但对局部波动敏感
- **长窗口**：提供更强的平滑效果，但降低位置分辨率

PCSD 通过软自适应窗口化，根据局部方差调整短窗口和长窗口持久一致性估计的相对贡献，实现两者的最优融合。

### 多轮智能体 RL 框架

在多轮智能体任务中，LLM 智能体与外部环境交互。在回合 $k$ 时：

$$\mathbf{y}_k=(y_{k,1},y_{k,2},\ldots,y_{k,T_k})\sim\pi_\theta(\cdot\mid s_k)$$

PCSD 在GRPO框架基础上，将稀疏轨迹级奖励与加权的 token 级蒸馏损失相结合：

$$\mathcal{L}_{PCSD} = \mathcal{L}_{GRPO} + \lambda \sum_{k,i} w_{k,i} \cdot KL(\pi_\theta \| \pi_{teacher})_{k,i}$$

## 实验结果

### 主要结果

在 ALFWorld（具身家庭任务）和 WebShop（电商购物）两个基准上评测：

- Score 和 Acc 上，PCSD 均优于 GRPO 和 SDAR

## 总结

PCSD 通过持久一致性评估和自适应聚合机制，解决了 Agentic RL 中教师监督无差别分配的问题，实现了精细化的 token 级信用分配。该方法轻量、即插即用，可直接集成到现有的 OPSD 框架中。

**核心创新**：(1) 提出持久一致性度量，利用局部差异模式估计 token 级教师指导有用性；(2) 软自适应窗口化机制平衡精度与鲁棒性；(3) 无需额外参数开销，与 GRPO 等标准框架无缝集成。

**局限性**：PCSD 依赖于高质量的特权上下文教师；在教师能力远弱于学生的场景下效果可能有限；超参数（窗口大小、权重系数）的设置仍需一定调整。
