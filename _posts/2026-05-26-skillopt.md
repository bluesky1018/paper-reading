> 📄 **论文**：SkillOpt: Executive Strategy for Self-Evolving Agent Skills
> 🔗 **arXiv**：[2605.23904](https://arxiv.org/abs/2605.23904)
> 🏢 **机构**：Microsoft Research

## 一句话总结

SkillOpt 将 Agent 的"技能文档"视为可训练的外部状态，通过一个冻结的优化器模型对技能进行受控的文本空间迭代优化，实现跨模型、跨执行框架的稳定性能提升。

## 背景与问题

大型语言模型正越来越多地被部署为 Agent，从单步提示调用到具备工具调用、文件操作和验证器的多步执行框架（如 Codex、Claude Code 等）。在这类场景下，领域适配不再只是关于模型权重或系统提示——还需要改进 Agent 收集证据、调用工具、遵循领域规范以及格式化输出的**程序化行为**。

**Agent 技能（Skill）**为这种程序化适配提供了一个自然接口：技能是一种可移植的自然语言制品，封装了程序、领域启发式规则、工具策略以及输出约束。然而，现有技能的创建方式存在根本缺陷：它们要么是人工手写的，要么是一次性 LLM 生成的，要么是通过松散控制的自我修订进化的——这些方式都不像深度学习优化器那样具备可重现性，也无法在反馈下可靠地超越起始点。

核心挑战在于：**如何像优化神经网络权重一样，系统性、可控地优化自然语言格式的 Agent 技能？**

## 核心方法

SkillOpt 是首个系统可控的文本空间 Agent 技能优化器。其核心思想是将技能视为冻结 Agent 的**外部状态**，使用独立的优化器模型对评分轨迹进行分析，并生成有界的 add/delete/replace 编辑操作。

![SkillOpt 总览](https://arxiv.org/html/2605.23904v1/x1.png)
*图1：SkillOpt 总览。目标模型使用当前技能执行任务，前沿优化器模型将轨迹转化为有界编辑，验证门仅接受提升验证性能的编辑。*

### 优化流程（Pipeline）

**前向传播（Rollout Evidence）：**
目标模型使用当前技能执行一批任务，收集成功和失败的轨迹，每条轨迹附有 [0,1] 范围的奖励评分。

**反向传播（Minibatch Reflection）：**
优化器模型对 minibatch 中的成功/失败轨迹进行反思分析，提出有界的 add/delete/replace 编辑，通过调度的编辑预算进行合并和排序。

**验证门（Validation Gate）与拒绝编辑缓冲区：**
候选技能仅在通过保留验证集的严格性能提升验证后才被接受。被拒绝的编辑被存入缓冲区，作为后续更新的负反馈。

**Epoch 级慢速/元更新（Slow/Meta Update）：**
保留跨 epoch 的长期教训，而不改变目标模型本身，使技能训练更加稳定。

![SkillOpt 优化管道](https://arxiv.org/html/2605.23904v1/x2.png)
*图2：SkillOpt 优化管道。冻结的目标模型使用当前技能执行一批 rollout；优化器模型在 minibatch 上进行反思，提出有界编辑，通过验证门后更新技能。*

### 关键设计原则

- **文本学习率预算**：控制每次迭代的编辑量，防止技能发生剧烈突变
- **零推理时延开销**：部署时只需加载优化后的技能文档，不增加额外的模型调用
- **框架无关性**：同一套优化流程适用于直接对话、Codex agentic loop 和 Claude Code 三种执行框架

## 实验结果

SkillOpt 在 6 个 benchmark、7 个目标模型、3 种执行框架（直接对话、Codex、Claude Code）上进行评估，涵盖 SearchQA、SpreadsheetBench 等多个任务，共 52 个（模型, benchmark, 框架）组合评估单元。

**主要结论：**

| 场景 | 提升幅度 |
|------|---------|
| GPT-5.5 直接对话 | 无技能准确率提升 **+23.5 点** |
| GPT-5.5 + Codex loop | 无技能准确率提升 **+24.8 点** |
| GPT-5.5 + Claude Code | 无技能准确率提升 **+19.1 点** |

在所有 52 个评估单元中，SkillOpt 均达到最优或并列最优，优于所有竞争基线，包括：人工手写技能、一次性 LLM 生成技能、Trace2Skill、TextGrad、GEPA 和 EvoSkill。

![性能趋势](https://arxiv.org/html/2605.23904v1/x3.png)
*图3：跨 epoch 检查点的性能趋势。在 SpreadsheetBench、SearchQA 等 benchmark 上，性能随优化 epoch 稳步提升。*

**迁移实验**进一步证明，优化后的技能制品在以下场景仍保留价值：
- 跨模型尺度迁移（从大模型到小模型）
- 在 Codex 和 Claude Code 执行环境之间迁移
- 迁移到相邻数学 benchmark，无需进一步优化

## 总结

SkillOpt 提出了一个严格的文本空间技能优化框架，将 Agent 技能的优化提升到与神经网络权重优化同等的可控和可重现水平。通过验证门、编辑缓冲区和 epoch 级慢速更新等机制，SkillOpt 实现了稳定且持续的性能提升，同时保持了技能的可移植性和部署零开销的优势。

然而，SkillOpt 目前依赖于一个"前沿优化器模型"来生成编辑，这意味着优化过程本身的质量受限于优化器模型的能力。此外，文本空间优化相较于梯度优化的理论收敛保证仍需进一步研究。未来工作可以探索更高效的优化器模型选择策略，以及在更多样化的 Agent 任务类型上的泛化能力。
