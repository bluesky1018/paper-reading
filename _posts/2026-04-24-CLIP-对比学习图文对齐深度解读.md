## 基本信息

- **作者**: Alec Radford, Jong Wook Kim, Chris Hallacy 等(OpenAI)
- **机构**: OpenAI
- **发表**: ICML 2021
- **arXiv**: [2103.00020](https://arxiv.org/abs/2103.00020)
- **全名**: *Learning Transferable Visual Models From Natural Language Supervision*

## 一句话总结

OpenAI 的 **CLIP (Contrastive Language-Image Pre-training)**——用 **4 亿对互联网图文对** 做**对比学习**,训练一个把**图像和对应描述映射到同一 embedding 空间**的双塔模型。核心创新:不用人工标注的类别,**让图片与"描述它的自然语言句子"配对**——这让 CLIP 具备**零样本迁移**能力,可以不 fine-tune 直接做 ImageNet 分类(76% top-1,匹配监督训练的 ResNet-50)。CLIP 开启了整个 VLM 时代,是后续 Flamingo、LLaVA、Stable Diffusion、Sora 等几乎所有视觉-语言模型的基础零件。

![CLIP 的双塔对比学习:图像 encoder + 文本 encoder,把 (image, text) pair 映射到相同 embedding 空间。用对比 loss 让正样本 similarity 高,负样本低。零样本推理时,把类别名当作 "a photo of [class]" 的 prompt,和图像做 cosine 相似度。](/assets/img/clip/x1.png)
_Figure 1:CLIP 的对比学习架构与零样本推理_

## 背景:计算机视觉的标注困境

### ImageNet-style 监督学习的局限

2012-2020 年计算机视觉的主导范式是 **ImageNet 监督预训练 → 下游 fine-tune**:

- **需要大量标注**:1000 类 × 每类 ~1300 张的人工标注
- **类别固定**:只能预测 1000 个预定义类别
- **难扩展**:加新类别要重新标注 + 重训

问题是根本的——**视觉概念是无限的**,但监督学习只能覆盖预定义集合。

### Natural Language Supervision 的希望

OpenAI 团队的想法:**互联网上有海量的 "图像 + 描述"**——这些描述是**自然语言**,而非固定类别。如果能利用这种弱监督:

- **数据无限**:全网图片都带 alt text、caption
- **类别无限**:自然语言可以描述任何概念
- **可零样本迁移**:新类别写一个描述就能用

之前的 VirTex、ConVIRT、ICMLM 等工作尝试过这个思路,但规模都 < 1M 图像。**CLIP 的突破是 scale**。

## 核心机制

### 数据:WIT (Web Image Text)

OpenAI 自建数据集 **WIT**:

- **4 亿对 (image, text)**
- 从 Common Crawl + Web 爬取
- 粗略过滤(去重、语言检测等)
- **没有人工标注**

规模是之前 VirTex 类工作的 **500×**。

### 对比学习 Loss

![CLIP 的对比 loss:batch 内有 N 对 (image, text),计算 N×N 相似度矩阵。对角线是正样本(匹配对),非对角是负样本。训练目标:对角线高,非对角低。](/assets/img/clip/x2.png)
_Figure 2:InfoNCE 对比 loss_

对一个 batch 内 $N$ 对 $(I_i, T_i)$:

- 计算 $N \times N$ 的 cosine similarity 矩阵 $S$
- **对角线**是正样本($S_{ii}$,真实匹配)
- **非对角**是负样本

用 **InfoNCE loss**(两个方向):

$$
L = \frac{1}{2} \left(L_{\text{image→text}} + L_{\text{text→image}}\right)
$$

其中 $L_{\text{image→text}}$ 让每个 image 偏好正确的 text 而非 batch 内其他 text:

$$
L_{\text{image→text}} = -\frac{1}{N}\sum_i \log \frac{\exp(S_{ii}/\tau)}{\sum_j \exp(S_{ij}/\tau)}
$$

$\tau$ 是温度(可学)。

### 架构

**Image encoder**:ResNet-50 / ViT
**Text encoder**:12 层 Transformer

两者输出 512 维 embedding,L2 normalize 后算 cosine similarity。

### Zero-shot Classification

![Zero-shot 分类的关键技巧:把类别名嵌入 prompt 模板 "a photo of a {class}",这样 text encoder 看到的是完整句子而非孤立类别名,效果大幅提升。](/assets/img/clip/x3.png)
_Figure 3:Zero-shot 分类的 prompt engineering_

训练好 CLIP 后,zero-shot 分类:

1. 每个类别嵌入 prompt:`"a photo of a {cat}"`, `"a photo of a {dog}"`, ...
2. Text encoder 编码所有 prompts
3. Image encoder 编码 query image
4. 对 image embedding 做 cosine 相似度,取最高的 class

**不需要 fine-tune**——直接跑!

### Prompt Engineering

作者发现:**不同 prompt 模板对精度影响巨大**。

- `"a {class}"`:73.9%
- `"a photo of a {class}"`:76.2%
- `"a photo of a {class}, a type of pet"`(加 hint):更高

甚至提出 **prompt ensembling**:多个 prompt 结果平均——ImageNet 到 77.2%。

## 实验结果

### 1. Zero-shot ImageNet

| Model | ImageNet top-1 |
|-------|---------------|
| ResNet-50 (supervised) | 76.2% |
| Visual N-Grams (old) | 11.5% |
| **CLIP (ViT-L/14)** | **76.2%** |

**零样本 CLIP 匹配监督 ResNet-50**——第一次有 zero-shot 模型达到这个水平。

### 2. 下游任务 zero-shot

![CLIP 在 27 个下游任务的 zero-shot vs supervised baselines 对比:多数任务 CLIP zero-shot 接近或超过 supervised fully trained 模型。](/assets/img/clip/x4.png)
_Figure 4:CLIP 在 27 个 benchmark 的 zero-shot 表现_

- **OCR 任务(SST)**:Zero-shot 88.9%
- **视频动作识别(UCF101)**:80.3%
- **某些 fine-grained 分类**(Birdsnap, Food101):接近 supervised

但也有弱项:
- 某些需要细微分辨的(MNIST)CLIP 意外弱(~88%,低于 CNN 99%+)
- 地理识别、极其 specialized 的任务仍需 fine-tune

### 3. Robustness

CLIP 对 distribution shift 异常 robust:

- ImageNet-R、ImageNet-Sketch、ImageNet-A 等 adversarial 数据集上 CLIP 大幅超过 supervised ResNet-50
- **因为 CLIP 学的是 "概念" 而非 "数据集 bias"**

这是 CLIP 最深刻的贡献——**自然语言监督让模型学到更 general 的表征**。

## 历史影响

### 1. VLM 时代的起点

CLIP 之后,所有 vision-language 工作都建立在它上面:

- **Flamingo**(2022):用 CLIP 的 vision encoder + LLM
- **LLaVA**(2023):CLIP 作 projector 的输入
- **Stable Diffusion**:CLIP 作 text-image conditioning
- **DALL-E 2**:CLIP 作 alignment
- **Sora**:底层某种形式的 CLIP-like alignment

可以说,**没有 CLIP 就没有现代生成式 AI 的视觉部分**。

### 2. 对比学习 + 大数据范式

CLIP 证明 **"大量噪声数据 + 对比学习"** 可以学到比 "小量干净数据 + 监督" 更好的表征。这个范式被广泛采用:

- **ALIGN** (Google 2021):18 亿 noisy pair,类似思路
- **OpenCLIP**(LAION 2022):开源复现
- **SigLIP** (2023):改进的 sigmoid loss
- **DINOv2** (2023):纯视觉对比学习

### 3. "Zero-shot" 成为 benchmark 必测

CLIP 让 zero-shot 成为 vision 模型的**标配评测**。之前的视觉 benchmark 主要 fully-supervised,CLIP 之后 zero-shot setting 也是默认。

### 4. Prompt Engineering 在 vision 的出现

CLIP 的 prompt 变体实验证明——**prompt 对 vision 模型也有大影响**。这让 prompt engineering 从 NLP 扩散到 vision。

### 5. OpenCLIP 开源生态

LAION 组织的 **OpenCLIP** 复现了 CLIP 并开源,在 LAION-2B (20 亿图文对) 训练。OpenCLIP 成为开源社区的 VLM 基础。

## 局限

### 1. Zero-shot 的上限

在某些任务上 zero-shot 不如 supervised。当 class 很细分(某些医学图像)或数据分布很特殊,CLIP 的零样本不够。

### 2. Bias

CLIP 学了互联网的 bias——对性别、种族的 stereotype 都会反映在 embedding 里。**"a photo of a CEO"** 会偏向白人男性。这是 web-scale 数据的必然代价。

### 3. 无 generation 能力

CLIP 只做 matching,**不能生成图像或文本**。后续工作(DALL-E、Flamingo)才引入 generation。

### 4. 细粒度视觉弱

对需要精细感知(数数、空间关系、细微差异)的任务,CLIP 相对弱。Q-Former、MLLM 等后续工作补上这块。

## 读完这篇你真正该带走的 4 件事

<callout emoji="white_check_mark" background-color="light-green" border-color="green">
1. **自然语言是无限的类别标签**:CLIP 证明用自然语言做监督信号,可以突破 ImageNet 固定类别的限制。这个洞察改变了整个 vision 领域
2. **大量噪声数据 + 对比学习 = 强表征**:CLIP 的 4 亿对不需要人工标注,噪声不少,但 scale 胜过质量。这个范式至今有效
3. **Zero-shot 不是 "freebie",是能力的自然展现**:CLIP 的 zero-shot 能力来自自然语言的 compositional 性——理解了 "photo of X" 这个模板,所有 X 都能处理
4. **Prompt engineering 不只是 NLP 概念**:CLIP 的 "a photo of a {class}" 技巧证明 prompt 在 vision 上同样强大——这启发了后续 CLIP 变体和 VLM 设计
</callout>
