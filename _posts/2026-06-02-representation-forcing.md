> 📄 **论文**：Representation Forcing for Bottleneck-Free Unified Multimodal Models
> 🔗 **arXiv**：[2605.31604](https://arxiv.org/abs/2605.31604)
> 🏢 **机构**：ByteDance Seed

## 一句话总结

Representation Forcing（RF）通过训练解码器在生成像素之前自回归预测视觉表示 token，使像素空间统一多模态模型无需外部 VAE 即可匹敌基于 VAE 的方案，同时提升多模态理解能力。

## 背景与问题

统一多模态模型（UMM）旨在单一模型中同时处理感知（理解）和生成。当前主流 UMM 方案依赖预训练好的冻结 VAE 进行图像生成——VAE 负责提供压缩的隐空间，供 Transformer 在其中进行扩散生成。

这种架构存在结构性瓶颈：
- VAE 是独立预训练的外部模块，与模型其余部分耦合紧密
- 无法实现真正的端到端原生多模态学习

然而，若直接移除 VAE、在原始像素空间生成，模型需要同时学习高级结构和低级细节，导致显著的质量下降（GenEval 分数从 0.52 跌至 0.25）。

## 核心方法

*图1：架构对比。(a) 现有 UMM 依赖冻结 VAE，存在结构瓶颈；(b) 直接像素空间生成消除瓶颈但损失质量；(c) Representation Forcing 通过自回归预测视觉表示 token 提供结构引导，无需外部隐空间。*

### Representation Forcing 的核心思想

**关键创新**：将视觉表示从感知输出转变为生成目标。

具体而言，RF 训练解码器在像素生成之前，自回归地预测理解编码器提取的视觉表示作为中间 token：
1. 理解编码器（默认使用 DINOv3）提取图像的高级视觉表示
2. 解码器在像素块之前，先以自回归方式预测这些表示的离散版本（通过码本量化）
3. 预测出的表示 token 留在上下文序列中，通过共享 Transformer 的自注意力为像素扩散提供结构引导

### 训练流程

![训练流程](https://arxiv.org/html/2605.31604v1/x3.png)
*图3：Representation Forcing 训练流水线。解码器处理统一的 [文本 token, 表示 token, 像素块] 序列；文本和表示 token 使用因果注意力预测，像素块使用双向注意力与扩散损失。*

序列结构：**[文本 token (T) → 表示 token (R) → 像素块 (P)]**

- T 和 R：标准自回归预测（语言建模损失）
- P：双向注意力 + 扩散损失，同时因果关注所有前置 T 和 R

### 关键设计选择

- **离散 vs 连续表示**：离散化预测（GenEval 0.76）远优于连续回归（GenEval 0.26），因为离散 token 避免了误差累积，且自然保留高级结构同时丢弃细粒度细节
- **表示引导 vs 对齐**：RF 将预测表示直接放入解码器序列（0.76），优于 REPA 的辅助对齐目标（0.43），因为直接条件化更有效
- **理解编码器选择**：DINOv3（自监督）优于 SigLIP2（语言对齐），因空间结构信息更丰富

## 实验结果

**文本到图像生成**（Table 1）：

| 方法 | GenEval | DPG-Bench |
|------|---------|-----------|
| 无 RF 的像素空间 | 0.25 | - |
| VAE-based（无 RF） | 0.52 | - |
| VAE-based（有 RF） | 0.77 | ~83 |
| BLIP3-o（VAE based UMM） | 0.84 | - |
| **RF-Pixel（本文，无 LLM 改写）** | **0.84** | **84.15** |
| RF-Pixel（有 LLM 改写） | 0.88 | - |

**多模态理解**（Table 2）：在 8 个基准中 6 个 Pixel+RF 优于 VAE+RF，无 VAE 的像素空间 RF 在理解任务上普遍优于 VAE-based 方案。

## 总结

Representation Forcing 以优雅的方式解决了像素空间生成的核心难题：通过让模型在生成像素前先"思考"高级视觉结构，实现了 VAE-based 方案的竞争力。更重要的是，同一套表示机制同时服务于理解（解释视觉输入）和生成（引导像素输出），指向感知与生成的更紧密融合。

主要局限性：目前从预训练语言模型初始化而非从头多模态预训练，且聚焦于静态图像，未扩展到视频等时序模态。
