## 一句话总结

Meta 的 **LLaMA 3** 系列——**8B / 70B / 405B** 三个规模的开源模型,是第一次有开源大模型**在主流 benchmark 上与 GPT-4 / Claude 3 Opus 正面抗衡**。关键技术选择:(1) **15T tokens 训练**(比 Chinchilla 推荐的 800B 大 20×,极端 overtraining);(2) **数据质量大提升**——多阶段清洗 + classifier + 去重;(3) **训练稳定性**——QK-Norm、z-loss、careful hyperparam;(4) **16K context + 后期 scale 到 128K**;(5) **post-training 配方完整**(SFT → Rejection Sampling → DPO)。这篇 92 页的技术报告是"**如何训一个 SOTA 开源模型**"的完整 playbook,被业界广泛学习和复制。

## 背景:开源 vs 闭源的距离

### 2023 年的差距

- **GPT-4**(2023-03):闭源,MMLU 86.4,HumanEval 67
- **LLaMA 2 70B**(2023-07):开源,MMLU 68.9,HumanEval 29.9
- **Claude 3 Opus**(2024-03):闭源,MMLU 86.8

开源模型落后闭源 **~15-40 分**。

Meta 的目标:**做一个开源模型,正面打 GPT-4 / Claude 3**。

---

## 核心决策

### 1. 15T tokens 的超大训练量

按 Chinchilla 最优:

- 8B 参数 → 160B tokens 最优
- **LLaMA 3 8B 训练 15T tokens**——overtraining **94×**

为什么?
- 8B 模型推理成本低,**多训点值得**
- 数据质量足够好(下见),15T 不是"注水"
- 推理部署时,用户会感受到小模型的质量溢出

**这是 "Beyond Chinchilla-Optimal" 思想的极端实践**。

### 2. 数据质量极大提升

![LLaMA 3 的数据处理流水线:原始 → 去重 → 质量过滤(rule-based + fastText + DistilRoberta)→ 去毒 → 数据混合。最终 15T tokens 中:50% 通用知识、25% 数学推理、17% 代码、8% 多语言。](/assets/img/llama3/x2.png)
_Figure 2:LLaMA 3 的数据处理_

关键步骤:

- **URL / line / doc 三级去重**
- **多级质量过滤**:rule-based(spam patterns)+ fastText classifier(Wikipedia-like)+ DistilRoberta(educational content)
- **安全过滤**:PII、CSAM、毒性
- **数据混合比例**:
  - 50% 通用知识
  - 25% 数学推理
  - 17% 代码
  - 8% 多语言
- **通过 scaling law 实验找最优混合比**——不是拍脑袋

### 3. 架构保守

与 LLaMA 2 相比,LLaMA 3 **几乎没改架构**:

- **GQA**(继续用)
- **RoPE**(base freq 从 10000 改为 500000,支持长 context)
- **SwiGLU**(不变)
- **RMSNorm**(不变)

变化微乎其微——**这证明架构已经成熟,数据是主要差异源**。

### 4. 三种模型规模

| 版本 | 参数 | Attention | KV Heads | Context |
|------|------|-----------|----------|---------|
| 8B | 8.03B | GQA | 8 | 8K → 128K |
| 70B | 70.6B | GQA | 8 | 8K → 128K |
| **405B** | **405B** | **GQA** | **8** | **8K → 128K** |

**没有用 MoE**——Meta 的论点:dense 更简单、训练更稳、部署更易。

## 训练配方细节

### 预训练(15T tokens)

- **Optimizer**:AdamW,$\beta_1 = 0.9, \beta_2 = 0.95$
- **LR**:peak $8 \times 10^{-5}$(405B),cosine decay 到 10%
- **Warmup**:8000 steps
- **Batch**:4M tokens(405B),逐步增加
- **稳定性**:QK-Norm,z-loss,bf16 训练,FP32 accumulation

### Long Context 训练

![LLaMA 3 的 long context 扩展:先在 8K pretrain 完,再分阶段扩展到 16K → 32K → 64K → 128K。每个阶段短期继续训练 + 测 needle-in-haystack 验证。](/assets/img/llama3/x3.png)
_Figure 3:Long context 分阶段扩展_

1. 主预训练用 8K context
2. 最后阶段**渐进 scale context**:8K → 16K → 32K → 64K → 128K
3. 每个阶段用对应长度的文档继续训练几千步
4. 验证:**needle-in-haystack** 任务在 128K 下仍接近完美

### 训练基础设施

- **16,000 张 H100**(405B 训练)
- **4D parallelism**:Data + Tensor + Pipeline + Context
- **FP8 accumulation** 探索(未在主训练用,后续 V3/V4 会用)
- 总训练时间 **约 54 天**

## Post-training Recipe

![Post-training 的 6 轮循环:每轮包含 Rejection Sampling → SFT → DPO。通过多轮循环不断提升质量,避免任一轮的错误被固化。](/assets/img/llama3/x4.png)
_Figure 4:Post-training 6 轮循环_

### 多轮迭代

每一轮:

1. **Rejection Sampling**:用当前模型生成多个 completion,用 reward model 选最好的
2. **SFT**:用筛选后的数据再训
3. **DPO**:在 preference pairs 上做直接偏好优化

**共 6 轮**,每轮都对比前一轮的模型。这个"自我改进"循环让模型质量稳步提升。

### 数据规模

- SFT 数据:**~10M 高质量 instructions**
- Preference pairs:**~10M 对比数据**
- 涵盖:通用 QA、代码、数学、多轮对话、推理

## 实验结果

![LLaMA 3 405B 在主流 benchmark 上对比 GPT-4 和 Claude 3 Opus:几乎全面持平或略超。MMLU 88.6(GPT-4 86.4), HumanEval 89 (GPT-4 76), GSM8K 96.8 (GPT-4 92)。](/assets/img/llama3/x5.png)
_Figure 5:LLaMA 3 405B 全面对标闭源前沿_

### 关键数字

| Benchmark | LLaMA 3 70B | LLaMA 3 405B | GPT-4o | Claude 3 Opus |
|-----------|-------------|--------------|--------|---------------|
| MMLU | 83.6 | **88.6** | 88.7 | 88.2 |
| HumanEval | 80.5 | **89.0** | 90.2 | 82.9 |
| MATH | 68.0 | **73.8** | 76.6 | 61.0 |
| GSM8K | 95.1 | **96.8** | 94.2 | 95.0 |
| ARC-C | 94.8 | **96.9** | 96.7 | 96.4 |
| MMMU (视觉)| — | — | 69.1 | 59.4 |

**405B 全面对标 GPT-4o 和 Claude 3 Opus**,部分任务甚至领先。

### 8B 模型的特别价值

LLaMA 3 8B 也极强:
- **MMLU 68.4**(超过 LLaMA 2 70B)
- 可以在单张 24GB GPU 推理
- **消费级硬件跑"前沿级别"能力**的里程碑

## 工程影响

### 1. 开源第一次追上闭源前沿

在 LLaMA 3 之前,开源最强约在 GPT-4 的 70-80%。**405B 第一次在多数 benchmark 上与 GPT-4o、Claude 3 Opus 持平**。这是开源历史性时刻。

### 2. 确立"Overtraining 小模型" 范式

8B/70B 的 15T tokens overtraining 效果如此好,**让所有后续开源模型跟进这个配方**:
- Qwen 2.5 18T tokens
- Mistral 3 18T+ tokens
- DeepSeek V3 14.8T tokens
- Phi-4 9.8T tokens(更专注高质量)

### 3. 数据 > 架构 的共识

LLaMA 3 几乎不改架构,仅仅数据规模和质量的提升就带来质变——这是**数据 >> 架构**的最强实证。后续几乎所有 LLM 工作都把重心放在数据清洗。

### 4. Post-training 的"6 轮循环" 配方

Meta 详细披露了 post-training 的迭代配方——**SFT + DPO + Rejection Sampling 的多轮循环**。这个 recipe 被业界广泛学习,成为 open-source post-training 的标配。

### 5. 推动开源生态

LLaMA 3 激活了整个开源 AI 生态:
- **Hugging Face** 上 LLaMA 3 变体数万个
- **vLLM / TensorRT-LLM** 等推理引擎专门优化
- **应用层**:Ollama 把 LLaMA 3 带进了消费级设备

---

## 局限

### 1. 不是 MoE

Meta 选择 dense 路线,**405B 推理成本极高**——需要 8 × H100。对比 DeepSeek-V3 的 671B MoE(37B 激活),推理经济性差很多。

### 2. 视觉 / 多模态延迟推出

LLaMA 3 初版只有纯文本。Vision 版本 **LLaMA 3.2 Vision** 2024-09 才发布——比 GPT-4V 晚了一年多。

### 3. 推理能力未跟上 o1/R1

LLaMA 3 的推理能力仍在 GPT-4 级别,未达到 o1/R1 的"long CoT + reflection"水平。**LLaMA 4** 在推理上追赶。

### 4. 训练成本仍巨大

**16000 张 H100 × 54 天** ≈ $50M+ 训练成本。虽然开源,但只有 Meta 这种体量才能真正训得起。

## 读完这篇你真正该带走的 4 件事

<callout emoji="white_check_mark" background-color="light-green" border-color="green">
1. **Overtraining 小模型是 2024 年后的主流策略**:Chinchilla 的"compute-optimal" 在推理成本考虑下被修正为"over-train"——LLaMA 3 8B 训 15T tokens 是极致体现
2. **数据质量 >> 架构创新**:LLaMA 3 vs LLaMA 2 架构几乎不变,但性能飞跃——主要来自数据。这告诉我们:训模型的 80% 精力应该花在数据
3. **405B dense 对标 MoE 671B**:Meta 用 dense 证明了 "精心训练的 dense 模型" 仍能与 MoE 分庭抗礼。dense 的训练稳定性和推理确定性有其独特价值
4. **Post-training 的 recipe 同等重要**:SFT + DPO + Rejection Sampling × 6 轮——这个迭代循环是从 GPT-4 级 base 到 Claude-level assistant 的关键配方
</callout>
