> 📄 **论文**：UniGRPO: Unified Policy Optimization for Reasoning-Driven Visual Generation
> 🔗 **arXiv**：[2603.23500](https://arxiv.org/abs/2603.23500)
> 🏢 **机构**：香港中文大学、字节跳动 Seed

## 一句话总结

UniGRPO 将"提示词 → 思考 → 图像"的多模态生成过程建模为单一 MDP，通过 GRPO 强化学习联合优化自回归文本策略与流匹配图像策略，在 GenEval 基准上达到 0.90 的 SOTA 水平，同时支持显式推理链。

## 背景与问题

生成式 AI 的最新趋势是将自回归大语言模型（文本）与流匹配模型（图像）融合为统一多模态架构。然而，如何有效训练这类统一架构仍是开放问题：

**已有方案的局限：**
- **SFT（监督微调）**：依赖高质量的推理-图像配对数据，构建成本高昂
- **FlowGRPO**：仅优化图像生成策略，无法支持推理链
- **TextGRPO**：仅优化文本推理，图像质量提升有限
- **UniFPO**：尝试联合优化但训练直接崩溃（collapse）

核心难点在于：文本生成基于自回归 token 预测，而图像生成基于连续流匹配——两者的策略更新方式根本不同，难以在统一 RL 框架下协同优化。

## 核心方法

### 统一 MDP 建模

UniGRPO 将整个生成过程形式化为单一马尔可夫决策过程（MDP）：

- **文本阶段状态**：提示词 + 已生成的 token 序列
- **图像阶段状态**：提示词、推理轨迹、带噪声的隐空间表示、流匹配时间步
- **奖励设计**：仅在最终去噪图像处给予稀疏终端奖励（sparse terminal reward）

统一目标函数：

$$\mathcal{J} = \mathcal{J}_{\text{Text}} + \lambda \cdot \mathcal{J}_{\text{Flow}}, \quad \lambda=1$$

### 两项关键技术创新

**1. 消除 CFG（Classifier-Free Guidance）**

传统流匹配训练需要条件/无条件两路前向传播（2-3× 计算开销）。UniGRPO 通过奖励最大化将对齐能力**直接内化到策略权重**中，训练时完全去除 CFG，推理时仍可按需使用。这将每步训练的函数评估次数降低 2-3×。

**2. 速度场 MSE 正则化**

传统方案使用 KL 散度作为正则项，但 KL 在不同噪声水平下的权重不均匀（被 $1/\sigma_{t_k}^2$ 加权），导致训练不稳定和奖励黑客攻击（reward hacking）。

UniGRPO 替换为速度场 MSE：

$$\mathcal{L}_{\text{MSE}} = \|v_\theta(x_{t_k}, t_k, y) - v_{\text{ref}}(x_{t_k}, t_k, y)\|^2$$

这种均匀正则化跨所有噪声水平施加，"减少了策略利用的漏洞"，从根本上解决了训练不稳定问题。

## 实验结果

### 主要基准对比

| 方法 | 支持思考 | TA Score | GenEval |
|------|---------|---------|---------|
| Bagel 基线 | ✗ | 0.6810 | 0.78 |
| SFT | ✗ | 0.7486 | 0.83 |
| FlowGRPO | ✗ | 0.8112 | 0.88 |
| TextGRPO | ✓ | 0.8078 | 0.88 |
| UniFPO | ✓ | **崩溃** | — |
| **UniGRPO（本文）** | ✓ | **0.8381** | **0.90** |

### GenEval 各类别细分

| 类别 | UniGRPO 得分 |
|------|------------|
| 总体 | **0.90** |
| 单一对象 | 0.99 |
| 两个对象 | 0.99 |
| 计数 | 0.91 |
| 颜色 | 0.91 |
| 空间位置 | 0.73 |
| 属性绑定 | 0.86 |

### CFG 消融实验

实验发现，CFG-free 训练在推理时加上 CFG 与全程使用 CFG 训练效果相当甚至更优。这说明内化对齐能力后，CFG 在推理时仍能作为质量增强器使用。

## 总结

UniGRPO 在统一多模态生成的 RL 训练上取得了重要突破，通过精心设计的 MDP 建模和两项关键技术创新（CFG 消除 + MSE 正则化），成功解决了之前联合优化导致训练崩溃的难题。

当前局限性包括：空间位置理解得分（0.73）相较其他类别仍有差距，且推理链的可解释性和实际贡献度尚待深入分析。未来工作可探索更丰富的奖励信号（如多轮交互奖励）和多模态推理链与生成质量之间更深层的耦合关系。
