## 一句话总结

提出 **Titans**——一个把 LLM 的"记忆系统"显式设计为**三层**的架构:**短期记忆(attention,精确但容量有限)**、**长期记忆(神经网络参数,推理时动态更新)**、**持久记忆(预训练固化,不变)**。最关键的创新:**长期记忆模块在推理时通过"惊讶度"(surprise)梯度动态更新自己的参数**——这让模型有了"在线学习"的能力,可以原生处理 **2M+ tokens** 的上下文,在 needle-in-haystack 等极限任务上碾压 Transformer / Mamba / GPT-4。

## 背景:大模型的记忆困境

### 当前 LLM 记忆的三种形态

1. **In-context(attention 短期)**:KV cache 存的东西,精确但受 context 长度限制
2. **参数(训练期固化)**:预训练学到的知识,容量巨大但不更新
3. **External RAG**:外部检索,灵活但延迟高、准确率依赖检索质量

一个**缺失的维度**是:**"推理时在线学习"**——模型在处理长文档时,能不能把新信息"记住"?目前的方案都没有这个能力(Mamba 的 state 是 fixed-size 压缩,难以精确 recall)。

### Titans 的哲学

借鉴**认知神经科学**:人脑有短期记忆(海马体)、长期记忆(大脑皮层固化的突触变化)、持久记忆(进化形成的基础功能)。Titans 把这三层显式化。

---

## 核心机制:三层记忆

### 1. 短期记忆:Attention over window

和 Mistral、GQA 一样——限定窗口的 attention,捕捉局部依赖。

### 2. 长期记忆:Neural Memory 模块

这是 Titans 的**核心创新**。

Neural Memory 是一个**小型神经网络**(2-3 层 MLP),参数为 $\theta_t$。关键:**$\theta_t$ 在推理时会随输入动态更新**。

更新规则(每处理一个 chunk):

$$
\theta_{t+1} = \theta_t - \eta \nabla_\theta \ell(M_\theta(k_t), v_t)
$$

其中 $\ell$ 是一个"重构损失":给定 key $k_t$,memory 网络 $M_\theta$ 应当输出对应的 value $v_t$。这个损失的梯度就是"**惊讶度**"——输出错得越多,更新越大。

这等于在推理时**做一步 SGD**,把 $(k_t, v_t)$ 这一对记忆"写入"到模型参数里。

### 3. 惊讶度调节(Momentum + 衰减)

Titans 还引入两个 trick 让更新更鲁棒:

- **Momentum**:累积梯度 $m_t = \beta m_{t-1} + \nabla \ell$,平滑更新方向
- **Weight decay / forgetting**:$\theta_{t+1} = (1 - \alpha) \theta_t - \eta m_t$,让老记忆逐渐淡化

这两个额外项让 Neural Memory 能**平衡新旧信息**,不会被某一条突兀的 key 过度"带偏"。

### 4. 持久记忆:训练期固化

预训练阶段学到的"通用知识"。对应传统 LLM 的参数,在推理时**不变**。

## 三种架构变体

Titans 探索了 Neural Memory 在整体网络中的三种位置:

### MAC (Memory as Context)

![MAC: Neural Memory 的输出作为 attention 的额外 context。attention 既看 local window,也看 memory 提供的"相关记忆片段"。](/assets/img/titans/x1.png)
_Figure 2:MAC——记忆作为 attention 的额外上下文_

Attention query 可以查"短期 window 里的 tokens"和"长期 memory 里查到的相关 tokens"。这个变体在实验中综合效果最好。

### MAG (Memory as Gate)

![MAG: Neural Memory 作为一个 gate,与 attention 的输出做加权融合。](/assets/img/titans/x2.png)
_Figure 3:MAG——记忆作为门控_

Neural Memory 输出一个向量,和 attention 输出做门控融合。更简单但效果略逊 MAC。

### MAL (Memory as Layer)

![MAL: Neural Memory 单独作为一个层,与 attention 层串联。](/assets/img/titans/x3.png)
_Figure 4:MAL——记忆作为独立层_

把 Neural Memory 当成一个独立的 layer,和 attention layer 交替堆叠。类似 Jamba 的 Hybrid 思想,但"Mamba 层"替换为"动态参数记忆层"。

---

## 并行训练

![Titans 的并行训练:chunk 内 attention 并行,chunk 间 Neural Memory 做 "mini-SGD" 顺序更新。整体类似 Mamba-2 的 chunkwise 算法。](/assets/img/titans/x4.png)
_Figure 5:Titans 的 chunkwise 并行训练_

- Chunk 内部:attention 和初始 $\theta$ 都并行
- Chunk 之间:Neural Memory 的 $\theta$ 按 chunkwise 做 mini-SGD
- 每个 chunk 计算 $\theta$ 的 gradient 后更新

这让 Titans 的训练速度与 Transformer 和 Mamba-2 相当。

---

## 实验结果:极长 context 大幅领先

![在 BABILong(100K - 10M tokens 的 reasoning)few-shot 基准上,Titans (MAC) 在 2M token 时仍保持 80%+ 正确率,Transformer / GPT-4 / Mamba-2 都急剧退化。](/assets/img/titans/x5.png)
_Figure 6:BABILong 超长 context 推理——Titans 独占鳌头_

### BABILong (10K - 10M tokens)

这是一个要求在超长文档中 reasoning 的任务:

| 模型 | 10K | 100K | 1M | 2M |
|------|-----|------|-----|-----|
| GPT-4 | 80 | 20 | N/A | N/A |
| Llama-3 8B | 65 | 5 | N/A | N/A |
| Mamba-2 | 40 | 30 | 25 | 20 |
| **Titans (MAC)** | **85** | **80** | **80** | **78** |

Titans 是**唯一一个在 2M context 仍保持 80% 正确率的模型**。

### Language Modeling (Pile)

在常规 LM 任务上,Titans 和 Mamba-2 / Transformer++ 相当(略优),没有显著落后。

### Time Series / Genomics

在长序列 time series 预测和 DNA 序列建模上,Titans 超过专门的 time series 模型和 Hyena,证明这不是对特定任务的 overfit。

## 为什么是架构的新范式

### 1. 引入"推理时学习"(test-time training)

传统 LLM 的参数在推理期冻结,所有"记忆"都塞在 context 里。Titans 让**一部分参数在推理时持续更新**——这是范式级的改变,打开了"LLM 不再是固定函数"的新可能性。

### 2. 显式的"记忆系统"分层

把 memory 明确分为"短 / 长 / 持久",每层有不同的更新速度和容量。这种**显式的记忆层次**给未来更复杂的认知架构提供了模板。

### 3. 2M+ context 的新高度

在 Titans 之前,主流模型在 100K-1M 之间挣扎。Titans 直接跨到 2M 量级。**不是靠 context window 变大,而是靠"把长距离信息编码到参数"**。这是完全不同的维度突破。

### 4. 统一 Transformer / Mamba / Linear Attention 的视角

SSD 说"SSM ≈ Linear Attention"。Titans 更进一步:**"Linear Attention 的 state 其实是一个可学习的 fast weight 矩阵"**——而 Neural Memory 就是这个 fast weight 的"深度、非线性"版本。这是一个更加抽象的统一视角。

---

## 局限

### 1. 推理时 SGD 带来额外计算

每个 chunk 都要做一次 backward pass 更新 memory,带来 ~30% 的额外计算成本。

### 2. 超参敏感

Memory learning rate $\eta$、momentum $\beta$、forgetting $\alpha$ 的调节较为敏感,不同任务上最优值不同。

### 3. Neural Memory 的理论容量

Memory 的 MLP 参数量决定了理论容量。太小则容量不足,太大则训练成本爆炸。实践上用 1-2% 的主模型参数量。

### 4. 未开源(2025-01)

Titans 截稿时 Google 尚未开源,社区复现有限。这让它的实际影响力(到 2026 年初)仍有待观察。

## 读完这篇你真正该带走的 4 件事

<callout emoji="white_check_mark" background-color="light-green" border-color="green">
1. **"推理时学习"是 LLM 的下一个维度**:固定参数的 LLM 是一种特殊情况,让参数随输入动态更新打开了全新的能力空间
2. **记忆分层是认知架构的必然**:短期 / 长期 / 持久——这种分层在人脑、OS 缓存、数据库中都存在,现在到了 LLM
3. **梯度本身就是"惊讶度"信号**:误差大的 key-value pair 触发大梯度,这个"surprise"直接对应心理学上的学习机制。把 gradient 当成 memory 写入信号是一个优雅的设计
4. **2M+ context 不靠扩 window 靠压缩**:Titans 证明超长 context 的正确路线不是把 attention 算到 2M,而是**分层记忆让真正重要的信息上升到长期存储**
</callout>
