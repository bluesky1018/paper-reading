## 一句话总结

本文提出"香农扩展定律"，将 LLM 训练建模为通过噪声信道的信息传输，用 Shannon-Hartley 定理统一解释了过训练退化、量化降级等非单调现象，并在 Pythia 系列模型上得到了验证。

## 背景与问题

自 Kaplan 等人（2020）提出神经扩展定律以来，幂律（Power Law）已成为预测 LLM 性能的主流框架：随着参数量和训练数据的增加，模型性能单调提升，且符合幂律关系。

然而，现实中越来越多的**非单调现象**无法用简单幂律解释：

1. **灾难性过训练（Catastrophic Overtraining）**：在数据量远超最优配比后，模型性能不升反降
2. **量化诱导退化（Quantization-induced Degradation）**：对模型进行低比特量化后，某些场景下性能出现意外的急剧下降
3. **涌现能力的突然出现与消失**：某些能力在特定规模突然涌现，又在更大规模消失

现有的单调幂律和扰动感知方法均无法系统解释这些现象。**需要一个更完整的理论框架**。

## 核心方法

### 香农扩展定律（Shannon Scaling Law）

本文提出的**香农扩展定律**将 LLM 训练建模为通过**噪声信道**的信息传输问题，基础是经典的 Shannon-Hartley 定理：

$$C = B \log_2\left(1 + \frac{S}{N}\right)$$

**理论映射：**

| 信息论概念 | LLM 对应 |
|-----------|---------|
| 信道容量 C | 模型性能上限（$C_{LLM}$） |
| 带宽 B | 模型参数量 N |
| 信噪比 S/N | 训练数据量 D / 噪声水平 |
| 噪声 | 数据噪声、量化误差、分布偏移等 |

### 非单调现象的解释

**过训练退化：**
当训练数据量 D 远超模型容量 N（即 D/N 过大），等价于输入信号功率过强，超出了信道的处理能力，导致信道**饱和**——这在信息论中对应非线性失真，表现为模型性能下降。

**量化诱导退化：**
量化操作引入额外噪声，相当于在信道中增加了噪声功率，降低了有效信噪比，从而降低信道容量——当信噪比本已接近临界值时，额外噪声会导致急剧的性能下降（容量断崖）。

**对称扩展定律的统一性：**
香农扩展定律是一个**对称**公式：N（带宽）和 D（信号功率）对容量的贡献具有对称性，这天然地统一了模型大小和数据量对性能的联合影响。

## 总结

香农扩展定律提供了一个优雅的理论框架，将长期以来"只能经验观察"的 LLM 扩展现象统一到信息论的严格框架下。这一框架的最大价值在于：它不仅能解释单调的性能提升（和幂律兼容），还能**预测和解释非单调现象**，为过训练检测和量化方案选择提供了理论指导。

局限性方面，香农框架中"噪声"的定义在 LLM 场景下仍较为宽泛（数据噪声、量化误差、分布偏移均被统一为"噪声"），更精确的噪声建模以及对涌现能力的定量预测仍是开放问题。
