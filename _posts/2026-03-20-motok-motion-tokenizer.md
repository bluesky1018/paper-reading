## 一句话总结

MoTok 通过将运动的语义抽象（离散 token 规划）与精细运动重建（扩散解码器）解耦，构建了统一的**感知-规划-控制（Perception-Planning-Control）**三阶段人体运动生成框架，使用仅1/6数量的 token 就将轨迹误差从0.72cm降至0.08cm，FID从0.083降至0.029。

## 背景与问题

人体运动生成存在两大主要范式的根本矛盾：
- **连续扩散模型**：擅长运动学控制（精确的关节轨迹遵循），但在语义条件化（文本驱动）方面较弱
- **离散 Token 生成器**：在语义条件化（文本→运动）上效果好，但难以处理精细的运动学控制

现有方法试图在两个范式间取得平衡时，往往面临**双重困境**：强化运动学控制会破坏语义意图；而注重语义一致性又会导致运动学精度下降。此外，现有离散运动 tokenizer（如 MoMask）为了保持高保真重建需要大量 token（残差向量量化），给下游规划器带来沉重负担。

## 核心方法

### 感知-规划-控制范式

作者提出了统一的三阶段框架：

1. **感知（Perception）**：提取异质条件特征——全局条件（文本、风格）指导整体运动，局部条件（关键点轨迹、接触提示）提供时序约束
2. **规划（Planning）**：在 token 空间进行离散序列规划（支持自回归 AR 和离散扩散 DDM 两种生成器）
3. **控制（Control）**：通过扩散解码进行精细运动合成，并在去噪过程中强制施加精细运动学约束

### MoTok：扩散式离散动作 Tokenizer

MoTok 的核心创新在于将离散 token 的责任重新定义：不再要求离散 token 编码所有运动细节，而是将精细重建委托给**扩散解码器**。

**架构组成**：
1. **卷积编码器** $\mathcal{E}$：将运动序列 $\theta_{1:T}$ 时序下采样为潜在序列 $h_{1:N}$
2. **向量量化器** $\mathcal{Q}$：将潜在向量映射为离散码本索引（码本大小 K=1024）
3. **扩散式解码器**：
   - 卷积解码器 $\mathcal{D}$：将量化潜变量上采样为逐帧条件序列 $s_{1:T}$
   - 条件扩散模型 $\mathcal{P}_\phi$：以 $s_{1:T}$ 为条件重建精细运动

关键设计：$f_\phi$ 通过 AdaIN 风格变换将条件嵌入注入运动特征，在去噪过程中自然支持精细约束施加。

训练目标：
$$\mathcal{L} = \mathcal{L}_{diff} + \lambda_{commit} \mathcal{L}_{commit}$$

![MoTok及统一框架概述](https://arxiv.org/html/2603.19227v1/x2.png)
*图2：(a) MoTok 将动作表示分解为紧凑离散 token 和扩散式重建；(b) 统一条件生成框架同时支持离散扩散和自回归规划器。*

### 粗到精的条件注入

**规划阶段**（粗约束）：局部运动学条件以 token 对齐特征方式注入 token 空间规划，在离散 token 预测时引导整体轨迹方向：
$$H_0[1+n] \leftarrow H_0[1+n] + M_n^s + p_n$$

**控制阶段**（精约束）：在扩散解码的去噪步骤中，通过优化辅助控制损失强制施加精细运动学约束：
$$\hat{x}^k \leftarrow \hat{x}^k - \eta \nabla_{\hat{x}^k} \mathcal{L}_{ctrl}(\hat{x}^k, c^s_{1:T})$$

这种分阶段设计防止了低层运动学细节干扰离散 token 空间规划，同时保证了连续运动的精确约束满足。

## 实验结果

### HumanML3D 可控运动生成（文本+轨迹控制）

| 方法 | FID ↓ | 轨迹误差(50cm) ↓ | 定位误差 ↓ |
|------|:-:|:-:|:-:|
| PriorMDM | 0.475 | 0.3457 | 0.2132 |
| OmniControl | 0.218 | 0.0387 | 0.0096 |
| MaskControl | 0.083 | 0.0000 | 0.0000 |
| **MoTok-DDM-4（Ours）** | **0.029** | **0.0000** | **0.0000** |

关键发现：当约束关节数量增加时，现有方法（PriorMDM、InterControl 等）的 FID 随之**退化**，而 MoTok 的 FID 随约束增强反而**提升**（从0.033降至0.014），展现出约束与真实性协同增益的独特特性。

### 与 MaskControl 的对比

相比最强基线 MaskControl：
- 仅使用 **1/6 数量的 token**
- 轨迹误差：0.72cm → **0.08cm**（降低89%）
- FID：0.083 → **0.029**（降低65%）

### 文本到动作生成（HumanML3D）

在标准文本到动作生成任务上，MoTok 在激进压缩下也优于强基线：
- FID 0.039 vs. 竞争方法 0.045（使用1/6 token）

## 总结

MoTok 的核心贡献在于对离散运动 tokenization 责任的重新划分：令离散 token 专注语义抽象，将精细运动细节委托给扩散解码器，从根本上解除了 token 效率与运动保真度之间的矛盾。这一设计使得系统能够以远少于现有方法的 token 数量同时实现更好的语义一致性和运动学精度。

感知-规划-控制的统一框架具有良好的可扩展性，同时兼容自回归和离散扩散两类规划器，并支持多种条件类型（文本、轨迹、关键帧等），为未来更复杂的多模态运动生成任务奠定了基础。

局限性方面，扩散式解码相比直接 VQ-VAE 解码增加了推理时间；此外，精细约束强度超参数 $\eta$ 需要任务级调优。
