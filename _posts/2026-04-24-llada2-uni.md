## 一句话总结

LLaDA2.0-Uni 在单一离散扩散框架内统一了多模态理解与图像生成，通过全语义离散分词、MoE主干与扩散解码器三件套，实现了与专用VLM相当的理解能力，同时具备高质量图像生成与编辑能力。

## 背景与问题

多模态大语言模型（MLLM）领域长期存在"理解"与"生成"两条并行路线——理解派（如LLaVA、InternVL）专注于视觉问答与推理，生成派（如DALL-E、FLUX）专注于文本到图像合成。少数统一模型（如Janus、BAGEL）尝试在同一框架内处理两类任务，但往往需要为两个目标维护不同的解码头或分支，架构复杂且存在优化冲突。

与此同时，基于掩码扩散的离散大语言模型（dLLM）作为一种新范式正在兴起。与自回归模型的逐token生成不同，dLLM通过去噪过程并行恢复被掩码的token，在文本生成质量和推理效率上均展现出竞争力。然而，如何将dLLM扩展至视觉模态——既要处理连续像素，又要保持离散扩散的优雅简洁——仍是开放挑战。

LLaDA2.0-Uni 正是在这一背景下提出的，旨在构建一个真正统一的离散扩散多模态基础模型，无需为理解与生成设计不同分支，而是通过统一的离散化与去噪机制同时服务于两类任务。

## 核心方法

LLaDA2.0-Uni 的架构由三个核心模块串联而成：

### 1. 全语义离散视觉分词器（SigLIP-VQ）

连续图像像素无法直接用于离散扩散。作者采用 SigLIP-VQ，将视觉编码器（SigLIP）的语义特征空间量化为离散 token，而非直接量化原始像素。这一设计确保了视觉 token 携带丰富语义信息，与文本 token 的语义粒度更为匹配，从而支持**块级（patch-level）掩码扩散**——即对图像块和文本 token 施加统一的随机掩码与去噪操作。

### 2. 基于 MoE 的 dLLM 主干网络

主干网络延续 LLaDA 架构，采用专家混合（MoE）设计扩展模型容量。视觉 token 与文本 token 在同一序列空间中被统一处理，无需区分模态。掩码扩散目标对两种模态的 token 同等适用：随机遮盖部分 token，模型学习在给定上下文条件下预测被遮盖的内容。

### 3. 扩散解码器（Diffusion Decoder）

对于图像生成任务，主干网络输出的离散视觉 token 需要被映射回高保真像素。扩散解码器扮演这一角色，将语义层面的离散 token 序列渲染为视觉连贯的图像输出，支持文生图与图像编辑。

### 推理效率优化

为加速推理，作者提出两项关键技术：
- **Prefix-aware 优化**：充分利用前缀条件的确定性，避免对已知上下文的重复计算；
- **Few-step 蒸馏**：将多步去噪压缩为少步高质量生成，显著降低推理延迟。

### 原生交错生成与推理（Interleaved Generation）

LLaDA2.0-Uni 的一大亮点是原生支持文本与图像的**交错生成**——在单次前向传播中，模型可以生成图文混合的输出，实现真正意义上的多模态推理与叙述。

## 实验结果

LLaDA2.0-Uni 在多模态理解与生成两类任务上均展现出竞争力：

**多模态理解**：在主流 VQA、多模态推理等基准上，性能可与专用 VLM（如 LLaVA、InternVL 系列）媲美，证明离散扩散框架并不以牺牲理解能力为代价；

**图像生成与编辑**：在文生图质量和图像编辑精度方面表现出色，尤其在需要理解语义约束的编辑任务上优势明显；

**交错生成**：在需要同步输出文本描述与对应图像的任务上，模型展现出流畅的多模态协调能力，这是纯自回归 MLLM 难以原生支持的场景。

## 总结

LLaDA2.0-Uni 为多模态基础模型提供了一种优雅的统一范式：以离散扩散为底层机制，通过语义量化消弭视觉与语言的模态鸿沟，让理解与生成在同一目标函数下协同优化。SigLIP-VQ + MoE dLLM + 扩散解码器的三件套架构简洁而有效，prefix-aware 优化与 few-step 蒸馏则确保了工程可用性。

局限方面，离散量化不可避免地引入信息损失，在高频细节丰富的图像（如人脸、复杂纹理）上仍可能逊于基于连续潜变量的生成模型（如基于 VAE 的 Stable Diffusion）。此外，MoE 架构带来的路由开销和训练不稳定性也是需要持续关注的工程挑战。整体而言，LLaDA2.0-Uni 是扩散语言模型从文本走向多模态的重要里程碑。
