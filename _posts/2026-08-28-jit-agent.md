## 一句话总结

JIT-Agent 是首个专为"即时 Harness 生成"训练的元智能体模型，能为任意现成的大语言模型实时合成任务自适应的智能体执行架构（Harness），使 DeepSeek-V4-Flash 超越 GPT-5.6，GLM-5.2 在某些任务上提升最高 +20.2 分。

## 背景与问题

LLM 智能体的能力由两个紧密耦合的因素共同决定：**基础模型**（推理与动作生成）和**智能体 Harness**（封装模型运行的执行环境）。Harness 决定了：
- 哪些历史信息被保留（Memory Management）
- 本地意图如何形成（Planning Strategy）
- 哪些工具/技能被暴露（Tool/Skill Orchestration）
- 验证和恢复何时触发（Action Protocol）

**核心问题**：现有 Harness 设计是手工的、任务特定的且根本上不可扩展的。当前的"提前优化（AOT）"范式预先编译一个通用 Harness，但无法适应每个任务实例的具体需求。

## 核心方法

### 即时（JIT）vs 提前（AOT）Harness 范式

**AOT 范式**（传统）：预先优化一个"持久"Harness，期望其泛化到未来任务。问题：
- 需要搜索大型设计空间
- 需要积累足够轨迹
- 希望最终 Scaffold 与下一个任务匹配

**JIT 范式**（本文提出）：不同任务需要不同 Harness 先验：
- 宽搜索任务 → 并行证据探索
- 终端任务 → 精简串行 ReAct 循环
- 深度研究任务 → 检索证据的工作记忆
- 代码任务 → 文件系统中介的 patch+测试+追踪

### 四模块 Harness 协议

JIT-Agent 将智能体 Harness 形式化为**可组合、机器可生成**的制品，由固定的四模块协议管理：

1. **Memory 模块**：管理工作上下文和跨会话经验
2. **Planning 模块**：形成局部意图和长期规划
3. **Action 模块**：执行协议和验证/恢复机制
4. **Tool/Skill 模块**：工具/技能编排和注册表

### JIT-Agent 训练挑战与解决方案

三大挑战：
- ❶ **适应性**：如何将生成的 Harness 与任务匹配
- ❷ **可靠性**：如何确保可执行行为并在合成失败时恢复
- ❸ **可演化性**：如何将执行反馈转化为更强的未来 Harness

### Harness 自演化机制

随着反馈和轨迹的积累，JIT-Agent 能够：
1. 修复 Harness（stable and reliable execution）
2. 从扩展的历史 Harness 配置归档中蒸馏性能信号进行自我演化
3. 测试时演化（test-time harness evolution）——生成器本身保持固定

## 总结

JIT-Agent 建立了"Harness 智能"作为与模型规模正交的、可训练、可迁移、可叠加的智能体能力新维度。核心贡献是首次将 Harness 生成形式化为可训练的机器学习问题，并证明了即时、任务自适应的 Harness 合成是可行且有效的。

局限性：目前 JIT-Agent 的评估主要集中在搜索、代码和通用智能体任务上，对具身智能、视觉感知等多模态场景的适用性尚需验证；此外，Harness 生成的推理开销需要更多分析。
