## 一句话总结

EVA 通过"先规划后感知"的迭代推理框架与 SFT→KTO→GRPO 三阶段训练流程，让 7B 视频多模态大模型成为能自主决定"看什么、何时看、怎么看"的高效视频智能体，在六项基准上相比通用 MLLM 基线提升 6–12%，同时大幅降低视觉 token 消耗。

---

## 背景与问题

### 视频理解的核心挑战

随着多模态大语言模型（MLLM）的快速发展，视频理解面临一个根本性矛盾：视频帧序列生成的超长 token 序列带来大量时序冗余，而现有方法要么对帧均匀采样（受上下文长度限制，错过关键帧），要么依赖外部工具的智能体流程（工具设计僵化，信息损失严重）。

![EVA对比传统方法示意图](https://arxiv.org/html/2603.22918v1/x1.png)

*图1：对于一个长达 6600+ 秒的视频，均匀采样受限于上下文长度会错过关键帧；传统智能体方法工具固定、无法自适应调整分辨率；EVA 先用低分辨率高帧率粗览全视频，再用高分辨率精准聚焦关键片段。*

### 现有方法的局限

现有智能体视频理解方法大致分为两类：

1. **调用外部 MLLM API 的工具式方法**（如 Ego-R1、M3-Agent）：依赖外部工具性能，主智能体自身能力受限。
2. **时序采样工具方法**（如 VideoMTR、FrameThinker、LOVE-R1）：仍将 MLLM 视为流水线中的固定感知组件，工作流僵化。

这两类方法的共同问题是：**以感知为先（perception-first）**，即先采样视频帧再推理，而非根据问题意图主动规划感知策略。

## 核心方法

### 先规划后感知（Planning-Before-Perception）

EVA 的核心理念是将视频理解重新定义为一个马尔可夫决策过程（MDP），采用迭代的 **摘要（Summary）→ 规划（Plan）→ 行动（Action）→ 反思（Reflection）** 推理循环。

**关键设计**：在初始步骤 $s_0$，模型仅接收用户问题（query），**不提供任何视觉输入**，强制模型先从文本角度制定感知计划，再有选择地采集视觉证据。

这样做有三大优势：
- **避免视觉误导**：文本规划阶段不受无关帧的干扰；
- **节省视觉 token**：提前判断哪些片段值得精细观察；
- **主动感知**：由被动识别转变为主动决策。

### 帧选择工具设计

EVA 的帧采集工具支持四个参数，赋予模型对时间和空间的双重自适应控制能力：

| 参数 | 描述 |
|------|------|
| `start_time` | 采样时间窗口起点 |
| `end_time` | 采样时间窗口终点 |
| `nframes` | 采样帧数 |
| `resize` | 空间下采样比例（支持缩放） |

`resize` 参数使模型能够实现"缩放"（zoom-in/zoom-out）——更大的 `nframes` 捕捉动态动作，更高的空间分辨率提取细节信息。这是 EVA 区别于仅调整时间范围的先前方法的重要创新。

### 三阶段训练流程

![EVA训练流程](https://arxiv.org/html/2603.22918v1/x2.png)

*图2：EVA 的三阶段训练流程：SFT 学习基本格式 → KTO 纠正探索失误 → GRPO 强化高效探索策略。*

#### 阶段一：监督微调（SFT）

- **教师模型**：Qwen2.5-VL-72B
- **数据来源**：llava-video（短视频 QA）+ cgbench（长视频 QA）
- **数据规模**：EVA-SFT，共 10k 样本
- **数据格式**：每条样本包含完整的 Summary + Planning + Action + Reflection 四部分
- **提示设计**：包含历史成功经验提示、多样化工作流提示、反思性思考提示

SFT 阶段让模型学会基本的推理格式，但往往仍存在低效探索问题。

#### 阶段二：KTO 偏好优化

KTO（Kahneman-Tversky Optimization）专门用于纠正 SFT 后模型的典型失误：

- 缺乏足够视觉证据就直接作答（"猜测行为"）；
- 在短时间窗口内采样帧数过多；
- 在长时间窗口内采样帧数过少。

**为何选择 KTO 而非 DPO？**
DPO 需要共享对话轮次的成对偏好数据，与多轮交互的视频智能体场景不兼容。KTO 仅需对单条样本打"好/坏"标签。

**为何选择 KTO 而非 GRPO？**
KTO 支持从外部收集的经验中学习，而非自我博弈（self-play），训练更稳定、更高效。

- **数据规模**：EVA-KTO，11k 条帧选择策略标注（63% 正样本 / 37% 负样本）
- **标注方法**：LLM-as-Judge 识别"视觉 token 不足却仍作答"的轨迹作为负样本，高质量成功轨迹重采样为正样本

#### 阶段三：GRPO 强化学习

**数据增强 GRPO 流程**针对标准 GRPO 的训练数据静态问题：

1. 收集 KTO 模型的失败案例；
2. 经过若干 GRPO 步骤后，收集新的失败案例；
3. 将失败案例作为上下文示例，驱动教师 MLLM 为未见过的 HD-VILA 视频生成新 QA 对；
4. 在增强后的数据集上重新训练 GRPO。

**奖励设计**：

$$R(\tau) = w_{\text{acc}} \cdot r_{\text{acc}} + w_{\text{fmt}} \cdot r_{\text{fmt}}$$

- **准确率奖励**：
  - 选择题：CSV（完整性自验证）奖励，仅当判断模型与 EVA 均答对时得 1 分；
  - 开放题：平均 ROUGE 分 $r_{\text{rouge}} = \frac{1}{3}(R_1 + R_2 + R_L)$。
- **格式奖励**：若模型生成了工具调用但最终答错，给予极低补偿奖励（0.05），刻意压低以防止随机猜测（选择题随机猜对率约 0.20–0.25）。

使用**开放式 QA**（非选择题）作为主要 RL 训练数据，可有效防止奖励黑客攻击。

- **数据规模**：EVA-RL，9.6k 开放式 QA + 1.1k 选择题

## 实验结果

### 实验设置

- **基础模型**：Qwen2.5-VL-7B-Instruct
- **SFT**：2 个 epoch，batch=8，lr=2e-6
- **KTO**：lr 同上，beta=0.1
- **GRPO**：1 个 epoch，batch=64，每样本 8 次 rollout，lr=1e-6，32×H100 GPU；90% 开放式 + 10% 选择题
- **评测基准**：LSDBench、LongVideoBench、MLVU、VideoMME、LVBench、Video-Holmes

### 主要结果

#### 表1：LSDBench（采样困境基准）

| 方法 | 帧数 | 视觉 Token | 准确率 (%) |
|------|------|-----------|-----------|
| Gemini-2.0-Flash | 2700 | 696.6k | 56.2 |
| Qwen2.5-VL (256f) | 256 | 166.4k | 50.1 |
| Qwen2.5-VL (768f) | 768 | 499.2k | 52.5 |
| Qwen2.5-VL* 基线 (32f) | 32 | 21.0k | 49.2 |
| **EVA** | **76.9** | **10.3k** | **51.0** |

EVA 仅用 **6.2K 视觉 token** 即达到 51.8% 准确率，超越基线 +2.6%，视觉 token 消耗不到基线的一半。

#### 表2：长视频理解基准

| 模型 | LongVideoBench | MLVU | VideoMME | LVBench |
|------|---------------|------|----------|---------|
| GPT-4o (32f) | 58.2 | 64.6 | 71.9 | 48.9 |
| Video-R1 (32f) | 52.7 | 60.2 | 59.9 | 35.3 |
| FrameThinker | 52.9 | 59.1 | — | 36.6 |
| EVA-SFT | 49.9 | 52.3 | 56.0 | 26.5 |
| EVA-KTO | 53.2 | 57.4 | 56.5 | 36.0 |
| **EVA-GRPO** | **55.0** | **68.3** | **60.2** | **43.3** |

EVA-GRPO 在 MLVU 上以 68.3% 大幅领先，LVBench 上 43.3% 超越所有同量级模型。

#### 表3：Video-Holmes 零样本推理

| 模型 | 总体准确率 |
|------|-----------|
| GPT-4o | 42.0 |
| Video-R1 | 36.5 |
| VideoChat-R1 | 33.0 |
| EVA-SFT | 32.6 |
| EVA-KTO | 32.9 |
| **EVA-GRPO** | **37.2** |

在需要复杂推理的 Video-Holmes 基准上，EVA-GRPO 达到 37.2%，超越同量级所有方法。

### 消融实验分析

![消融实验](https://arxiv.org/html/2603.22918v1/x4.png)

*图4：三阶段训练对视觉 token 消耗与性能的影响对比。*

三阶段训练的演进规律：
- **SFT**：帧消耗最大，性能最低——学会了格式，但探索效率低；
- **KTO**：大幅减少帧消耗和交互轮数，性能显著提升；
- **GRPO**：进一步减少每轮采样帧数，但**增加**交互轮数——策略更成熟，"精少采样、多轮推理"。

这揭示了一个有趣的规律：GRPO 训练的智能体会进行更深思熟虑的多轮推理，同时在每轮中更精准地分配视觉 token 预算。

### EVA 行为模式分析

![EVA行为分析](https://arxiv.org/html/2603.22918v1/x5.png)

*图5：EVA 逐轮视觉 token 分布——第一轮大范围粗看，第二轮聚焦关键帧细看。*

- **第一轮**：大 `nframes`、长时间跨度（粗览全视频）；
- **第二轮**：`nframes` 和时间范围急剧缩短，`resize` 因子增大（放大聚焦细节）。

### 幻觉抑制评估（ELV-Halluc 基准）

| 模型 | 规模 | 平均准确率↑ | SAH 比率↓ |
|------|------|------------|----------|
| Qwen2.5VL-7B | 7B | 18.1 | 8.8% |
| InternVL3-8B | 7B | 16.3 | 6.8% |
| InternVL3-38B | 32B | 26.1 | 4.3% |
| **EVA** | **7B** | **26.2** | **5.0%** |

EVA（7B）以最低的幻觉率（SAH 比率 5.0%）获得所有对比模型中最高的准确率（26.2%），表明自适应感知策略有效抑制了语义聚合幻觉。

## 总结

EVA 提出了一种将被动视频识别器转变为主动自适应智能体的全新范式。主要贡献包括：

1. **先规划后感知范式**：从零视觉输入出发制定感知计划，实现真正意义上的主动视频理解；
2. **时空双维度自适应控制**：通过帧数与分辨率参数的组合，智能体可同时控制时间粒度和空间精度；
3. **三阶段渐进训练体系**：SFT 奠定格式基础，KTO 纠正探索失误，GRPO 强化高效策略；
4. **数据增强 GRPO**：动态更新训练数据，持续挑战模型边界，避免静态数据带来的泛化瓶颈；
5. **显著的效率收益**：以大幅少于基线的视觉 token 实现更高性能，推理开销合理可控。

**局限性与未来方向**：当前推理循环依赖预定义工具接口，对未见过的查询分布可能泛化不足。未来工作方向包括：灵活的工具生态系统、自进化推理策略、跨模态记忆机制。
