> 📄 **论文**：Addressing Performance Saturation for LLM RL via Precise Entropy Curve Control
> 🔗 **arXiv**：[2604.26326](https://arxiv.org/abs/2604.26326)
> 🏢 **机构**：普渡大学

## 一句话总结

Entrocraft 通过熵引导的拒绝采样实现对 RL 训练中熵曲线的精确控制，找到了"线性退火"作为最优熵调度策略，使 4B 模型超越 8B 基线，pass@K 提升 50%，显著延长有效训练轮次。

## 背景与问题

强化学习（RL）已成为大语言模型（LLM）推理能力提升的主要范式，但大多数 RL 算法都面临**性能饱和**（Performance Saturation）问题——随着训练规模扩大，性能比预期更早饱和，额外的数据和计算无法带来进一步提升。

性能饱和背后的核心机制是**熵崩溃**（Entropy Collapse）：LLM 过度聚焦于少数解决方案，停止探索替代推理轨迹，表现为 RL 训练中熵的持续下降。

现有熵保持技术（如熵正则化、裁剪、正负解耦）虽能提升熵，但对熵曲线的控制仍然粗糙：
- 熵可能在几步后漂移过高，使 RL 训练不稳定
- 这一问题在长期 RL 训练中尤为严重
- 没有方法能回答"什么样的熵调度最优？"这一根本问题

## 核心方法

### 理论基础

论文基于现实的 LLM 策略假设，对熵变化进行了严格的理论分析：

**定理 1（Token 级熵变化）**：熵变化与优势值**负相关**，且高模型置信度会放大这种熵变化。

这一理论结果揭示了一个直接的控制机制：通过偏置优势分布可以直接控制熵的变化方向和幅度。

### Entrocraft：熵引导的拒绝采样

基于上述理论，Entrocraft 设计了一个简洁的拒绝采样过滤器：

- **当前熵 < 目标熵时**：过滤掉**正优势**的 rollout 样本（这些样本会降低熵），只保留负优势或中性样本
- **当前熵 > 目标熵时**：过滤掉**负优势**的 rollout 样本（这些样本会提高熵），只保留正优势或中性样本

通过调整过滤比例，Entrocraft 能在极少步数内将熵精确推向目标值，如同为 RL 训练配备了"学习率调度器"。

**关键优点**：
- 无需熵正则化项（与目标函数解耦）
- 与优势估计器无关（可即插即用于 GRPO、GSPO 等任何策略梯度方法）
- 精确可控，能实现任意用户定制的熵调度

### 最优熵调度探索

Entrocraft 的精确控制能力使论文得以首次系统性地比较不同熵调度策略：

| 调度类型 | 特点 | 效果 |
|---------|------|------|
| 固定目标 | 维持恒定熵水平 | 训练 200k 步后趋于不稳定 |
| 线性退火 | 从高熵开始线性降低 | **性能最优** |
| 余弦退火 | 余弦曲线降低 | 性能居中 |

**结论**：线性退火（高熵起始，逐步向略低目标退火）是最优策略，既利用了早期训练的高探索性，又在后期保持了训练稳定性。

## 实验结果

### 数学推理基准（MATH-500、AMC-23、AIME-25）

| 方法 | MATH-500 mean@32 | AMC-23 mean@32 | AIME-25 mean@32 | 平均 |
|------|-----------------|----------------|-----------------|------|
| GRPO | 75.3 | 57.4 | 8.9 | 47.2 |
| + 熵正则化 | 76.0 | 55.0 | 9.9 | 47.0 |
| + Clip-Higher | 75.8 | 55.5 | 10.8 | 47.4 |
| + Clip-Cov | 76.8 | 57.1 | 10.8 | 48.2 |
| **+ Entrocraft** | **79.0** | **65.0** | **16.5** | **53.5** |

Entrocraft 在所有基准上均显著优于其他熵保持方法，在难度最高的 AIME-25 上，mean@32 从基线的 8.9% 提升至 16.5%（提升 85%）。

### 跨模型规模的效果

- **4B 模型超越 8B 基线**：Entrocraft + Qwen3-4B-Base 在 AIME-25 上超越标准 GRPO 训练的 Qwen3-8B-Base
- **pass@K 提升 50%**：相比基线，Entrocraft 使推理时间扩展（inference-time scaling）更有效

![模型规模对比](https://arxiv.org/html/2604.26326v1/2604.26326v1/x3.png)
*图 2：左：4B 模型使用 Entrocraft 可超越 8B 基线；中右：pass@K 曲线对比——Entrocraft 使 pass@K 增长更快*

### 长期训练效果

Entrocraft 将有效训练时长延长约 **4×**——标准 GRPO 通常在 300k-400k 步时饱和，而 Entrocraft 可将持续提升延续至 1.2M 步以上。

### 方法对比汇总

| 方法 | 达到目标熵 | 控制熵曲线 | 算法无关 |
|------|---------|---------|--------|
| 熵正则化 | ✓ | ✗ | ✗ |
| Clip-Higher | ✓ | ✗ | ✗ |
| Clip-Cov | ✓ | ✗ | ✗ |
| W-Reinforce | ✗ | ✗ | ✓ |
| EntroPIC | ✓ | ✗ | ✓ |
| **Entrocraft** | **✓** | **✓** | **✓** |

只有 Entrocraft 同时满足达到目标熵、精确控制熵曲线、算法无关三个属性。

## 总结

Entrocraft 填补了 LLM RL 训练中"精确熵曲线控制"这一空白，通过简洁的拒绝采样机制将熵控制从粗粒度的正则化提升为可精确设计的调度问题。理论与实验的紧密结合使该工作具有较强的说服力，而"线性退火"调度的发现也为整个领域提供了可落地的实践指导。

局限性方面，拒绝采样会降低样本效率（部分 rollout 被丢弃），在数据稀缺场景中需权衡；此外，论文发现维持高熵在长期训练中可能引发不稳定性，提示对最优熵调度的进一步研究仍有空间。
