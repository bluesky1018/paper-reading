## 一句话总结

ViFeEdit 提出了一种**无需视频训练数据**的视频编辑框架，仅依赖 2D 图像数据，通过时空解耦的架构重参数化技术，让预训练的文本到视频 Diffusion Transformer 能够以极低成本完成多样化视频编辑任务。

---

## 背景与问题

Diffusion Transformer（DiT）在图像和视频生成领域展现出了卓越的可扩展性和生成质量，学界对将其用于可控生成和编辑任务的兴趣也日益增长。然而，与图像编辑相比，视频控制和编辑领域的进展依然十分有限，主要原因有以下两点：

1. **配对视频数据稀缺**：构建高质量的配对视频数据集成本极高。例如，近期相关工作为整理此类数据集据报道消耗了超过 10,000 GPU 天。
2. **训练计算代价昂贵**：训练视频扩散模型本身需要大量多帧依赖计算，通常只有拥有大规模 GPU 集群的工业实验室才能承担。

在此背景下，论文提出了一个核心问题：**能否仅使用 2D 图像，而不依赖任何视频数据，有效地调优用于视频编辑的 DiT？** ViFeEdit 对这一问题给出了肯定的回答。

现有视频编辑方法大致可分为三类：
- **时序适配方法**：在图像 backbone 中显式加入时序模块，计算代价高且通常需要逐视频微调；
- **注意力/潜变量调制方法**：在推理时操控注意力或潜变量表示，效率较高，但编辑能力主要限于外观层面的细粒度调整；
- **端到端视频编辑方法**：在大规模配对视频数据集上进行全监督训练，性能强大，但数据和计算成本极高。

ViFeEdit 另辟蹊径，在无需视频数据的前提下实现多样化视频编辑，填补了现有方法的空白。

*图 2：（a）原始文本到视频模型 Wan2.1 的 DiT Block 架构，以及（b）ViFeEdit 的视频编辑调优架构。源视频 $C_V$ 与含噪视频潜变量 $Z$ 在 2D 空间注意力分支中共同输入并交互，提供显式的参考引导。*

### 3.1 预备知识：DiT 中的视频生成

现代视频生成 DiT（如 Wan2.1）采用**全 3D 注意力**机制，对视频潜变量中的空间和时序依赖关系进行联合建模：

$$\mathrm{Attn}_{3D}(X) = \mathrm{Attention}(XW^Q, XW^K, XW^V)W^O$$

其中 $X \in \mathbb{R}^{B \times N \times d}$，$N = f \times h \times w$（$f$ 为帧数，$h$、$w$ 为空间维度）。训练采用 Flow Matching 机制，通过以下目标优化 DiT 参数：

$$\mathcal{L} = \mathbb{E}_{\epsilon,(Z_0,C_T),t}[\|u_\theta(Z_t, C_T, t) - v_t\|^2]$$

全 3D 注意力在空间和时序之间紧密耦合，这使得直接使用 2D 图像微调时，空间信息的学习会破坏已有的时序建模能力（表现为推理时出现"帧冻结"现象）。

### 3.2 时空解耦（核心创新）

ViFeEdit 的核心挑战在于：**如何在全 3D 注意力架构中实现干净的时空解耦？**

由于现代 DiT 中注意力头的空间/时序角色会随着去噪步骤和条件提示动态变化，显式地将 3D 注意力分割为空间和时序部分是不可行的。

论文提出了一种**架构重参数化**技术，其关键思路如下：

1. **冻结原始 3D 注意力**，保留其完整的时序建模能力，不做任何修改；
2. **引入一对互补的 2D 空间注意力模块**（正向 $\mathrm{Attn}_{SpaPos}$ 和负向 $\mathrm{Attn}_{SpaNeg}$），专门负责空间建模；
3. 两个 2D 注意力模块均**以对应的 3D 注意力模块权重初始化**，充分复用预训练的空间先验；
4. 初始化时两者输出相互抵消（差值为零），确保模型初始行为与原始模型完全一致。

最终的输出形式为：

$$\mathrm{Attn}_{3D}(X) + \mathrm{Attn}_{SpaPos}(X') - \mathrm{Attn}_{SpaNeg}(X')$$

其中 $X'$ 为在所有帧上统一使用相同帧索引的时序位置编码版本。这种正负空间注意力的设计实现了**符号感知的语义编辑**，将正向语义增强和负向语义抑制显式解耦。

**微调阶段仅更新** $\mathrm{Attn}_{SpaPos}$、$\mathrm{Attn}_{SpaNeg}$ 以及 feed-forward 层，原始 3D 注意力参数始终保持冻结，从而确保时序一致性。

### 3.3 双路径流水线

在时空解耦的基础上，ViFeEdit 还需要将源视频作为条件信息注入模型。受近期图像编辑方法启发，论文复用 DiT backbone 对条件信息进行编码，并设计了**双路径流水线**：

- 两个流（含噪视频潜变量 $Z$ 和源视频条件 $C_V$）分别独立处理，**仅在 2D 空间注意力模块中交互**，确保原始 3D 注意力不受影响；
- 在 3D 注意力层，$Z$ 和 $C_V$ 沿 batch 维度拼接：$[Z, C_V] \in \mathbb{R}^{2B \times N \times d}$，各自使用独立的 3D 位置编码；
- 在 2D 空间注意力层，将输入展平为单帧格式 $\mathbb{R}^{(B \times f) \times (h \times w) \times d}$，并沿空间维度（如 $w$）拼接，使注意力仅在每帧内部发生，确保帧间一致性。

此外，为增强结构一致性，可选地使用 SDEdit 方式将 $C_V$ 作为噪声先验初始化潜变量：

$$Z_\alpha = (1 - \alpha)C_V + \alpha\epsilon$$

#### 独立时步嵌入（Separate Timestep Embeddings）

由于 $Z$（含噪潜变量）和 $C_V$（干净源视频）处于不同的噪声水平，使用相同的时步输入会模糊条件引导。为此，论文为二者分配**独立的时步嵌入**：$Z$ 使用当前流匹配时步 $t$，而 $C_V$ 始终使用时步 $0$（代表干净输入）。

## 总结

ViFeEdit 提出了一个优雅的解决方案，回答了"能否无需视频数据来调优视频编辑 DiT"这一重要问题。通过**架构重参数化**实现时空解耦，以及**双路径流水线**加独立时步嵌入，ViFeEdit 成功将预训练文本到视频 DiT 适配到六类细粒度视频编辑任务，仅需 100–250 对图像数据，大幅降低了视频编辑模型的开发门槛。

该方法的核心优势在于：在冻结原始 3D 注意力（保留时序建模能力）的同时，引入可学习的正负 2D 空间注意力分支（学习空间编辑映射），实现了"用图像学空间编辑、用 3D 注意力保时序一致性"的巧妙分工。与需要大量配对视频数据和高昂计算资源的端到端方法相比，ViFeEdit 在多项任务上不仅成本更低，还取得了更优的定量结果。

未来工作可能的方向包括：将框架扩展至更大规模的基础模型（如 Wan2.1-14B）、探索更多编辑任务类型（如运动编辑），以及进一步压缩所需的图像数据量。
