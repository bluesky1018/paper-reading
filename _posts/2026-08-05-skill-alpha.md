## 一句话总结

Skill-α 将技能生成分解为一系列局部编辑决策，通过回滚奖励（rollback reward）为每次编辑提供细粒度的信用分配，利用强化学习训练一个统一的技能生成器，在文档转技能和经验转技能两类任务上超越现有方法。

## 背景与问题

现代 LLM 智能体越来越多地依赖**外部技能（skills）**——作为模块化的程序单元，技能能够引导推理过程并帮助解决复杂任务。因此，如何从文档或经验中自动生成高质量技能，成为一个重要问题。

现有的技能生成方法主要依赖启发式规则或流水线式整合，需要针对不同来源（文档 vs 经验）进行特殊设计；而基于学习的方法虽然更统一，却面临一个核心难题：**技能没有自然的监督信号**——技能的价值只能通过它是否能改善智能体在下游任务上的表现来判断，而这种判断天然地延迟且稀疏。

## 核心方法

### 渐进式技能生成（Progressive Skill Generation）

Skill-α 的核心思想是将技能生成分解为一个**局部编辑决策序列**，而不是一次性生成完整技能。从初始技能出发，每一步执行一个局部编辑操作（抽象、去噪、冲突解决、压缩等），逐步构建最终技能。

这样做有两个优势：
1. 可以处理超过上下文窗口的长文档/经验源，每次只关注相关片段
2. 将抽象、去噪、整合等多种操作解耦，使信用分配更精准

### 回滚奖励（Rollback Reward）

关键创新是**回滚奖励**机制：针对每个编辑动作，通过将技能回滚到编辑前的版本，对比编辑前后智能体在下游任务上的表现差异，为该编辑动作分配精细的奖励信号。

这解决了技能生成中稀疏奖励的问题——不再只有最终技能质量这一个信号，而是每步编辑都有对应的奖励评估。

### 训练实现

使用强化学习（类 GRPO）训练单个统一的技能生成模型，该模型可以处理文档和经验两种来源，通过采样编辑轨迹并使用回滚奖励进行策略优化。

## 实验结果

在两类设置下的评测结果：

**文档转技能（Document-to-Skill）** - CL-Bench 基准（含四类任务：规则系统应用、程序任务执行、领域知识推理、经验发现与模拟）：

| 方法 | 训练类别 | 未见类别 | 总体 |
|------|----------|----------|------|
| No Skill | - | - | 基线 |
| Anthropic Skill-Creator | - | - | 较低 |
| Progressive Prompt Skill | - | - | 中等 |
| Ctx2Skill | - | - | 较好 |
| AutoSkill | - | - | 较好 |
| **Skill-α** | **最佳** | **最佳** | **最佳** |

**经验转技能（Experience-to-Skill）** - SpreadsheetBench 和 tau2-bench（航空、零售、电信三个领域）：Skill-α 在所有领域上均优于 ExpeL、AWM（Agent Workflow Memory）等竞争方法，展现出跨来源的泛化能力。

## 总结

Skill-α 通过渐进式生成和回滚奖励两个关键设计，为技能生成提供了一个统一的强化学习框架，避免了针对不同来源进行特殊设计的需要。核心贡献包括：(1) 将技能生成问题形式化为序列局部编辑决策；(2) 回滚奖励提供了稀疏奖励问题的有效解法；(3) 单一模型统一处理文档和经验两类来源。

局限性在于回滚奖励的计算需要多次执行下游任务，计算开销较大；此外，当技能生成的证据来源极度嘈杂或矛盾时，渐进式编辑的收敛性可能受到影响。
