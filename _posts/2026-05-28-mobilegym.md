## 一句话总结

MobileGym 提出了一个浏览器托管的轻量级移动端 GUI 仿真平台，通过结构化 JSON 状态实现确定性验证和低成本并行在线强化学习，并在 Sim-to-Real 实验中证明仿真训练收益可以 95.1% 保留到真实设备。

## 背景与问题

移动端 GUI 智能体在从截图和自然语言指令操控智能手机方面取得了快速进展，但当前评测和训练环境面临根本性权衡：

- **模拟器环境**（如 AndroidWorld、AndroidLab）：可重复评测，但主要覆盖系统工具和简单开源应用，扩展到在线训练需要大量重量级模拟器实例
- **真实设备基准**：交互保真度高，但不可重置、代价高昂，且存在不确定性

两种路径都无法同时满足**可验证的结果信号**和**可扩展的在线强化学习**这两个核心需求。

现有方法在评测真实日常应用（如社交媒体、电商、外卖等）时面临巨大挑战：后端数据不确定、副作用难以控制（如误发消息、误下订单），且验证机制依赖脆弱的文本匹配。

## 核心方法

### MobileGym 平台架构

MobileGym 是一个浏览器托管的类 Android 仿真环境，将应用数据、系统设置和设备属性表示为**显式结构化状态**，实现配置、重置、快照、分叉和比较。

*图1：MobileGym示例界面，展示可配置的沙箱化启动器和消息界面*

![端到端工作流](https://arxiv.org/html/2605.26114v1/x2.png)
*图2：MobileGym端到端工作流——结构化状态支持任务实例化、并行推演分叉和状态差异验证*

**核心技术特性：**
- **单台服务器**可托管数百个并行实例（每实例约 400MB，冷启动约 3 秒）
- **全状态 JSON 化**：完整环境状态可被捕获、配置、分叉和比较
- **确定性判定**：通过结构化 JSON 状态的基于状态的判定提供可验证结果信号
- **分层状态模型**：World Data（只读）+ Runtime Overlay（运行时）+ OS Runtime

![系统能力与状态模型](https://arxiv.org/html/2605.26114v1/x3.png)
*图3：MobileGym系统能力和状态模型，应用视图通过组合World Data、Runtime Overlay和OS Runtime生成*

### AnswerSheet 评测协议

传统自由文本匹配存在严重缺陷——可能拒绝等价答案或接受泄露的推理过程。MobileGym 引入 **AnswerSheet 协议**：通过 GUI 表单填写和类型特定验证替代文本启发式匹配。

![AnswerSheet协议](https://arxiv.org/html/2605.26114v1/x4.png)
*图4：AnswerSheet协议——使用GUI表单填写和类型特定验证，避免自由文本匹配失败*

### MobileGym-Bench 评测套件

**规模：** 416 个参数化任务模板（256 测试 + 160 训练，严格不相交），覆盖 28 个应用

**任务分类（四个正交维度）：**
- **范围（Scope）**：S1单应用 / S2双应用 / S3三应用及以上
- **目标（Objective）**：操作型 / 查询型
- **数据（Data）**：不同参数化程度
- **难度（Difficulty）**：L1-L4 校准难度层级

## 实验结果

### 9个智能体的综合评测

对 9 个智能体（含 Gemini、Claude 等顶级商业模型）进行评测，成功率区间为 9.4%–58.8%，提供 6× 性能区分度，无饱和效应。

**关键发现：**
- 难度 L1 已能区分商业与开源智能体
- L4 成为前沿判别因素
- 各模型成功率随 L1→L4 单调下降

| 模型类型 | 总体 SR | L1 SR | L4 SR |
|---------|---------|-------|-------|
| 最强商业模型 | ~58.8% | 高 | 低 |
| 开源最优 | ~中等 | 中 | 极低 |
| 开源基线 | ~9.4% | 低 | 极低 |

### Sim-to-Real 迁移实验

在关键 Sim-to-Real 案例研究中：
- **Qwen3-VL-4B-Instruct** 经 GRPO 训练后，在 256 任务测试集上提升 **+12.8 pt**
- 在 59 任务真实设备信号子集中，**真实设备保留 95.1% 的仿真训练收益**

![Sim-to-Real迁移结果](https://arxiv.org/html/2605.26114v1/x5.png)
*图5：GRPO训练收益的Sim-to-Real迁移——各难度桶和信号总体的成功率对比*

这一结果证明了 MobileGym 的交互保真度足以支持有效的行为策略迁移。

## 总结

MobileGym 将日常移动端使用转化为 GUI 智能体研究的完全可控仿真环境。通过将状态可读（确定性验证）、可写（重置配置）、可分叉（并行在线 RL）和无后果（高风险操作沙箱）四大特性统一于一个平台，填补了现有移动端 GUI 研究基础设施的关键空白。

特别是对在线强化学习的支持——低成本（~400MB/实例）、快速冷启动（~3s）、高并行度——为移动端智能体的 GRPO/PPO 训练提供了实用基础。

局限性在于 MobileGym 模拟商业应用的交互语义而非真实服务后端，服务器驱动内容（广告、推送、推荐流）以占位符表示，且视觉细节（动画、特定图标）与真实应用仍有差异。
